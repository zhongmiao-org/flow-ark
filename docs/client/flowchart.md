# 编辑器流程图语义

2026-09-16：用户要求不同动作通过形状区分。沿用 React Flow 自定义节点与连接桩；AntV X6/XFlow 也具备所需能力，本次无须迁移图库或执行契约。文档只在治理仓库维护。

遵循常用流程图视觉约定，不宣称通过 ISO/BPMN 规范认证；相同语义类别可以共享形状，由图标与名称进一步区分。

| 语义 | 形状 | 当前节点 |
| --- | --- | --- |
| 开始 / 结束 | 胶囊终止符 | 画布辅助标记，不是执行节点 |
| 数据 | 平行四边形 | value |
| 处理步骤 | 矩形 | HTTP、浏览器、结果断言；断言失败中止，不伪装成可编辑双分支 |
| 预定义处理 | 双侧线矩形 | JS/TS、模板动作 |
| 文档 | 波浪底边文档形 | 文件 |
| 工作簿 | 多文档叠页形 | Excel |
| 条件判断 | 菱形 | condition；成立 / 否则从两侧引出 |
| 人工操作 | 梯形 | human |
| 串行循环控制 | 六边形并显示回边 | loop；本应用的循环视觉约定，不将六边形称为唯一标准循环符号 |

条件的两条分支并列布局，分支末端或空分支在辅助汇合点连接后续步骤；不存在绕过分支体直达后续步骤的第三条路径。循环显式区分逐项进入、下一项回到循环控制、完成后继续；显示的回边仅投影既有串行循环语义，不能通过拖线创建任意回路。

布局使用各子树的占用宽度和高度，避免嵌套条件/循环重叠。开始、结束、空分支、汇合点属于渲染辅助元素，不能编辑、导出或生成 Run 步骤。显示辅助元素不改变流程 JSON、节点版本、快照、计划或数据库，不需要迁移。

验证应覆盖嵌套及空分支、循环返回和完成路径、实际执行路径与图形一致、选中节点仍可编辑；桌面截图检查形状、文字、连接桩和边标签。图形使用 SVG 路径，保持内部文字正向；选择状态沿真实外形描边，颜色不是唯一区分。

参考：[IBM 常用流程符号](https://www.ibm.com/think/topics/workflow-diagram)、[React Flow 自定义节点](https://reactflow.dev/learn/customization/custom-nodes)、[连接桩](https://reactflow.dev/learn/customization/handles)、[AntV X6 节点](https://x6.antv.antgroup.com/tutorial/basic/node)、[AntV XFlow](https://github.com/antvis/XFlow)。

## 长流程全图与选中步骤

2026-09-20：修正长流程在窄窗口和展开内置网页时，全图仍受固定最小缩放限制而裁切的问题。具体实现与安装状态见[验收](acceptance.md)。

- 全图视图按完整投影的实际宽高与当前画布尺寸计算缩放下限，包含开始、结束、空分支、汇合及循环回边。初次打开、结构变化、未选择步骤时的尺寸变化、显式 Fit View 使用同一边界；不能仅把 0.15 换成另一个会再次截断长流程的固定常数。
- 全图用于查看整体结构，长流程文字会随缩放变小。保留缩放与平移，并提供显式“聚焦所选步骤”入口：以所选执行节点为目标恢复可读视图，无选择时禁用。聚焦和全图切换不改动选择或草稿。
- 已选步骤时展开/收起网页或改变窗口大小继续保持该步骤可见；仅参数输入、节点选择或普通重渲染不得撤销用户手动平移/缩放。流程切换和结构变更不能沿用过期的投影边界。
- 仅调整 Renderer 投影视口，不修改节点形状与尺寸、执行结构、JSON、公共契约 0.7.0、IPC、Run/计划/数据库，不触发保存、运行或网页刷新。内置网页仍按 1920 CSS 像素排版，画布缩放与网页缩放相互独立。

使用隔离内置表单验证：先在旧安装版复现长流程裁切，再核对窄/宽窗口、面板展开/收起、超过百步及多层条件/循环的完整投影、显式全图与聚焦切换、无选择状态、参数编辑保留手动视口、结构修改和切换流程。实际 DOM/SVG 边界应落在画布可视区；核对网页控件、会话与未保存输入保留，零意外 Run 或表单提交。不能以强制点击、注入 transform、只检查所选末端节点或进程存活冒充全图通过。
