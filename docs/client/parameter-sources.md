打开选择器时标题包含目标参数，来源面包屑为「流程参数与资源」。候选只含当前可用的其他流程参数与本地草稿子字段；不显示运行后才产生的步骤输出、循环项。取消返回并恢复入口焦点。确认写入对应来源字段并展示有效预览；非法路径或依赖错误保留当前输入、内联提示并阻止保存。删除被引用参数阻止并明确引用者，重命名更新来源及步骤引用。未保存返回支持继续编辑、放弃、保存后离开，失败保持草稿。

导出 ZIP 不保留真实固定值或求值结果；来源路径需要的结构以空文本/0/false/null 中性值保留，输入类型依据有效参数生成。

模板实例的入口输入沿用现有 Schema 表单说明，必须明确列出哪些参数在运行时由来源路径覆盖，提醒编辑对应来源参数。宿主从当前入口流程的已保存来源生成说明，保留模板原有说明；不把真实值、求值结果或新默认值写入说明，不修改包定义、Schema 校验条件或运行快照。入口页与入口详情使用同一份说明，不新增协议字段或独立基础组件。
