# 滚动网页区域

2026-10-20。真实BOSS列表在原北京条件下经普通UI滚动由15项增加到45项，现有16种网页动作和SDK均没有区域滚动。原实例已有6条确认招呼及单项自动回执闭环；加载新候选、冻结覆盖、续批与网站150次上限仍未完成。本增量补通用能力，站点选择器、候选队列和招聘规则继续归模板。

## 先行交互

在既有网页目标配置明暗页面中复用字段、按钮、字体和语义主题，展示滚动配置、变量来源、已滚动、区域边界、定位无效、取消/来源变化六类状态。普通作者从动作库选择“滚动网页区域”，拾取或引用一个准确目标，选择向上/向下及1–2000 CSS像素距离，显示固定iframe范围和最近纵向滚动区域语义，再保存。高级JSON不成为正常路径。

执行结果展示实际位移、前后位置与是否到区域边界；滚动成功不代表新增内容已加载，区域边界不代表网站没有下一批或当天任务完成。后续流程须另外等待并读取实际候选、按准确链接去重，不把计数增长当打招呼成功。

## 通用契约候选

独立browser新节点及browser-scroll-v1能力，旧节点和SDK1.0语义保持。目标采用既有有限固定CSS或变量引用，框架路径固定、最多8层；本次只提供纵向滚动。距离为1–2000整数CSS像素，方向为up/down；没有无限到底、自动重复、业务点击或任意网页脚本入口。

本次命令固定唯一可见目标及其文档/框架，选取目标本身或最近的纵向auto/scroll/overlay祖先；无适用祖先时才使用该文档的scrollingElement。到达边界不继续滚动父区域。返回区域来源、前后实际scrollTop、scrollHeight/clientHeight、位移和边界；隐藏、多匹配、非标准书写/反向布局、范围超限或无法确定区域时拒绝。导航、目标/祖先变化、取消或期限到达后不派发后续步骤，不重试滚动。

首批实现内置和所选Chrome；Firefox/Safari明确阻止新节点，其他浏览器不冒充通过。滚动可触发网站加载，但不点击或提交内容；仍须自己的browser/use资源和流程/入口能力声明。Renderer仅维护普通配置和显示结果，宿主按不可变节点复验已解析目标与调用身份，通用驱动执行固定有限操作。受保护实际结果与普通日志脱敏保持，无新数据库、任意JS或招聘专属IPC。

当前为设计与未发布候选。正式协议、客户端采用/完整打包、原生UI配置/结果/重开与模板实际续批分别取证；不新增或运行单元测试，执行既有类型、格式、构建及所需真实界面验证。个人资料、凭据、登录态和既有账本保留。

独立[0.49.0候选](../../contracts/v0.49.0/README.md)包含169份机器资料，旧定义及旧Node变体逐项保持。新增固定调用/结果数值关系及作者/包能力、自己的browser/use资源校验，来源维护于[区域滚动草案](../../contracts/drafts/browser-region-scroll/README.md)。21项格式/固定来源关系和4项声明关系通过；169项摘要及准确重建逐字保持。可复制命令为`python3 contracts/build_browser_scroll.py --output /absolute/new-empty-directory`与`node contracts/drafts/browser-region-scroll/check-format.mjs /absolute/existing-dependency-directory`；依赖目录只提供AJV/esbuild，不导入应用源码，不安装新依赖。

位移采用[CSSOM View规范的instant行为](https://drafts.csswg.org/cssom-view/#smooth-scrolling)，避免把尚在平滑过渡的中间位置当最终位置。新回执不追加到旧结果；既有SDK不接受scroll，作者只使用新的可视化节点。尚未发布tag、客户端采用、打包或实际滚动执行，不将纯格式核对计为浏览器/招聘验收。
