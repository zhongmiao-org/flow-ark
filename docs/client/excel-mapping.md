# Excel 字段映射

## 节点和数据

契约 [0.10.0](../../contracts/v0.10.0/README.md) 新增 `excel` v3、`operation: map`。`binding` 是逻辑输出目录，`name` 是相对 `.xlsx` 文件名或既有值引用，`sheet` 是 1～31 字符的工作表名称，不允许 Excel 禁用字符、控制字符、首尾单引号及保留名 History。不添加文件读取、预览或网络权限。

`rows` 是记录数组或既有值引用，最多 100000 条。记录可以是普通对象或数组；映射 `source` 是单个自有属性名，数组使用零基索引字符串。它不是 JavaScript 表达式或点路径，含点字段名按字面属性处理，不访问原型或隐式解析子对象。缺少所选字段、非法记录或非标量值报告来源行与映射列，不默默写空白。

`mappings` 为 1～256 项，每项指定 `source`、大写目标列 `column`（A～XFD）、表头 `header` 和类型 `type`（text/number/boolean）。目标列必须唯一；非连续列保留空位。`includeHeaders` 明确是否将表头写入第一行，映射数组顺序不改变目标列位置。最多生成一百万个含空位的单元格，超过时在输出前拒绝。

`nullPolicy` 当前只支持 blank。显式 null 写空单元格，空字符串仍是字符串，0 和 false 不能当作空值。其他值必须与映射类型相符；不做字符串到数字等隐式转换。对象（含 formula/result）、数组、非有限数字均拒绝，普通字符串中的等号保持文本，不执行公式。该操作不读模板、不保留宏、不处理公式或新增格式。

## 保存、预览和运行

编辑页保持独立草稿，工作簿、表名、来源、映射和类型一起保存；取消只放弃此页的修改。离开需要保存／放弃／继续编辑；保存时检查来源草稿仍一致，不能覆盖期间的其他修改。来源、映射或参数变化使旧预览失效。

预览仅解析当前参数和字面量，验证全部可解析记录后最多显示前三行，不执行前序步骤、脚本或文件操作。运行期引用不可预览时明确标记，允许保存尚需运行核对的配置；可静态确定的冲突必须定位并阻止保存。运行时使用同一映射规则，按该 Run 的固定快照解析数据，在写文件之前完整校验所有记录；即使冲突出现在预览的三行之外，也不能先写部分结果。

输出只新建文件，不覆盖同名文件、目录或符号链接。最终提交必须以原子的不覆盖操作占用目标名；不能用“先检查不存在，再普通 rename”代替。写入途中失败仅清理本次临时文件，已有目标字节保持不变；两个并发创建最多一个成功。成功后按既有规则登记产物副本；失败不自动重试或重放。输出目录遵守既有授权和路径范围，运行／计划绑定不可变快照，编辑草稿不改变已开始的执行。

2026-10-15 取消与故障恢复补充：工作簿序列化期间可请求取消；在创建临时文件、开始序列化及原子提交目标名之前检查该Run取消信号。提交前检查检测到取消时，不发起目标提交、不登记成功产物，并尝试清理本次临时文件；进程被回收或目录不可访问时，临时文件也可能需要人工核对。检查之后的系统提交与取消存在竞争，不能仅凭取消时间或零产物断言零写入；原子提交已完成后的取消不能承诺撤销磁盘副作用，须按原Run核对文件及产物，禁止自动重放。取消与完成不混为同一回执，不改变旧Run快照。

权限不足、目录失效、只读位置、空间不足或文件占用应提供可读原因，保持已保存映射与原文件；恢复目录/权限/空间或明确选择其他文件名后，重新预检并创建新Run，失败Run保持。此补充落实现有取消和原子写入边界，不增加公式、宏、公开字段或契约版本。
