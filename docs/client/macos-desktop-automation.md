## 2026-11-07 动态窗口观察校验

两次实际只读Run均在窗口观察处以observation-changed停止，Excel读取节点成功，没有桌面写入。原因是把连续两次完整AX树的所有文字和值完全相同作为观察成功条件，动态网页会被过度拒绝。

只读观察采用单次有界快照，前后核对同一进程/窗口及几何位置。动作仍核对结构快照、准确目标控件的身份与属性；输入/复制核对焦点及选区，坐标动作核对截图中的目标区域。用户切换对象、改变目标或窗口几何变化继续拒绝，unknown不重放。不以取消全部校验解决动态文本问题。单个原生动作effectKey须唯一，同一业务effectId下的点击/粘贴/按键使用不同子键，不能共用一个键。
