## 边界与实现

扩展本机 Swift 助手，保留 TextEdit 原选区路径；通用窗口观察/动作采用独立 v1 草案。Main 管理原生会话，宿主控制授权、唯一桌面租约及效果账本，Worker 只能调用固定 SDK。窗口按应用、进程启动身份与原生窗口固定，不按标题重新查找后静默切换。

观察包含短期 observationId、控件引用、窗口逻辑坐标与按需窗口截图。动作包含激活、点击/双击、滚动、拖动、输入、组合键；前置检查观察版本、窗口几何与焦点。控件树优先，视觉识别仅本人明确选择的窗口；辅助功能和屏幕录制分别授权。动作后重新观察，执行回执不等于业务成功。unknown 不重发。人工干预、目标变化、取消和超时停止动作。

AI、普通流程、JS/TS、CLI/MCP共用正式宿主。20次请求/10分钟默认预算包含规划和视觉，开始前确认费用及发送范围；静态检查不调用模型。使用本人受保护Key，模型不支持视觉时明确拒绝，不换模型。API Key产生的费用由用户自行承担。
