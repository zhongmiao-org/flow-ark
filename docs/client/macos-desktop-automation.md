## 2026-11-07 动态窗口观察校验

两次实际只读Run均在窗口观察处以observation-changed停止，Excel读取节点成功，没有桌面写入。原因是把连续两次完整AX树的所有文字和值完全相同作为观察成功条件，动态网页会被过度拒绝。
