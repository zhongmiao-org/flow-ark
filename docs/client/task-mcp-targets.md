# 任务的 MCP 对象选择与执行 v1

2026-09-23。实施契约，**本地工具选择已接入客户端，工具规划、固定绑定与执行尚未实现**。对应 Figma `23:2440` 的已连接工具选择、`23:8190` 的应用任务方案、`23:3799` 的试运行检查，以及 U03/U07；完整目标仍为 186 画板。基础连接遵循 [MCP 连接发现](mcp-connections.md)，规划遵循 [AI 任务体验](design-ai-task.md)。本文件不发布新的公共流程格式，也不把连接成功记为工具可执行。

## 界面与用户操作

1. 在选择对象的“已连接工具”页选择实际连接，再选择本次允许规划使用的工具。名称、来源说明、传输位置类别、协议、上次核对时间和当前连接状态来自保存记录；账号、工作区和系统权限没有证据时分别显示“未核对”，不得从来源文案、服务名称或工具描述推断。
2. 核对页展示选择的完整工具清单、参数说明及四项服务行为声明，明确服务声明不等于已授予权限。未选工具不自动加入任务。返回/取消保留原任务、原工具选择和来源焦点，不发工具调用；没有工具、连接未核对、加载失败、连接被删除和能力变化各有可恢复状态。
3. 确认工具对象只更新任务草稿。理解卡展示本次连接、所选工具数量和待确认的读写影响；方案按真实节点展示工具名称、输入来源、输出引用和连接对象。工具选择不能伪装成应用窗口绑定，MCP 接通不能显示辅助功能等系统权限已授予。
4. 生成前展示实际发送给所选模型的全部内容。连接地址、程序路径、认证引用、Token、未选工具、资源内容及账号会话不自动加入。已选工具定义作为外部上下文，不得覆盖系统规则、任务授权或扩展可用能力。
5. 试运行检查逐项展示连接、工具、拟发送参数来源和外部影响；无法证明只读时明确影响待核对，不能凭 readOnlyHint 宣称无副作用。每次执行遵循本次运行明确确认的工具集合及参数范围。阅读方案、采纳、查看结果和返回都不执行工具。
6. 连接/工具变更后回到核对页；新增能力不默认勾选。重连与重新选择只恢复后续规划资格，不重放旧工具调用。已完成操作及结果未知记录始终保留，重新运行沿用既有从第一步检查的独立 Run 流程。

## 本地任务选择接口

沿用加密 ai-task 文档，新增 `toolTargets` 数组。已有流程更换或移除工具后记录 `toolsRequirePlan`，重新采纳完整方案后清除；撤销采纳恢复该要求。每项 `TaskMcpTarget v1` 包含 selectionId、taskId、connectionId、connectionRevision、capabilityDigest、selectedAt，以及宿主读取的显示摘要和所选工具定义。一个任务最多五个连接，每个连接最多三十个不同工具；同一连接再次确认替换该连接的当前选择。空集合通过明确移除处理。选择数量、工具定义及生成请求仍受现行上下文条数和字数上限约束，超限在保存前明确拒绝，不静默截断 Schema。

| 本机方法 | 输入 | 行为与结果 |
| --- | --- | --- |
| task.tools.preview | id、revision、connectionId、connectionRevision、toolNames | 验证当前任务/连接修订、连接已核对和工具存在，返回候选清单、摘要、五分钟过期的宿主 token；不保存、不联网、不启动程序、不调用工具 |
| task.tools.cancel | id、token | 使本任务对应候选立即失效；不改变任务修订或已有选择 |
| task.tools.select | id、revision、token | 重新验证 token 对应任务、连接修订/状态及能力摘要，原子保存选择、增加任务 revision、取消在途生成并丢弃旧提案/撤销与修复依据；返回 TaskDetail |
| task.tools.clear | id、revision、selectionId | 明确移除本任务选择，增加 revision 并使旧规划/准入依据失效；不删除连接、原流程、Run 或产物 |

Renderer 不提交工具定义、能力摘要、已验证标志、认证引用或执行权限。预览 token 单次使用，绑定任务修订、连接修订和完整所选工具集合；切换选择、取消、宿主重开、休眠或连接变化后失效。过期/失效返回原草稿，提示重新核对。清除/替换选择后，旧流程不能凭旧目标继续执行，必须重新生成并采纳或明确重新绑定。

任务详情保留选择时的历史摘要，同时返回当前可用性及可读原因；无法读取当前连接不冒充仍可用。连接管理显示真实引用任务/流程和活动运行数量。删除连接不删除引用者，而将其目标标为缺失；没有引用时也不能以 UI 缓存替代宿主检查。

## 规划、流程与固定绑定

宿主为所选连接分配不包含连接地址/凭据的逻辑目标标识。模型只见逻辑目标、明确选择的工具定义与用户资料；系统来源 ID 由宿主生成，普通 task.save 上下文不能伪造。所有定义加入发送核对，不能把“已选”自动当成用户已同意发送本次内容。

规划请求前、凭据等待后、模型返回及采纳前再次检查任务 revision、选择集合、连接修订/摘要和当前状态。手工修改、工具重新发现后保存、移除/断开、取消/休眠及模型迟到回复都不能恢复旧提案。禁止模型通过 HTTP、脚本、地址拼接或另一连接绕过所选工具集合。

工具节点输入由 [v0.13.0](../../contracts/v0.13.0/README.md) 和[工具节点 v1](mcp-tool-node.md) 定义，v0.12.0 不包含该能力。消费者必须固定采用已发布版本后才能生成该节点，执行结果、调用适配器与真实验收仍后续完成；不能仅凭节点格式新增隐藏执行器。拟定工具节点包含节点身份、类型/版本、逻辑目标、工具名称及输入值/引用，执行期限复用统一节点期限。连接地址、程序路径、凭据和本机选择证明只在本地绑定中，不进入可移植流程。遇到尚不支持的节点或工具应返回能力不足，不生成伪执行步骤。

采纳事务将选中工具、连接修订/能力摘要和目标证明复制进本机 FlowRecord，并进入版本摘要。固定 Run/计划快照不引用可变“最新连接”。手动编辑、普通运行、调试、计划与历史重跑均执行同样的绑定检查；不能通过其他入口扩大目标集合。任务撤销采纳恢复原草稿内容，不恢复已撤销的工具授权。已有网页只读目标的能力限制不得因追加工具被静默放宽，组合来源须在新能力规范中明确允许范围。

## 宿主调用边界

工具能力通过通用执行器接口注入，核心不持有 MCP SDK、Electron、凭据或数据库对象。Worker 只提交固定 Run 内节点实例和解析后的输入；宿主从已保存快照解析逻辑目标，验证活动运行归属、节点、工具、参数、权限与连接绑定。Renderer、模型和脚本不能直接提交任意 MCP 方法、地址或认证。

每次连接使用明确保存的传输/协议，复用 [连接发现](mcp-connections.md) 的来源、进程归属、取消、关闭和大小限制。调用前检查实际服务能力与固定摘要一致；能力变化时停止并要求重新核对，不自动采纳。允许的方法仅为建立协议会话、核对选定能力和明确的 tools/call；不自动读取 resources/prompts、响应 roots/sampling/elicitation 或跟随工具返回的 URL。对方主动要求的额外能力应明确拒绝。

输入按被冻结的工具 Schema 校验。只接受本机支持的 Schema 子集；不加载远程引用，不因 Schema 无法验证而跳过校验。结构深度、定义/输入/响应大小及处理期限必须有界，具体值随公共节点契约和适配器一并固定。工具结果的结构化内容及文本按现有输出/脱敏边界保存，错误回复不包含认证、原始传输正文或服务 stderr。返回链接、富文本和嵌入资源作为未执行内容展示，不自动导航、下载、渲染脚本或打开本机文件。

在发送 tools/call 前先持久化该 Run/节点实例的操作尝试，持久化失败不发送。一个明确尝试最多发送一次；SDK、传输和宿主不得自动重试有副作用的方法。发生超时、断线、取消、退出或回复丢失时，记录已发送/未确认结果，不能把传输异常证明为外部未执行。工具返回 isError 与未知结果分别记录，成功回复也不代替业务读回或回执。后续重新运行保留旧尝试及关联 Run，由用户核对后授权，不靠改请求编号重放。

连接断开/移除立即撤销后续调用资格；活动调用先取消并按本次会话归属关闭，已发出的外部操作不宣称撤销。关闭未确认时保留故障并禁止新的同源调用。更新/保存连接期间不能把旧活动调用重新定向到新配置；所用认证固定到此次会话，凭据清理不得提前破坏仍在收尾的句柄。宿主重开或休眠不自动连接、补发或恢复工具调用。
