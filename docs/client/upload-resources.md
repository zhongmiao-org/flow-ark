# 上传资源的准入与执行检查

2026-09-20。0.1.19 审计复现：宿主预检只收集 file/excel 的目录，只有 browser upload 使用的未绑定目录仍被接纳。修复沿用现有 `{binding,name}` 上传值和本机目录绑定，不增加协议、IPC、数据库或浏览器能力。

- 上传描述必须是含有 binding、name 的对象，两项解析后均为非空字符串。字面量或流程参数可确定的值在准入时校验；前序步骤、循环 item/index 等动态来源保留到执行边界，不猜值或提前执行节点。参数对象被引用后是数据，不递归执行参数内容中的 `$ref`。
- 静态可确定的目录绑定必须存在并仍为本机目录；嵌套分支、循环同样检查。保存计划、创建 Run、排队后启动共用预检，错误不创建新 Run 或计划、不执行前序副作用。可确定的文件名先做目录范围检查，但不要求目标文件已经存在，允许前序文件/Excel/可信脚本生成目标文件。
- 编辑器“参数与绑定”也显示由参数引用确定的上传目录名；不读取文件系统，不从任意历史输出推断动态目录。半成品配置保留，错误在保存后的运行/计划准入明确报告。
- 上传动作交给 BrowserDriver 之前，从不可变快照解析实际目录绑定，再次检查范围（含符号链接）、文件存在、普通文件类型和可读性。动态来源或排队后文件/目录变化也受检查；失败不调用上传驱动、不自动重试，已完成步骤不重放。不将路径检查描述为针对恶意可信脚本的安全沙箱，也不承诺消除操作系统路径竞争。
- 原 file/excel 目录检查保留，真实路径不进入导出的流程。旧草稿和历史记录不改写；过去接纳的无效配置在下次准入或执行上传时明确失败。

验收：宿主证明仅上传使用的缺失/无效目录、参数引用目录及非法描述在准入时失败，前置文件副作用不存在；动态来源在执行时拦截目录/缺失文件/越界链接且不调用驱动。真实内置浏览器从界面绑定参数引用目录，执行先生成文件后上传，核对网页实际读取字节，并保留完整复杂表单回执与取消/恢复回归。只使用本机虚构服务、隔离数据与内置浏览器。代码、DMG 候选、最终安装和日常桌面分别记录，日常升级仍待先前解锁请求的回复。
