# 初始默认值及开发实例的受控纠正

2026-11-11，未发布候选。现有宿主的默认值算法对所有可选属性递归造值，将缺少默认值的 nullable/anyOf 字段生成为空字符串。实际 Excel 工程的可选 layout 被填入空列数组/空网址，初始 pending 被填为空字符串；正式重建因违反原 Schema 拒绝。此为客户端初始化与重建问题，不是用户代码修改要求。

## 默认值

显式 default/const 优先；无显式默认值的可选属性不实例化。nullable 选择 null，不把空字符串当 null。数组最小项数、必填网址或布局等不能靠凭空生成值满足。缺少真正可用的初始业务值时，仅保留尚未初始化的初始槽；SDK 第一次 state.set 继续按原业务 Schema 校验并登记状态修订。不存在放宽业务 Schema、将 unknown 当空状态或正常启动清理的路径。

## 仅本机工程重建可纠正旧初始值

纠正必须通过既有正式 project-rebuild 确认，展示脱敏预览及准确摘要；确认后同一事务重新核对：旧实例配置或状态与旧宿主算法生成值逐项精确一致，状态修订为 0，所有已有 Run 的固定快照入口无 action，且无模板 effect、桌面/MCP effect 或状态数据提交。只读检查 Run 可保留；任何写入、未知、非初始值、并发变化或资料不完整均拒绝。

配置只修正匹配的旧无效默认值，用户配置不覆盖。状态只修正精确的旧无效初始值；不能生成合法业务初值时，以既有 SDK 可返回的 null 表示尚未初始化，私有元数据限定 revision=0。该槽不是业务状态通过证据，后续业务写入仍完整验证 Schema。

旧值与前后摘要、准确实例/包/修订、核对依据及确认回执存入本地受保护记录，不进入 Git/ZIP；不删除 Run、effect、unknown、去重、配置资源、Key、Skill 或登录。后续开发仍复用同一实例及历史，不创建实例绕过准入。

类型、构建、现有契约与静态检查分别记录；不新增或运行单元测试。实际修复、正式重建和业务填写验收分别登记，本文不能作为业务通过证据。

已合法登记的 revision=0/uninitialized=true/null 槽是已有初始化状态，不是再次纠正旧值的操作；当本人配置有效时，普通源码重建原样保留该槽和所有历史，不重复要求既往 Run 无动作声明。任意未标记 null 仍按原业务 Schema 拒绝；真正旧默认值纠正仍必须满足全部零修订、精确旧值、无 effects 与只读历史条件。
