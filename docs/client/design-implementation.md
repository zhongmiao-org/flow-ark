## 首页统计的本地接口增量

`bootstrap.runOverview` 增加 `today` 只读字段：`{ date: string, total: number, succeeded: number, failed: number, interrupted: number }`。`date` 为宿主当前本地日历日期 `YYYY-MM-DD`；按 Run 的 `createdAt` 落在当天本地午夜至下一天午夜的半开区间汇总完整运行记录，而不是最近 200 条历史。成功/失败/中断计数只按现有 Run 状态，其他排队、运行、暂停或取消记录计入 total。不得把“中断”推断成已确认的外部业务失败或待核对数量。

只新增本地展示响应，不改变请求白名单、公共契约 0.8.0、持久化数据、快照或计划语义。缺失统计时 UI 显示未取得数据，不将缺失当成 0；正在运行仍依据宿主 execution 所有权，而非旧历史 RUNNING。验证跨日边界、未来/无效时间、全部记录及超过 200 条统计。

最近编辑采用本机最近七个日历日，以流程 `updatedAt` 排序；来源筛选依据实际模板引用。搜索不修改流程或触发运行。首次使用页只在成功读取后确认为零流程时显示，读取失败保持错误提示。
