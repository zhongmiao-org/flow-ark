## 修复范围

保持不可变Run、旧SDK1.0和既有IPC/数据库格式，不增加自动升级或新业务节点。授权检查先验证正式实例/包/入口，再核对当前入口所需动作、原固定配置值与准确修订、当前入口资源和绑定身份。名称及其他入口无关资源不改变本入口授权；配置、所需资源或动作模式变化时停止，不静默读新值、切换资源或扩大原快照。

需要人工确认时，在等待前、响应后、记录approval前和返回允许前重新核对范围、当前权限和signal。已存在approval只能对同一当前范围使用，不能跳过最新检查。无效grant、缺少精确原配置或缺失当前实例按拒绝处理。原版`canWrite`保留调用兼容；内部可返回/传递只读复验函数，在浏览器异步会话初始化完成、命令交给实际浏览器之前再检查，避免初始化期间撤权仍下发命令。普通节点和模板SDK浏览器均须接入，SDK状态修改也不能绕过当前动作授权。

检查点只控制尚未下发的动作。已开始的驱动命令、DOM事件和站外操作不能被描述为原子撤回；后续取消/权限变化仍须核对真实回执，unknown不重放。没有伪造全局锁或宣称消除站外人工竞争；真实BOSS账号/聊天DOM/发送回执尚未校准。
