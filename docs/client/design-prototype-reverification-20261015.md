## 本轮实际发现与修订

- 参数页、参数来源选择和重跑等稿中的路径是一整段静态文字，祖先不能点击。将 36 个正常状态头部改为独立面包屑，复用原生 Breadcrumbs；祖先分别返回我的流程及当前流程，参数未保存时先设置返回目标并进入离开确认。外观祖先归本地设置。确认/保存中背景保留不可操作。此前原预检页已有祖先动作，不据此推断新参数头部也可用。
- 原预检“重新检查”`2:3989` 确实错误跳到授权页 `2:1083`。修正为检查中 `426:5287`，通过 `426:5365` 或未通过 `426:5460`；可取消并返回原预检，不创建 Run。通过仍需重新核对本次范围，消费后不能再提交。原成功卡改为“核对本次运行”；配置资源单独进入当前流程参数页。
- 新 Run、暂停及取消收尾页原先固定返回列表。现在根据来源返回 R024 的 `1:3539` 或 R018 的 `8:19176`，不修改旧 Run。新 Run 终态同步禁用暂停、取消的视觉状态；列表 R024 状态与详情使用同一变量，选择行也取当前状态。
- R018 输出页没有可用文件时禁用定位和清理，重跑入口携带 R018。参数类型异常、循环/缺失路径补上明确恢复入口。安装固定示例按网页包/文件包分别初始化确认，说明、回执、实例入口保持对象一致；不虚构真实 ZIP 安装或唯一实例分配。
