# AI 服务配置与验证 v1

2026-09-22。落实 [DeepSeek Key 状态设计](design-ai.md) 与 U08，覆盖首次配置、替换、脱敏回显、移除、连接测试及来源返回。公开流程/AIRequest/SDK/模板包不变，不添加 SQLite 表；本机 IPC 和受保护凭据格式随当前开发版共同更新，不保留旧客户端写入接口。

## 配置与存储

供应商固定为 deepseek 或 openai-codex。DeepSeek 优先展示，地址由既有适配器固定，不允许页面提交任意服务地址。model 是用户明确选择的非空模型 ID；不因配置或测试失败静默换供应商/模型。保存不发出模型请求、不生成方案、不创建 Run。

Main 通过系统保护存储，将供应商 Key 与模型元数据作为一个带 kind/version 的加密记录原子替换。配置 revision 是当前密文字节的摘要，不是 Key 的摘要；不存在时为 null。保存/移除使用预期 revision，检查与写入按供应商互斥。保护、读取、解密、加密、写入或原子替换失败时保持旧记录，错误不把失败当成文件缺失，也不创建新数据密钥。删除仅限本机所选供应商凭据，不删除 MCP、其他供应商、数据密钥、任务或历史，也不撤销供应商平台 Key。

已有受保护 Key 可继续在内部使用。旧条目没有模型/尾号元数据时只显示已配置和固定掩码；采用明确模型后保存为当前记录，不向 Renderer 返回旧 Key。此规则只保护既有凭据，不承诺旧客户端读写新格式。新记录仅提供安全尾四位，完整 Key 只从 Renderer 本次用户输入送往内部写入；已保存 Key 不回显或复制。替换留空保留原 Key；首次写入必须提供 Key。保存成功、取消或放弃编辑清理输入，保存失败保留待修正输入及原配置。

## 本机接口

| 方法 | 输入与行为 |
| --- | --- |
| ai.configuration.get | provider；读取配置、revision、configured、model、可选 tail、当前操作和对应当前 revision 的测试摘要，不联网 |
| ai.configuration.save | provider、revision（可为 null）、model、可选 apiKey；首次写入需 Key，替换留空不覆盖；原子保存并使旧测试失效 |
| ai.configuration.remove | provider、revision、confirmed:true；显示依赖影响后删除，仅成功后显示未配置 |
| ai.configuration.test | provider、revision、requestId、reviewedCost:true；对已保存配置发出一次固定 JSON 测试，不接受任务内容/自定义地址/Key |
| ai.configuration.cancel | provider、requestId；撤销对应测试，不重试或变更配置，旧回复不覆盖新状态 |

旧本机 credentials.set / ai.test 由上述接口替代，内部 credentials.get/list 保留供执行与资源检查使用。Main 的读取/比较写入/删除接口不进入 Renderer 白名单。公开响应没有完整密钥、文件路径、密文、供应商原始错误正文或任意请求参数。

## 并发与测试

Host 在保存/删除期间阻止同供应商再次修改、测试及新的凭据消费。活动/排队运行的固定快照已绑定该凭据，或该供应商正在生成方案时，禁止更改和移除；非使用该资源的任务不受影响。异步运行准入在最后写入队列前重新核对凭据可用性和配置操作，防止读取旧状态后绕过移除保护。测试期间禁止编辑和移除，只有明确取消且收尾结束后才能再次修改。

测试使用既有供应商适配器，只发送固定虚构 JSON 值并校验固定 Schema。整体有时限，凭据等待、HTTP 及解析均属于本次 requestId；只有仍属于当前请求、当前 revision 且未取消时才能记录完成。成功保存实际返回模型与时间；错误分类为认证、余额/限流、模型/请求、网络、超时或输出格式，保留 Key 和掩码，不展示原始响应或凭据。

测试状态存放在既有加密 documents 中，按供应商和配置 revision 关联；更改配置后的旧成功不可复用。重开时在途测试标为中断，不联网重试；休眠/退出撤销测试，不延误真实 Worker 的停止。取消后的迟到凭据/HTTP/结果不得覆盖状态，也不得启动第二次请求。连接测试通过只证明这次固定内容的响应，不代表业务事实、完整规划或工具执行验收。

## 来源与页面

从本地设置进入时返回原设置；从任务进入时展示实际来源任务，保留描述、附件、目标、补问、供应商/模型选择与清单/画布位置。配置保存或返回只重新读取状态，不自动生成或运行。从模板进入按已有实例和入口保持未保存普通输入；不能以设置页可用代替此来源链路验收。

未配置提示、首次填写、已保存待验证、测试中、已验证、失败、替换、移除确认均消费实际状态，不使用示例尾号/账号/测试时间。顶部返回、面包屑、侧栏与键盘返回使用同一离开守卫：保存并离开、不保存离开、继续编辑；失败留在当前上下文。测试在途离开须明确取消并等待，不在背景继续测试。

## 验证门槛

必须分别验证严格 IPC、真实系统保护读写/加密原子性、旧 Key 保留与安全回显、修订冲突、存储失败、空替换、删除在用保护、异步准入竞态、两种实际请求形状、取消与迟到回复、休眠/重开不重试，以及原任务/模板返回、三尺寸和离开守卫。隔离 HTTP/供应商夹具、真实 API、原生操作和用户验收分别记录；本规范不表示这些能力已经实现。

DeepSeek 当前 Chat Completions、JSON 格式与模型选择依据[官方接口说明](https://api-docs.deepseek.com/api/create-chat-completion/)，实际模型权限与账户额度通过用户所选配置的真实请求确认。
