## 本机选择与模型边界

- `task.output.choose {id,revision,name,onConflict}`：任务修订校验后由宿主请求 Main 打开系统目录选择器。name 是不含路径分隔符的安全文件名（最多 255 字符），onConflict 为 number 或 overwrite。Main 只把选择器取得的目录交给宿主；Renderer 不能传入路径、选择证明或已授权字段。取消不写任务、不取消既有生成、不创建流程或文件。
- `task.output.configure {id,revision,name,onConflict}`：只更改已经选择的输出文件名 / 策略。
- `task.output.clear {id,revision}`：撤销当前输出选择。

成功选择、修改或撤销递增任务 revision、取消在途生成并清除提案 / 最近采纳撤销 / 目标修复依据。单步修改期间先退出该范围才可改变整个任务输出。目录选择器等待、目录检查后再次校验原任务、取消代际和活动运行；迟到回复或同时操作不能覆盖新草稿。同一任务已有排队、执行或收尾中的 Run 时拒绝改变输出选择。退出 / 休眠 / 存储失败拒绝写入。

沿用加密 ai-task 文档，保存本地 outputTarget：selectionId、taskId、directory、目录设备及 inode 身份、name、onConflict、selectedAt。目录取系统选择的真实路径并检查为可写目录；生成、采纳、准入和步骤授权时再次核对身份与可用性。目录内容及本机路径不自动读取或发送；模型只收到宿主构造的保留上下文 `_flowark_selected_output`（固定逻辑 binding `task_output`、文件名、同名规则）。普通资料不能冒用系统 ID，二十项 / 单项 50000 / 合计 200000 字符限制包括所有宿主资料。发送核对页展示相同元数据，并明确路径留在本机。

## 方案、采纳与执行

number 使用现有 file v4 create/onConflict:number 和 file-create-numbered-v1；overwrite 使用现有 file v2 write，只作用于该目录内所选文件名，不扩大网页操作权限。模型必须使用固定 `task_output` 绑定、静态所选文件名及对应操作；不可改成另一文件、动态名字、复制、归档或读取该输出目录。选择了输出但方案没有使用时拒绝方案，要求重新核对需求。对网页只读任务，允许此用户独立确认的文本覆盖例外；网页仍只读，其他文件覆盖仍拒绝。同名序号创建保持原子不覆盖；覆盖行为在方案与运行前检查明确展示，沿用现有原子替换和目录范围校验，不自动运行或重试。

采纳在同一 Store 事务中合并 `bindings.files.task_output`，仅使用宿主保存的真实路径，保留其他绑定。已有同名手动绑定不同路径时拒绝隐式覆盖，须用户在理解页重新核对，并在既有流程中移除冲突绑定后重新生成。FlowRecord.outputTarget 同事务保存并加入版本 / 冲突摘要；flow.save 不能去掉它。撤销恢复原流程、绑定和输出约束，仍保留用户独立选择的当前输出资料；旧约束与当前选择不符时必须重新生成采纳。

选择变化不改写既有 Run / 计划 / 产物。普通运行、运行检查、排队出队、计划和历史重跑核对快照输出选择仍有效及绑定相同；步骤授权再次核对，不允许借手动编辑绕过所选文件名 / 策略。已发生的文件副作用不回滚、不重放。原子存储失败回滚任务与流程，模型结果、目录选择或一次试运行成功均不等于真实供应商或用户验收完成。

## 验证与交付边界

覆盖严格 IPC / 路径伪造、取消无写入、过期选择器 / 并发 CAS、上下文保留 ID 及合计限制、路径不外发、生成与凭据等待期间变更、恶意方案文件名 / 策略、采纳冲突及事务回滚、撤销 / 重开、真实文件策略、普通运行 / 队列 / 计划 / 重跑和手动编辑绕过。界面核对原稿两栏尺寸、目录取消 / 重选、缺少目录与模型配置返回、理解修改与补问、文件名 / 两种策略、真实运行和产物；GUI 严格单实例串行。

公开规划格式 1.0、契约 0.12.0 和 SQLite 表结构不变，不移动既有 tag。首次教学接入后须移除测试中以 flow.save 准备输出目录的捷径，重新取得 UI 到真实文件的闭环证据。规范、宿主实现、界面、真实 AI 及 U12 用户验收分别记录。
