# 导航、返回与离开保护

2026-09-21。用户反馈配置页缺少当前位置、可点击面包屑和回退路径。本规范补齐 Figma 导航闭环，供客户端统一实施；不将图稿跳转当作路由、草稿或真实运行已实现。

## 全局导航语义

- 面包屑表示信息层级，不是访问历史。祖先可点击，末级是当前页且不可点击；分隔符不接收点击。显示具体流程/模板实例/入口或 Run 编号，不只写“工作空间/设置”。长名称单行省略并可取得完整名称；紧凑窗口保留当前位置与可用祖先。
- 页面顶部提供明确命名的返回，如“返回流程编辑”“返回模板入口”“返回记录第2页”。已知来源回到实际来源及上下文；直接打开没有来源时回到有效父级。根模块不显示伪返回。
- 左侧导航高亮按当前模块，页内标签高亮按当前子页；不能在 AI 设置状态中高亮运行记录。
- 从模板进入本地设置，当前位置仍属设置，另显示“来自：模板/实例/入口”，并给出返回该入口的操作。直接从设置进入不显示无关的返回模板按钮。
- 返回、面包屑和切换页面只改变界面，不启动、取消、重试或重新播放运行。关闭网页面板不等于关闭浏览器会话。

## 来源与恢复

客户端保存结构化、可校验的来源：模块、实体 ID、标签/配置项、列表查询与分页、选中步骤和编辑视口、滚动与焦点。来源不得携带完整密钥或任意外部跳转 URL。优先恢复合法来源，否则降级到存在的父级。

| 路径 | 返回应恢复 |
| --- | --- |
| 流程编辑 → 参数/节点配置 | 同一流程草稿、选中步骤、画布位置与缩放；保存后再返回不触发运行 |
| 流程参数 → 显示网页 | 先处理参数页更改，再进入同一流程的网页工作区；保留打开参数页前的流程草稿与所选步骤，不保存离开仅放弃参数页增量；网页面板取得焦点，不自动访问网页或运行 |
| 参数/节点配置 → 变量选择 | 返回实际调用表单和字段；取消不改原值，选定后只更新当前字段；其他未保存输入不丢失 |
| 模板入口 → AI 设置 | 同一实例、所选入口、共享配置与本次输入；重新读取 AI 资源状态；不自动运行 |
| 运行列表 → 详情/产物 | 原搜索、过滤、分页、滚动和选中 Run；不会默认重置到第一页 |
| 待办 → 请求/运行详情 | 原待办筛选和位置；已处理、过期或来源不存在时明确提示，不继续执行旧动作 |
| 设置 → 子配置/凭据 | 返回原设置项；从其他表单进入时优先返回该表单 |
| 紧凑抽屉/弹窗 → 关闭 | 先关最上层并恢复触发控件焦点；不连带退出流程或丢弃草稿 |

任务主路径成功进入新的描述、对象、理解或方案页面时，回到顶部并定位当前标题；对象页返回描述时恢复需求输入。保存失败保持原页面和草稿，延迟定位须核对当前活动页面，不能把已离开的页面拉回。此定位不发送模型请求、不选择新对象，也不创建运行。

原对象已删除、来源过期、无权限或打开失败时，不跳到名称相同的其他对象。显示原因及“返回列表/留在当前设置”等明确选择，已成功保存的配置仍保留。

## 未保存更改与历史栈

所有离开方式调用同一导航守卫：顶部返回、祖先面包屑、侧边栏、切换实体、弹窗关闭、应用内快捷键与历史回退。必须有实际更改才拦截；选择变量等子任务可暂离表单，但保留该草稿。

2026-09-22 模板实例采用 [实例编辑与离开保护 v1](template-instance-editing.md)：共享配置与所有已改入口输入在同一修订上原子保存，来源冲突不能通过切换标签绕过；实现与验收另行记录。

统一三选项：

1. **保存并离开**：验证输入并等待保存成功，然后前往用户原来点击的目标。保存中禁止重复操作；校验/存储失败停留在当前上下文并保留输入。
2. **不保存离开**：放弃当前未保存增量，再去原目标；不改变以前保存的版本、活动 Run 或计划。
3. **继续编辑**：关闭提示，恢复原输入和焦点；不得更换目标或重置数据。

2026-10-12 脚本、参数与表格映射子页补充：保存并离开时校验/存储失败保留当前离开提示、原目的地和明确重试入口；继续编辑才回到无效字段，避免焦点落在弹窗背后。实际保存成功先采用回执更新本地已保存基线，再重读列表。列表刷新失败仍单独提示，但不能把已保存配置当成未保存并要求再次写入。实际范围与证据见[验收](acceptance.md)。

密钥输入取消/放弃后清理输入内存，旧 Key 及其有效测试记录保持。替换保存成功后旧测试失效；安全存储失败不明文降级。

表单中的保存成功、测试中/成功、提示弹窗不是独立历史页面。客户端应更新当前位置或替换状态，不把每个状态都压入历史；弹窗关闭先处理弹窗，避免反复回到“保存成功→表单→保存成功”。新 Run 是显式新操作，不能由后退再次触发。

Mac 的应用内返回与键盘回退应等价；输入框内的文本编辑快捷键不劫持为全局返回。Escape 先处理拾取/最上层浮层；有更改时使用同一守卫。浏览器面板自己的后退只影响网页历史，必须与工作台返回区分。

## 设计原型与实施边界

Figma 以可点击祖先、明确返回按钮、保留来源的示例页面和统一离开提示演示闭环。当前 Figma 套餐不支持多动作/条件导航，原型改为按来源和离开目的地区分分支画板：变量选择可返回对应表单，离开提示的保存/放弃都前往原点击目标。辅助确认画板归入独立原型状态分区；生产实现必须采用真实来源状态和统一守卫，不能照搬成大量固定路由。Figma 无法代表原生焦点、刷新恢复、完整历史栈、实际文件/Key 保存或每种表单组合；上述行为必须由客户端验收。

2026-10-03 目的地区分：来自模板的 AI 设置中，“返回模板入口”恢复原实例、入口和输入；侧栏“模板库”对应画板 156 的模板库首页，先处理 AI 输入，再独立处理模板草稿，保存或放弃后到达首页。保存 AI 配置不等于保存模板输入。

状态目录与导航演示仅用于规格和验收，不成为产品侧菜单。不能将虚构示例值、页码、实例、尾号或 Run 编号写死到应用。

## 客户端验收清单

- 每个页面都有明确当前位置，祖先可达、当前项无跳转，所有返回目标存在。
- 从不同来源进入同一配置/变量选择页，返回各自来源；无历史的直接打开可回有效父级。
- 逐项验证保存、放弃、继续、保存失败/处理中及验证失败，所有离开方式一致。
- AI 跨模块返回保留实例、入口及普通未保存输入；密钥不进入来源或浏览器历史。
- 列表详情往返保留查询和分页；已删除对象给出明确恢复路径。
- 运行中编辑/切页/返回不影响当前运行快照，不导致取消或重放。
- 大窗口与1040×700分别验证面包屑、抽屉关闭、焦点和键盘；原生网页后退与工作台返回相互独立。

### 2026-10-02 AI 服务的设置分类目的地

AI 服务页的凭据与文件、脚本分类进入现有凭据与本机资源、脚本包设置；脚本包再由用户选择所属流程进入真实步骤配置，不把设计状态目录作为产品菜单。浏览器、资源、脚本以明确目的地请求选择设置分类，重复进入也须生效，并清除上一次分类搜索。未保存 Key 先经过 AI 离开守卫；来自模板且原模板有未保存输入时，继续经过模板守卫，不以成功保存或放弃 AI 输入替代模板保存授权。目的地焦点落在资源标题或对应设置标签。此为 Renderer 内部导航，不新增 IPC、自动保存、运行或依赖安装。


### 2026-10-03 资源列表与流程配置

凭据与本机资源中的文件“打开流程配置”、凭据引用“打开绑定”直接进入对应流程的参数与资源页。顶部和表单返回指向原资源列表，沿用保存、放弃、继续及失败不离开的保护；返回保留搜索、展开项、滚动和入口焦点，并重新读取凭据引用。解除绑定使入口消失时，焦点回到凭据列表的新增入口。流程名称面包屑仍指向编排画布，脚本包入口仍进入编排以选择对应脚本步骤；不改变绑定授权或执行行为。
