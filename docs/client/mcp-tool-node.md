# MCP 工具节点 v1

2026-09-23。公共契约 [0.13.0](../../contracts/v0.13.0/README.md) 的草稿和方案格式，配合[任务工具目标](task-mcp-targets.md)。工具规划与实际调用分开交付，未接入宿主执行器前，普通运行、试运行、计划、调试和历史重跑都必须明确拒绝含此节点的流程。

## 字段与输入

| 字段 | 语义 |
| --- | --- |
| id、name | 沿用节点身份与可读名称，修改保留未变步骤 ID |
| type、version | 固定 mcp、1 |
| target | 1–100 位字母、数字、下划线、连字符的逻辑目标；任务规划只接受宿主授予的 selectionId |
| tool | 1–500 字符，必须精确匹配该目标已选择工具的 name；显示名称不代替原名 |
| arguments | 现行 Value，支持对象常量、整对象引用和属性中的值引用；解析后必须是 JSON 对象，不能是数组或 null |
| timeoutMs | 沿用统一步骤期限 100–3600000 ms，未填沿用现行默认值；超时不证明外部未执行 |

流程 requiredCapabilities 必须包含 mcp-tool-v1。流程引用仍遵循顺序、分支、循环作用域，不增加任意表达式或动态工具名称。模型不能声明新的连接、程序、凭据、能力或工具。输入尺寸和服务 Schema 的可支持范围在调用适配器接入前按固定契约补充，未能校验时不得执行。

## 方案与本机绑定

选择页核对原始定义；生成前的完整内容预览显示实际将发送的所选工具，未选工具、连接地址、程序参数、认证引用和登录态不自动发送。工具 Schema 与描述按外部数据处理。

生成前、凭据等待后、模型回复及采纳前再次核对任务、连接修订、能力摘要和所选工具集合。返回方案只允许对应 target/tool 组合；结果含其他工具必须拒绝，不能静默替换。方案卡和编辑器显示工具原名、逻辑目标、参数值/来源及输出引用，读写声明只标成服务声明，不作为无副作用保证。

采纳时把所选目标及定义复制到本机 FlowRecord，纳入流程摘要；同一节点修改参数、目标或工具均需重新检查。任务选择改变后不得沿用旧提案/准入凭据。可移植流程只有逻辑目标，导出不携带本机连接证明，重新导入后需重新绑定。

## 调用与结果的后续门槛

本版本定义节点输入格式，不发布新的执行结果封装或宣称调用能力可用。执行适配器接入前必须固定：支持的输入 Schema 子集与深度/字节限制、解析后的参数校验、工具响应类型/尺寸及输出引用形状、固定 Run 绑定、一次尝试的持久化与结果未知处理。上述缺失时执行入口保持不可用，不返回伪成功结果。

最终真实调用按任务工具规范完成；工具 readOnlyHint 等声明不能替代影响核对，未知结果不自动重试，返回链接、富内容和外部指令不自动执行。主线程、脚本、模型和 Renderer 均不能绕过固定绑定直接传入 MCP 方法或地址。
