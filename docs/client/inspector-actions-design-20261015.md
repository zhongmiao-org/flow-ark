# 2026-10-15 节点检查器操作布局

用户反馈 Excel 检查器长文案按钮相互贴合、主操作与分隔线过近。本轮沿用原 Ant Design 按钮及单套 Semantic Light / Dark 变量，补充[检查器操作与提示](https://www.figma.com/design/sVciNUZHG9yx81gCpYzjH9?node-id=467-5120)，节点 `467:5120`、内容检查器 `467:5122`。这是实施补充规范，原186画板ID及原型连线保持。

## 布局与文案

- 节点类型与上移、下移、复制、删除形成标题区。图标操作保持40px点击区域，彼此间隔8px；空间不足时整组换行。
- 节点ID与“保存后，下次运行生效”放在操作区之前，长ID允许换行。
- 内容区操作使用两列等宽网格，列距/行距12px；宽度不足220px时改为单列。与相邻正文至少16px，客户端采用20px下间距与期限区分开。
- Excel映射的两行为“编辑位置 / AI 修改”“表格配置 / 编辑映射”。映射为主按钮，移到相关配置旁边，不再挤在执行期限下方和文件配置上方。
- 文件和HTTP分别显示“文件配置”“请求配置”；其他现有入口采用“控制配置”“网页配置”“条件与循环”，保持原路由和输入守卫。

## Tooltip 与可访问性

所有缩短文案的入口保留完整可访问名称，并提供 Ant Design Tooltip，支持鼠标悬停与键盘聚焦。提示说明原操作含义；“编辑映射”解释为打开Excel映射编辑器、预览与编辑字段映射。禁用的上移/下移说明当前已在首位/末位；禁用AI说明需要先保存。禁用项通过可聚焦容器查看提示，不解除真实按钮禁用。

未保存原因、错误与恢复说明仍在页面中显示，不把必需信息全部藏入Tooltip。移动、复制、删除、参数校验、运行版本与保存逻辑不改；提示不发起AI或任何运行。

## 设计证据与验收范围

Figma补充稿已实际查看，使用现有 `1:146` / `1:148` 按钮实例、`Label#1:6` 文本属性、Noto Sans SC及原间距/颜色/圆角变量，所有文字和结构可编辑。336px面板、288px内容、138×40px两列按钮，12px间距实际结构已读取；Light/Dark通过同一Semantic集合继承，不创建双套页面。稿中记录Tooltip内容与触发规范，不把说明文字当作已点通的原型浮层。

客户端实施与安装版验收另行记录；设计完成不代表客户端或186张画板完整通过。本轮不新增/运行单元测试，保留类型、构建、格式与人工界面核对。
