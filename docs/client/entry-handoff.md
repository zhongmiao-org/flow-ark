# 模板入口的停止后执行

2026-10-16，BOSS0.2.1已能跨Run保存暂停，但串行执行槽使控制入口排在在途模型后。新增通用入口切换：本人核对明确实例与Run集合后，宿主先撤销该实例活跃及排队Run，确认回收，再创建所选入口的一次固定Run。不能把排队请求或新Run创建称为业务暂停已提交。业务控制Schema、会话键及规则继续归独立模板仓库。

## 通用约束与门槛

[0.30.0](../../contracts/v0.30.0/README.md)先定义语言无关的选择/预览/确认/回执。preview无副作用，确认前要求来源和Run集合相同，只有明确同实例目标；其他实例活跃时拒绝。发出取消不等待旧Run自然完成，也不增加并发Worker槽。旧输出/状态不回滚，实际外部提交未知必须另查。确认回收后再次检查固定来源、当前资源/授权和准入代次，新Run/snapshot/created回执同事务。

请求持久化、同id幂等、不同内容拒绝；同token不能新id重复执行。切换期间暂停新准入与pump，保留其他实例队列。读回执不执行。应用退出/休眠/重开不得自动续跑未完成请求；旧未完成Run按原恢复语义处理。UI按requestId/revision合并，不以旧响应覆盖新回执。

当前G1，须先PR/最新CI自动合并并发布实际contracts-v0.30.0，再由客户端固定采用。G2分别核对类型/构建、受控Runtime/Worker中模型取消后不进入第二模型、原队列/其他实例隔离、重复/失效/故障/重开和原生明暗界面；随后用客户端准确公开BOSS入口实际采用，不改写既有业务Flow或ZIP。当前不新增/运行单元测试。真实Key/本人确认、实际站点来源、完整onmessage、所有招聘外发及G3–G5/186/Agent继续。
