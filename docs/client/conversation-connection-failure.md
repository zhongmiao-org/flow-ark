## 原生复现

隔离空工作区用 UI 保存虚构 Key、创建一个通用 conversation v2 节点、选择显式服务/模型并建立持续会话。生产代码与契约不改写；临时传输适配只允许准确虚构 Key，拒绝所有其他 fetch 目的地，将合成 Chat Completions 请求路由到只监听 127.0.0.1 的 HTTP 服务。实际 Main、Preload、Utility Host、Worker、加密 Store、AI SSE 适配器和 Renderer 组件保持当前构建。原个人工作区和真实凭据未接入，所有内容均为虚构观察资料。

人工控制服务通过真实 HTTP 分开发送 UTF-8/CRLF 帧和终态。首轮甲→乙在原生 UI 按序追加，成功终态前不成为完整历史；第二轮取消仅保留甲，连接关闭后尝试乙和终态未改变已取消记录；显式重试产生第三次独立请求并成功，旧取消尝试不变。第四次中途切换响应身份被拒绝，保留甲并显示身份冲突。第五次在甲后主动断开连接，正确进入 failed，但错误正文仅显示底层英文 `terminated`，没有说明连接中断和下一步。这是本批实际修复点，不把前四项局部通过计为全部 S08。
