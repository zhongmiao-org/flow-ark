## 可视化流程

1. 原资料清单与逐份解析保持；访谈改为持续会话，无总轮次限制，建立/继续后结束本批，不自动使用聊天窗口生成Skill。已有访谈ID和历史不迁移、不重开。
2. 独立“整理与生成草稿”入口读取本人选择的固定完整来源，以本人绑定模型和公开整理规程逐片段整理，每批最多8次。配方改变是新任务，有限批次结束保存后按准确入口继续。
3. condition仅在phase=complete时进入后续，小型脚本只核对完整结果并将markdown/分类数据和宿主proof包装为SkillEvidence，不能签发/伪造证明、调用模型、读取文件或发出业务动作。
4. skill节点创建待确认草稿。正文与结构化内容供本人编辑、试聊、查看差异并最终确认；未知月份、未更新简历的经历或缺乏依据的数值保留待核实，不反复阻塞草稿或补造事实。
5. 原确认版本、手工修改和BOSS绑定不自动替换；完整增量合并及新版显式采用仍按长期计划独立推进，不把首版草稿当作更新闭环完成。

整理规程沿用已固定的nuwa-skill本地语料/证据/判断规则/表达DNA与诚实边界方法，只分析用户选择的材料和本人访谈；助手建议不自动成为本人事实，后续明确更正取代旧说法。按岗位与问题类别给出简短事实回答、待确认或转本人，不冒充看过题、不固定否认AI身份。全部逻辑归独立模板，不进入客户端。
