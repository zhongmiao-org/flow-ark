# 第一次实操与学习进度

2026-09-22。对应 Figma [第一次实操 23:2106](https://www.figma.com/design/sVciNUZHG9yx81gCpYzjH9?node-id=23-2106)、首页的继续教学卡片和侧栏重新学习入口。四项学习内容为选目标、看方案、试一次、找结果；执行步骤仍为打开网页、读取标题、非空检查、保存文本。教学进度不表示执行成功，不替代真实模型或 U12 用户验收。

## 页面与真实任务

教学介绍使用原稿 400 / 728 两栏、24 间距、690 最小高度，复用全局字体、变量、卡片和按钮；窄窗纵向延展。首页“跟着示例做一次”和侧栏“重新学习”打开介绍，打开本身不清空进度或创建任务。第一次开始才创建普通 AI 任务草稿，默认需求为读取明确选定网页标题、空标题提醒、在用户所选目录新建文本、同名自动加序号且不覆盖。示例地址提示为 https://example.com，仍须用户点击打开并明确选择；不在启动或继续教学时导航、读取网页、发送 AI 请求或运行流程。也可输入用户自己的 HTTP(S) 网页。

复用描述、网页来源、[理解与输出选择](task-output-selection.md)、模型发送核对、补问/方案、运行检查及可读结果页面。理解页要求先选择教学输出目录，支持文件名、同名序号或明确覆盖，再核对发送内容。采纳直接使用宿主保存的目录绑定，无须手动编辑流程资源。无 Key 时保留原任务进入配置后返回，模型生成失败保留草稿；教学不使用伪造模型结果或另一个执行器。继续同一任务，不另外复制流程或 Run。跨重开网页旧身份失效时仍须重选，学习记录不能恢复执行授权。更换需求后仍按真实任务检查；原稿的练习步骤是教学说明，不当作已经采纳的可执行流程。

## 本机进度与接口

宿主以现行加密 documents 表保存 `learning/first-task`，版本 1，无 SQLite 迁移。字段：`revision`（初始 0，实际写入递增）、`status`（new/active/skipped/completed）、可选 `attemptId`、`taskId`、`updatedAt`，以及 `achieved` 的 target/plan/trial/result 四项。各项记录时间和真实来源：selectionId / flowHash / runId / runId+artifactId。Renderer 不提交已完成标记。task/flow/run 协议与公开契约 0.12.0 不变；学习记录不进入模板、模型请求或流程导出。

新增严格白名单本机 IPC：

- `learning.status {}`：只读返回进度、当前任务是否存在，以及该任务最近一次显式试运行标识。无记录返回 new/revision 0，不隐式创建数据库记录。
- `learning.start {revision, mode:continue|restart}`：CAS 核对修订。continue 保留已有任务/阶段；没有任务的首次开始在一个事务内创建普通任务与学习记录。已有任务缺失时拒绝继续，明确重新学习才创建新的任务。restart 保留旧任务、流程、运行、文件和产物，以新 attemptId/taskId 开始四项空进度。旧教学任务仍生成中或有未终结运行时拒绝重新学习，不能丢失活动归属。返回新进度与 TaskDetail；不发模型请求、导航或执行。
- `learning.skip {revision}`：CAS 写入 skipped，保留任务与学习证据；未开始可直接跳过。不会取消、暂停或继续任何运行。已完成记录不退回未完成；再次学习须显式 restart。

CAS 冲突返回错误并要求刷新，重复/并发开始最多创建一个新任务。取消界面、返回首页和打开介绍都不算跳过或重新开始。继续学习的持久状态与页面内未保存输入分别处理，保存失败留在当前页面。

## 进度证据与原子性

- 选目标：本任务成功确认真实网页来源时记录第一项，和选择保存同事务；预览/地址输入不算完成。
- 看方案：本任务已选网页并实际采纳可执行方案时记录第二项，和采纳草稿同事务；生成中、失败、未采纳或拒绝不算。后续修改/撤销不删除已经学习过该操作的记录，也不让旧学习证据成为运行许可。
- 试一次：本任务通过运行检查确认并持久化带 task 引用的真实 Run 时记录第三项，和运行及去重记录同事务。只说明已明确尝试，排队、失败、取消和成功仍按真实运行状态展示；预览或普通 flow.run 不冒充此确认。
- 找结果：用户请求真实文本产物预览，宿主验证副本完整性、归属教学任务的 Run 已 SUCCEEDED，并取得实际非空文本后记录第四项及完成。不能仅凭 Run 成功、文件名、打开结果页或 Renderer 的布尔值完成。异步预览期间重新学习/跳过/产物变化不得将旧回执计入新任务；已清理、篡改、不可读或非文本产物不算完成。

每个学习事件只记录一次，后续学习不污染上一轮或下一轮。跳过期间如原任务继续完成真实操作，可保存同一轮证据但保留 skipped；显式继续后依据已存在第四项恢复 completed，否则 active。已完成状态和历史来源跨重开保留；删除/清理产物不撤销曾完成的学习，但当前文件可用性仍据实显示。写入失败回滚相关事务，不返回虚假学习成功。应用启动不隐式重放、补发 AI 请求或补跑 Run。

## 必须验证

严格 IPC、初始只读、开始/重复点击/CAS 并发、事务失败无孤立任务、跳过与继续、重新学习保留旧记录、活动任务拒绝重置；网页预览不能推进、确认和采纳按证据推进、拒绝/撤销及无关任务不误计；真实运行确认与失败状态区分、真实文本预览才能完成、迟到预览/重启/清理不误记新轮；UI 四项与实际证据一致，原稿尺寸和窄窗无横向溢出，模型配置返回、跳过/跨重开继续/重新学习及无自动外部动作。GUI 验证严格串行，启动前拒绝已有 FlowArk/Electron 主实例，自己退出后才重开。
