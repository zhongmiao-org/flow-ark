# FlowArk AI 流程开发章程 v1

日期：2026-11-06。状态：实施中，未发布；适用于内置AI、外部MCP Agent与手工工程开发。用户批准本章程，共用正式工程格式、编译器、运行宿主及打包器。

## 职责与阶段

Skill提供方法，MCP提供工具，编译器检查结构/绑定/引用/类型/能力声明，宿主管理权限/不可变快照/动作回执，用户确认事实和业务意图。Skill不授予权限；静态通过不代表业务完成。

统一阶段：需求 → 节点规划 → 节点实现 → 校验组装 → 运行核验 → 打包复导。需求记录输入输出、目标、不可改内容、终点和授权；规划展示条件、串行循环、节点输入输出及资源。简单任务不逐节点重复确认，已有授权持续有效。

优先现有Excel/浏览器/桌面节点。AI仅实现必要脚本，不虚构SDK或要求普通用户安装Python；稳定区块ID保留，调整需求仅改受影响节点。组装器生成Mermaid、绑定、路径、Schema引用及公开清单，调用正式编译器；手工编辑通过同一检查。

## 强制边界与正式接口

随安装包发布同版本Skill、SDK、节点目录、Schema和MCP说明。源码与运行节点格式分别提供。plan/get/code/assemble采用修订检查；草稿不可执行，代码齐全且正式编译成功才原子提交。诊断返回code/file/entryId/nodeId/field及准确可得的行列；没有位置时不编造。

脚本校验包含JS/TS语法、SDK类型及导出形状；类型检查不执行用户代码，不读取用户工程外的配置或系统环境。动态定位、消息和保存结果另以Run回执核验。内置AI只使用分阶段规则，删除要求直接批量拼写完整工程的冲突指令。

UI展示阶段、节点进度、诊断及下一步，支持对话调整。通用规范归客户端，站点/业务规则归独立模板；内置开发Skill不计为用户任务。

## 修复、上下文和预算

局部修复具体诊断。连续三次相同诊断且无工程/草稿/代码有效进展时暂停自动循环，保留现场，用户调整方案后可继续；只读查询或重复提交相同内容不算进展。完整审计保留，模型优先读取当前规划、最新节点代码及相关规范，历史大正文显式引用而非重复发送。

代码重试与业务动作重试分开。当前开发重试授权继续有效；动作前持久唯一意图，unknown先核对，不自动重发。原生performed只证明输入，业务结果独立核对。运行固定代码/配置/绑定版本，编辑只影响下一Run。

开始前显示模型、发送范围和预算；静态检查不调用模型。API Key产生的费用由用户自行承担。
