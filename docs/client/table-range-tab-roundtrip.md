# 表格范围读取的显式导航准备

2026-11-11，真实多维表格只读验收确认：单击首格后直接 Shift+Down 未扩选；单击后 Tab、Shift+Tab 返回原格，再 Shift+Down 能选择第1至2行，底部显示2个单元格。该结论仅用于已核定目标，不泛化为所有网页。

范围读取请求新增可选 selectionPreparation: "tab-roundtrip"。仅显式传入时，键盘范围选择在 anchor 点击后执行 Tab、Shift+Tab，再按原协议扩选与复制；缺省行为不变，drag 与此策略不混用。每个动作使用独立稳定effectKey、重新观察，失败停止不重放。策略只导航，不输入、粘贴或保存，调用方必须先确认目标格没有待提交编辑；任何导航可能产生提交的其他站点不得选择此策略。最终仍必须校验实际复制矩阵的严格行列与内容，不能用按键回执代替。
