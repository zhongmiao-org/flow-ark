# 流程结构编辑与撤销

2026-09-20。落实[产品参考](product-reference.md)中的流程修改体验，保持现有节点、分支、循环和不可变 Run 语义，不新增公共契约或数据库迁移。

## 编辑语义

- 动作库继续支持主流程、条件成立/否则分支和循环体末尾；选择节点前或节点后时明确显示锚点。连续在后方添加时跟随最后插入的步骤，保持添加顺序；删除锚点后要求重新选择，不静默落到主流程。
- 复制插入到原步骤后；条件/循环连同子树复制，每个新节点均有独立 ID。子树内的单键 `$ref` 输出引用映射到对应新节点，外部前序输出与 params/item/index 保持原引用；普通字符串、代码、文件名和选择器不做文本替换。不会自动执行复制的动作。
- 上下移动限定当前分支，边界禁用；移动到其他位置通过明确目标完成。不能将节点移动到自身或后代中。移动和删除若新增输出引用缺失或作用域越界，拒绝变更并显示具体引用；不要求尚未填完的其他节点配置先通过完整运行校验。保存/运行仍使用原有完整校验。
- 撤销/重做作用于当前打开流程的内存草稿，覆盖结构、参数、代码、浏览器和本机绑定配置，并恢复选择。一次连续聚焦输入合并为一次编辑；切换控件或执行结构命令分开记录。最多保留 100 次编辑。打开另一流程或重新进入时重建历史，保存不清空历史，撤销保存过的内容后需要再次保存。
- 工具栏显式提供撤销/重做；快捷键仅在编辑器且不在输入框、Monaco、可编辑内容或内置网页中时接管，文本编辑沿用原生撤销。撤销不撤销网页操作、文件副作用、已保存计划或已开始的 Run；历史不写入数据库、导出包或日志。

## 验收

纯函数行为验证复制子树 ID/内部与外部引用、字面量不替换、同分支/跨分支插入移动、非法引用拒绝、锚点删除、历史分组/上限/重做失效和流程隔离。真实桌面用本地复杂表单从界面添加与调整动作，撤销/重做后保存重开，再逐步执行并核对结果；调试快照创建后的草稿编辑不得改变该 Run。验证最窄窗口与网页同屏，输入框快捷键不误触结构历史。

测试只使用内置浏览器和本地虚构数据；复制、移动、撤销本身不得产生 Run、网页提交或其他执行副作用。所有实现与安装结论以[验收记录](acceptance.md)为准。
