## 工程与契约

普通安装包提供开发入口、CLI与stdio作者MCP，共用工程编译器和原运行宿主。Mermaid按稳定区块ID绑定节点JSON及JS/TS；支持顺序、条件、嵌套和显式串行循环。不执行配置中的代码、不推测任意图环语义。UI和源码双向保存，修订冲突不覆盖；Run固定快照。

工程v1：`flowark.project.json`声明身份、入口和公开文件；`flows/`为Mermaid，`nodes/`为完整节点及绑定，`scripts/`为JS/TS，`config/constants.json`为只读公开常量，`config/defaults.json`为公开默认值，`schemas/`为配置/入口/结果，另有prompts、assets和README。`.flowark/`与真实env为本地资料，不进入ZIP。

配置优先级：公开默认→实例→显式开发profile（JSON后env）→本次配置覆盖。入口input独立；常量不可覆盖。对象递归合并、数组替换、null遵循Schema；env只读取工程声明的变量，严格转换，不读取父目录或整个process.env。密钥仅保护存储及引用，不允许env明文降级。外发权限不由配置自动授予。公开包只收录白名单且禁止本地资料。

开发接口v1：规范/能力读取、项目创建/打开/读取、按修订批量修改、配置解析、校验、构建、预览、运行核对/请求、状态/结果/取消、ZIP打包/检查/转工程。UI、CLI、MCP与内置AI共用同一服务，不暴露任意宿主IPC或数据库。工具返回文件/入口/区块/字段诊断。项目路径由本机配对授权，调用不提升授权。运行、凭据及效果继续使用既有宿主；unknown不重放。
