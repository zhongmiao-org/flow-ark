# 可选内置浏览器

2026-09-18：0.1.6 的独立网页窗口已通过复杂表单与安装验证，但实际显示入口仍有会话退出问题。用户进一步明确：所有测试使用内置浏览器，先不测试 BOSS；网页必须通过右上角按钮显示在主窗口右侧面板。0.1.7 已实现以下面板方案，验收证据见 [开发预览验收](acceptance.md)。

## 模式与隔离

本机 Chrome/Firefox/Safari 保持原驱动和绑定，当前不执行兼容测试。内置模式仍使用固定 ID `embedded`，但由主窗口持有独立 `WebContentsView`，网站运行在隔离 Renderer 中。宿主经受控系统能力接口管理租约；通用流程和 Worker 不接触 Electron 对象。原实验性 Playwright Electron 子应用移除，避免另开网页窗口和单独应用的生命周期问题。

自动化使用该网页 WebContents 的 `debugger` 传输和固定 BrowserDriver 命令，不开放网络调试端口、不控制工作台页面。定位与表单逻辑放在浏览器适配器，不进入 Main 的业务编排。后台禁用页面节流；窗口隐藏与恢复不销毁页面。新页面留在受控面板中，不能弹出外部浏览器。

远程页启用 sandbox、contextIsolation、webSecurity，禁用 Node、webview，且无 preload；不给网站提供工作台 IPC。专用 Profile 保存登录态，不复制用户日常浏览器资料。网页导航只允许 HTTP(S)，阻止本地文件、应用协议及外部程序唤起；新窗口仍用同一受控安全配置。自动下载必须有当前下载命令，下载文件归对应 Run。

## PC 网页宽度

2026-09-20 用户要求内置浏览器按 1080p 标准宽度显示。网页布局视口固定为 1920 CSS 像素（默认网页缩放 100%），与工作台右侧面板的物理宽度分离；使用 Electron 的桌面视图模拟和等比显示缩放，不伪装移动设备、不修改网站 CSS。面板变窄只改变显示比例，页面高度随面板可视区域换算，以利用纵向空间。该设置降低响应式窄屏布局的影响，不代表所有 PC 网站均已验证兼容。

网页初建、导航、收起/恢复和后台新建都应采用同一桌面宽度。缩放、面板位置及原生点击坐标必须正确换算，覆盖普通控件、嵌套跨源 iframe 和拾取拦截；显示变化不刷新网页、不改变租约、已填内容或执行状态。截图继续记录实际网页视口，不承诺页面总高度或物理 1920×1080 PNG。界面标明“桌面宽度 1920”，不要把面板物理宽度显示成网站布局宽度。

验证以实际 `innerWidth`、媒体查询和布局结果为准：不同窗口尺寸均保持桌面布局，恢复后会话和表单内容保留，真实原生点击、拾取、自动化、后台截图分别通过。仅本地复杂表单及隔离测试页面；BOSS/智联继续暂停。

## 生命周期

窗口最小化或收起时关闭页面后台节流，并隐藏原生网页视图；显示面板由用户主动操作，不因下一步运行抢焦点。页面等待登录或验证码用原有等待人工节点与待办，用户完成后继续。一个会话同一时刻只租给一个 Run；显示/收起不改变租约、重开页面或重放动作。

取消、超时、会话丢失、显式退出销毁对应网页 WebContents 并拒绝未完成命令；外部浏览器仍回收受控进程树。网页失效必须通知宿主并建立待办，不能保留看似可继续的人工等待。应用正常驻留可继续执行，显式退出后不能运行。系统休眠会中断执行条件，不能承诺合盖或休眠仍工作；收到 suspend 事件应停止当前 Run，恢复后核对结果并由用户发起新 Run，不自动重放。不自动启用阻止休眠或开机启动。

macOS 在窗口已最小化时创建新 WebContentsView，可能没有可截图的绘制表面。0.1.7 在后台截图期间将同一网页短暂移入始终隐藏、无 preload 的绘制宿主，完成后移回右侧面板并销毁绘制宿主；不打开另一网站、不改变 URL、租约或执行内容，不显示窗口或抢焦点。原生截图记录当前网页视口，不承诺整页长截图。取消仍销毁网页，不为截图复用已失效的会话。

2026-09-20：截图绘制宿主必须绑定到具体网页视图。取消可以先结束 Run、销毁网页，底层截图 Promise 随后才返回；这段清理时间不能阻止新网页布局或显示。旧截图完成只释放自己的宿主，不移动新截图中的网页；关闭当前网页须从它实际所属的主窗口或截图宿主移除。此项只调整 Main 内部资源归属，不改变截图动作、页面租约或流程协议。

## 本地 IPC 与兼容

公共流程仍用契约 0.7.0 和 browser v1/v2/v3，无节点语义变化。只新增本地 IPC `browser.embedded.enable`（无参）、`browser.embedded.visibility`（visible 布尔）、`browser.embedded.status`（无参）；系统窗口事件使用宿主内部接口。启用只创建本地绑定；打开面板可创建空白网页，不自动运行流程。新增 `browser.embedded.viewport` 仅接收主窗口内的整数矩形，Main 限定边界；`browser.embedded.navigate` 仅接收 HTTP(S) URL，活动执行期间禁止工具栏导航（暂停/等待人工可手动接管）。内部创建、执行、关闭和会话丢失方法不进入 Renderer 白名单。状态只返回已启动、显示状态、当前页面 URL 与标题；不返回 Profile 路径、Cookie、凭据。绑定使用现有浏览器存储，无表结构迁移；0.1.6 专用 Profile 与新面板 Session 分开保留，不在未经验证时拷贝 Cookie 或声明登录继承；旧客户端不认识 embedded 时拒绝执行，不转换成本机浏览器。

## 验证关口

- 完整复杂表单：input、radio、checkbox、原生/自定义 select、多选、日期、按键、延迟控件、上传字节与服务端回执。
- 最小化与隐藏窗口时连续执行、定时页面更新和下载，核对无新窗口抢焦点。
- 调试暂停、单步、取消、销毁后重开、Profile 登录态保留、旧 Chrome 绑定兼容。
- 远程页无 Node/FlowArk 桥；新窗口、非 HTTP(S) 导航和无命令下载的隔离。
- suspend 通知与退出停止任务，不继续后续提交；实际电脑睡眠另列，不将模拟系统事件称为硬件验收。
- 打包、从 DMG 安装、安装版同一回归；BOSS 登录和实际招聘行为另验。

`pnpm test:embedded-capture` 在完整隔离客户端中延迟真实原生截图的异步返回，依次验证取消后新网页显示、旧截图待清理时关闭新网页、两代截图清理隔离、移回面板与截图像素；取消 Run 不出现迟到产物或后续节点，不提交表单、不弹出额外窗口。设置 `FLOWARK_TEST_EXECUTABLE` 可针对 DMG 候选或安装应用验证，测试始终使用独立临时数据；具体版本结果见 [客户端验收](acceptance.md)。
