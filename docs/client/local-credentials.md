# 通用本机凭据 v1

2026-09-23。落实 Figma 凭据与本机资源 `2:3227` 的通用凭据编辑。此接口独立于 [AI 配置](ai-settings.md) 和 MCP 认证，不恢复已移除的 credentials.set。公开流程、SDK、模板包与 SQLite 表结构不变；本机接口与客户端同期采用。按当前用户要求，先完成 UI/UE，单元测试后置；下列边界仍须实现，未验收部分不得记为通过。

## 身份与存储

通用凭据 ID 固定为 local- 加 UUID，由新建表单一次生成，重试不更换 ID；显示名称支持 Unicode，去除首尾空格后 1～100 字符。名称不是文件名或权限标识。凭据值为 1～8192 字符，不修剪实际内容；禁止空字节。名称与值一起写入带 kind/version 的系统保护记录，仅存放在凭据目录。修改使用当前密文字节摘要 revision 比较后原子替换；不存在时 revision 为 null。系统保护不可用、读取或写入失败均明确失败，不能明文降级或覆盖其他命名空间。

AI 供应商、mcp- 工具认证与 data-key 不属于通用凭据接口。已保存值不返回 Renderer、不可复制或回显，仅显示固定掩码。替换留空保留原值；首次保存必须提供值。保存成功、关闭或放弃清除本次输入；失败保留当前输入供修正。列表和 bootstrap 只提供 ID/名称等非密钥摘要，参数绑定可显示名称，但持久化仍使用 ID。

## 本机接口

- credential.local.list：无参数，返回已配置条目的 id、name、revision、boundFlows（ID/名称）与 inUse。不得包含密钥、密文或本地存储路径。
- credential.local.save：id、revision（可为 null）、name、可选 value。保存名称/值，不联网、不创建 Run、不自动绑定流程。
- credential.local.remove：id、revision、confirmed:true。只删除所选本机记录，不撤销外部服务授权、不删除流程、运行或产物。已保存流程仍引用时拒绝，先由用户在对应流程移除绑定。

Main 内部读取/比较写入/删除与执行时密钥读取不进入 Renderer 白名单。错误不包含输入值或底层凭据内容；本次输入和解密值加入既有脱敏集合。创建/替换/删除响应不回显值。

## 使用与并发

Host 按 ID 互斥修改。活动或排队 Run 的固定快照引用该凭据时禁止替换/删除；历史终态快照不阻止本机清理。应用退出、休眠、宿主存储故障或执行资源回收未确认时禁止修改。准备执行时同时捕获 AI 与通用凭据修改代次，在异步资源检查后、进入运行队列前复核，避免读取旧资源后绕过修改保护。Worker 仅能读取自己固定快照中明确绑定的 ID。

新建 ID 已存在或 revision 冲突时拒绝覆盖。提交结果未知不自动重新保存：用户可刷新列表核对同一 ID；重新读取不会将本次明文输入传给其他记录。执行历史、已保存流程与不可变快照不因凭据编辑而被改写。

## 页面与验收边界

凭据列表、编辑和移除核对使用统一设计变量；AI/工具认证有各自管理入口。新增/替换在独立模态表单中填写名称和密码框，未更改可直接关闭，有更改提供保存并离开、不保存离开、继续编辑；系统保存失败停留并保留输入，保存中冻结操作。模态框阻止背景导航，Escape 使用同一离开检查，关闭恢复触发按钮焦点；编辑或移除期间改变窗口尺寸后，返回还须使原按钮位于可见区域，不能仅恢复视口外的逻辑焦点。继续编辑恢复最后编辑的名称或凭据值字段及其选区/光标位置，不统一跳回名称。名称和值在发送前使用同一共享Schema校验，中文内联原因通过aria-describedby关联输入，首次与重复提交定位第一个无效字段；修改该字段撤下已过期的校验提示，不抢走输入焦点。其他保存失败仍使用总提示并保留草稿；已有凭据只改名称时不携带value字段。移除核对展示依赖流程和当前使用状态，只在允许时明确确认。

后续完整验收须覆盖严格接口与命名空间隔离、系统保护真实读写/原子性/失败、修订冲突、空替换与明文不回显、引用及在用保护、异步准入竞态、显式绑定后执行读取、删除与历史保留、来源返回及窗口布局。隔离 UI 模拟不能代替真实系统保护和运行验收。
