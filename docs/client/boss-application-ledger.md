## 数据与边界

实例stateSchema追加可选applicationIntents，公开默认空数组、最多500项。旧conversationControls及replyIntents逐字节保留，所有写入保留其他根属性。每项严格对象，字段为：

| 字段 | 语义 |
| --- | --- |
| key | 稳定投递意图SHA256；由动作域、账号可见来源摘要和职位身份计算，不包含日期、批次、配置、Skill、材料或本地账号别名 |
| accountSourceSha256 | 已确认并重采一致的必要可见账号来源摘要；不是平台唯一账号ID |
| jobId / jobSource | 实际独立职位路径身份和无查询/锚点的HTTPS来源 |
| jobSourceSha256 | 本次核对的完整岗位来源摘要 |
| resumeSha256 | 本次固定完整材料摘要，不接受文件名冒充 |
| profileVersionId | 本次固定的已确认Skill版本 |
| configurationRevision | 本次固定共享配置修订，非负整数 |
| batchId | 本次有限批次身份，不参与去重 |
| day / timeZone | 明确时区中的额度日期 |
| createdAt | 真实预留ISO时间，必须与日期/时区一致 |
| status | reserved、confirmed、failed或unknown；已有任何状态都阻止同岗位自动重提 |

空缺applicationIntents才按空数组处理，显式null、错误字段或损坏记录不能被当空。全量检查字段、摘要、稳定键、职位路径、日期与预留时间，重复键/未来日期/容量满停止并通知，不清库或自动扩容。500项是当前有限实现边界，后续归档须另有不丢去重证据的明确设计；没有归档时满额停止。

账号别名不参与摘要；姓名/手机号掩码/求职者入口等必要来源变化时，不能自动建立空账本。已有其他账号摘要或不同时区时暂停，交本人核对，不自动迁移或按新别名重置。当前可见来源仍不能证明平台唯一身份，多个实例或外部手工投递的全局额度尚不由本实例账本证明。

当日confirmed、reserved、unknown、failed分别展示，当前都计入本地额度使用，不因失败或未知自动退额。所有日期的同岗位意图继续去重；未解决reserved/unknown转本人，重开不执行或重发。批次结束、剩余额度0、记录满或本地计数150都不能设为当天完成。

实际预留必须在完整Skill/事实、匹配判断、当前账号/城市/岗位和固定材料复验后，使用最新状态修订CAS写入。任何CAS冲突停止、重新读取而非重放提交；动作准备与网站提交、站点回执和最终状态分别编排，不能把写入回执算作投递成功。当前先接账本结构与读取门槛，实际预留、effect/提交/回执和跨批仍待后续接通；不以缺少最终Skill或本人确认为由伪造资格。
