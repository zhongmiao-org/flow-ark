# 模板实例编辑与离开保护 v1

2026-09-22。落实 [模板实例设计](design-p1-review.md) 的共享配置、资源与动作授权、操作入口及 [导航规范](design-navigation.md)。客户端为未正式发布的开发版，不保留旧客户端的无修订写入接口；公开模板包 2.0、SDK 1.0、流程契约 0.12.0 及 SQLite 表结构不变。

## 实例草稿与来源

每个打开的实例维护一份已读取基线和一份本地草稿，包含实例名称、共享配置、资源、动作权限及各入口输入。页内标签和当前实例的入口切换共享草稿；打开 AI 设置或系统资源选择器是子任务，保留草稿。真实业务字段仍来自包的 Schema，不由客户端硬编码。

离开实例、切换实例、顶部返回、祖先面包屑、侧栏和应用内返回快捷键使用同一守卫。只有实际未保存变化才提示保存并离开、不保存离开、继续编辑；保存失败保留输入、所在页和原目标。保存中阻止重复操作，继续编辑恢复原焦点；放弃恢复基线，不改之前的 Run、快照或计划。设置子任务内的 Key 守卫独立处理，密钥不进入模板草稿。

原实例/包/入口丢失或变化时不能按名称寻找替代对象。可以重新读取权威状态，明确放弃本地草稿后恢复；不能从有来源冲突的入口绕到共享配置页继续使用旧基线保存。

2026-10-13 入口归属补充：模板流程的编排工具栏、参数侧栏及本地设置的流程资源入口都应打开绑定的精确实例/操作入口，不进入普通流程参数编辑器。导航前处理编排草稿，读取时核对instanceId、packageKey、entryId与flowId，缺失或变化留在原页。返回编排重新读取已保存流程，再恢复入口焦点；从设置进入则返回设置。 设置的“配置资源”直接定位同一实例的资源与动作授权分类，并保留对应entryId供操作入口往返；编排中的参数入口仍打开对应入口输入，不把两种操作混为同一初始分类。实例页仍沿用自己的统一离开保护，不把侧栏导航误当返回编排。宿主flow.save拒绝直接改写模板入口参数或来源表达式，图编辑可以保存，参数仍只经template.save及对应Schema/修订校验；固定Run和计划不变。本增量不新增IPC字段或SQLite迁移。

## 本机接口

`template.detail({id})` 返回现有实例、清单、Schema、各入口输入/可用性，并增加 `revision`。修订为当前实例记录及全部入口流程记录的 SHA256 摘要；包括名字、输入、图与绑定的实际内容，缺少入口记录明确计入摘要。仅创建、编辑或移除与该实例相关的记录会改变修订；运行事件和独立运行快照不改变它。摘要不是凭据或文件内容的导出。

使用严格 `template.save` 替代旧公开 `template.configure/template.input`：

| 字段 | 规则 |
| --- | --- |
| id | 实例 ID |
| revision | 必填 64 位十六进制预期修订 |
| name | 去除首尾空白后 1–100 字符的实例名称 |
| configuration | 该包共享配置 Schema 的完整值 |
| resources | 当前完整逻辑资源绑定，不能引用包外资源 |
| grants | 当前完整动作授权；未提供的声明动作仍为 deny，不能引用包外动作 |
| inputs | 仅包含此次要保存的入口 ID → 完整输入值；空对象允许只保存配置。未知入口拒绝，逐项按对应 Schema 验证 |

Renderer 不提交清单、流程图、包版本、凭据值、运行 ID 或内部记录。资源沿用已有本机绑定结构及能力边界，不因为保存或选择路径而获得动作授权。所有普通值沿用现有 IPC 尺寸与 JSON 限制。

Host 按模板写操作串行处理，在读取包并完成全部 Schema/资源/动作验证后，再于一个同步事务内复核修订并保存实例及所有受影响流程。修订不匹配、来源缺失、校验或存储失败时整个操作失败，没有部分配置或部分入口输入落盘。没有流程记录的入口不可被保存隐式重建。普通实例名称修改同步其入口流程的显示名，保留已有步骤图；指定输入之外的其他入口参数不变。

入口输入单独保存成功时，界面反馈注明对应入口名称；切换到其他入口后，仍能辨认此前成功回执的归属，不能把一个入口保存成功呈现为其他未保存草稿已保存。

成功返回已保存的完整 detail 与新 revision。单独保存共享配置/权限时可以不提交其他未保存入口输入；保存入口时可以使用已保存实例字段。统一保存并离开须将全部未保存配置和输入放在同一请求中，成功后才导航。共享配置与输入编辑造成的图/绑定变化不改变既有不可变版本、排队/活动 Run 快照、计划或历史产物，不创建运行。

保存回执丢失时不静默重放写入。保留草稿并提示重新读取；新修订不能被旧请求覆盖。当前接口不声称支持跨进程任意数据库写入，也不把文件选择返回等同于路径可用性或运行准入。

## 验证要求

分别验证严格 IPC、旧接口拒绝、未知入口/资源/动作、非法 Schema、两个旧修订竞争、读取包期间另一处改动、事务故障零部分写入、名称及多个入口原子更新、未指定输入保持、旧 Run/版本/计划不变和重开不执行。

界面验证标签共享草稿、切换实例/侧栏/返回/快捷键的三种离开选择、保存失败与焦点、取消资源选择、来源冲突跨标签仍阻止写入、AI 往返、三尺寸与标准 ZIP 回归。原生文件选择、真实 AI、安装运行及用户验收独立记录，规范不表示实现完成。

## 2026-09-22 入口运行、调试、计划与结果

入口的运行、逐步调试和创建本机计划使用同一已保存实例/入口来源。存在本地未保存值、未完成的原始字段、来源冲突、当前入口缺少能力/资源或动作未授权时阻止启动；与当前入口无关的资源不阻止它。调试沿用宿主首步暂停、单步/继续/取消，不写回流程草稿或自动授予权限。不可计划的入口禁用创建计划并显示原因。

本机 `flow.run` 和 `schedule.save` 增加可选 `templateSource`：严格对象 `{ instanceId, entryId, revision }`，ID 沿用现有本机长度限制，revision 为 `template.detail` 的 64 位 SHA256。模板实例页面必须提供该来源；普通流程入口不提供。不允许在该对象夹带流程、输入、资源或凭据。Host 在捕获入口记录时以及异步准入完成、发布 Run/版本/计划之前再次同步核对：实例存在、完整修订一致、入口映射到请求的 flowId、记录的模板绑定与实例/包/入口一致。任一变化拒绝且不创建新 Run、快照、版本或计划，不按名称寻找替代入口，也不隐式保存。计划计时与执行仍复用现有间隔分钟、时区、固定版本及 schedulable 校验。

创建计划是独立的本机计划页面，明确显示来源实例/入口及固定的已保存内容，默认间隔 60 分钟，时区来自系统；用户确认固定该版本后再显式创建，初始启用且首个触发在间隔之后。打开、取消或返回不创建计划、不创建 Run；保存失败/来源改变保留表单，重复点击及迟到回执不重复创建。离开有更改的计划表单提供保存并离开、不保存离开、继续编辑，保存失败停留；成功后返回原入口或原点击目标。修改实例不会自动更新该计划快照。

运行和调试成功后打开真实 Run 详情，保留来源实例/入口以及返回位置。运行详情/输出页的返回只恢复页面，不取消、重试或重新执行；再运行沿用现有明确核对。最近结果通过当前入口的实际 flowId 查询完整运行历史，不依赖 bootstrap 的前 200 条摘要，不混入其他入口或实例；零记录、读取失败和记录已不存在分别呈现。上次运行仍在进行时描述为运行状态，不假装已有最终结果。来源页面保留草稿；从子页面离开至其他模块仍通过实例草稿保护。

新增验收：严格来源字段、跨实例/入口拒绝、旧修订及异步准入期间改动零落盘；真实首步暂停/单步/继续、运行快照固定和新旧入口结果隔离；创建计划初始零运行、确认/取消/失败/重复提交、不可计划入口与独立资源、三尺寸、返回焦点/滚动和来源失效。本增量不改变公开契约 0.12.0、SDK 1.0、标准包 2.0 或 SQLite 表结构；实现及实际证据另行记录。


## 2026-10-10 · 资源选择返回与字段布局

资源页的文件/目录选择正常返回（包含取消）后，等待原按钮恢复启用，再将焦点恢复到可见的原按钮；仅在焦点仍为页面根部或原按钮时恢复，不覆盖用户主动选择的其他控件。失败继续聚焦原操作错误，保留绑定与授权草稿。清除只是修改草稿，取消恢复已保存绑定，选择资源不自动授予动作权限。

按2:1083缓存稿，资源左Card通过Ant原有styles设置28px留白；资源文件字段采用自身网格，标签跨整行，路径输入与选择/清除按钮同行，避免共享AI表单样式覆盖。输入/按钮沿用集中主题40px，不新增基础控件封装。生产页保留允许范围Select与三项授权按钮，不将稿件状态演示入口加入产品菜单。

实际App加虚构宿主的目录/可选文件取消、失败、成功、授权保存失败/明确重试和入口往返已人工核对，具体证据见实施记录。本条不计真实原生选择器、SQLite持久化或授权执行验收。


## 2026-10-10 · 采用新版后的资源入口

新版实例创建成功提示中的“核对资源与动作授权”属于内容导航：打开该分类后聚焦本机资源绑定标题并将其滚入视口，沿用实例页现有内容定位逻辑。不能只聚焦标签并禁止滚动；长模板名与实例名可能使标签和目标都位于视口外。该导航不保存、绑定、授权或执行资源。

创建成功但读取失败时保留已创建实例回执，明确打开只重读该实例，不重复创建；原实例继续引用原包。实际App虚构宿主核对与局限见实施记录，真实创建/持久化和整板验收仍单独记录。


## 2026-10-10 · 入口详情的只读配置与返回

入口详情中的共享配置显示已保存值，使用Ant只读输入呈现，不提供此处修改共享配置的保存按钮。实例仍有草稿时继续提示并阻止启动，返回配置应保留未保存内容；取消更改恢复已保存基线。0、false、null、数组和对象不能被当成空值隐藏。入口输入与真实执行仍遵循各自契约，不根据入口名称或actions为空推断严格安全只读。

按2:1314缓存稿，详情主卡采用Ant原有styles的32px留白、720px字段、444px最小高度，复杂内容自然增长；普通入口表单保留原布局。返回实例后原详情按钮获焦，资源区展开/窗口尺寸变化不能把仍获焦的按钮留在视口外；用户改焦点后不主动抢回。人工核对与真实验收边界见实施记录。


## 2026-10-13 · 本地资源清单中的模板路径映射

模板的逻辑文件/目录绑定以清单中的资源ID、类型与访问声明展示一次。宿主为执行步骤投影到bindings.files的同名同路径映射，不是第二份目录绑定；设置清单不能重复计数或把模板文件标为目录。无法确认对应关系的普通路径绑定仍独立显示，不据名称猜测、删除或改变实际绑定。该规则仅修正展示，不改变模板保存、资源检查或执行权限。
