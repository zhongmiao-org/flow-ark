## 设计先行

## 现有契约内实现

- 仅在完整脚本页提供“代码编辑 / 纯文本编辑”，默认保留代码方式。两者编辑同一份当前脚本，切换不更改字节、输入来源、依赖、资源或授权，也不新建草稿和Run。
- 纯文本使用有明确可访问名称的标准多行输入，支持选择、粘贴、复制及辅助技术，遵循系统/显式主题。展示当前实际字符数，普通保存、取消离开保护及保存中禁用保持。
- 两种方式调用同一语法检查、预览和保存路径。选中语法错误时能在当前编辑方式定位；模式切换本身不清空已有诊断或输入，也不将语法通过当成入口或业务成功。
- 不新增协议、IPC、持久化字段或招聘逻辑，不降低SDK能力、实例来源、CAS或副作用守卫。原0.2.45缺少human能力仍应拒绝；公共作者入口另行按实际需求声明。私人的本地核对证据不得公开导出，也不能作为新用户的默认材料。
- 不新增或运行单元测试；按阶段执行类型、格式、构建及完整macOS打包，在日常安装版通过UI填入、保存、重新打开核对内容，保持旧记录。随后回到原实例恢复及循环，不把编辑器修复计为150招呼验收。
