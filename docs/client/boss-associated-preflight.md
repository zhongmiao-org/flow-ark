## UI 制作范围

以客户端从公开原始 0.2.4 复制作者草稿，保留其余六入口、共享配置/状态、Skill及资料/AI资源、动作映射和两项提示词。新预检仅使用通用 browser v5/collect 同次采集网址、标题与明确正文登录提示，再由有界脚本整理、条件分流、原两路待办/结果构成五步。字段、输入引用、脚本、入口能力、说明、版本和 ZIP 全部由 UI 维护，不直接写流程 JSON、Store或归档。

只接收契约格式正确、顶层/框架网址一致且属于预期采集字段的观察。标题缺失或字段多匹配等不完整状态只能转本人核对；不能取首项或让模型补值。仅在明确 BOSS HTTPS 页面、当前登录路径或已校准提示确实出现时提示本人登录；提示缺失仍是账号/内容待核验。导航、定位语法、框架或预算等整次失败沿用通用失败 Run，只显示原因，不隐式重试或切驱动。全程 `accountVerified=false`、`eligibleForActions=false`，不将 collector 完整性当作账号、完整JD、会话来源或外发资格。

分类结果只保存去除查询串/片段的 origin/pathname、标题、采集状态及原因，不复制整页正文或链接查询参数到待办；提示的原始文字仍在本机受保护浏览器结果中。待办沿用正式模板 Run 来源及实例内去重键，运行结束释放槽，不等待人登录。当前不调用模型，无额外动作授权、状态写入或招聘外发；此前本人付费重试和暂不登录选择不变。
