作者字段树提供最少项数、最多项数及不允许重复项；高级JSON沿用严格检查。切换字段类型移除不适用规则。公开默认值仍可为空，预览显示不足，不能自动补占位或个人输入；Schema有效与实例值有效分别判断，矛盾范围或非法类型不能保存。

表单校验与宿主采用相同JSON结构相等语义：对象键顺序无关、嵌套数组顺序有关、文本不修剪或大小写折叠。显示首个重复条目的位置，用户修改/删除后恢复；最少/最多提示、资源准入及未保存草稿分开。数组选项枚举同样不能绕过数量/唯一性检查。

上下移动只调整本地值与稳定行键，不改写条目内容；未完成的JSON、数值或字段草稿仍跟随原条目，移动后焦点恢复到该条目。首项上移、末项下移及父表单禁用状态不能操作；增加/删除后边界更新。取消更改恢复基线，离开保护仍区分真实更改和未编辑无效默认值，保存失败不清草稿。排序不创建Run、不自动保存或扩大资源授权。
