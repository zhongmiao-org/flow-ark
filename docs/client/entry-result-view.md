# 入口结果的只读展示

2026-10-17，状态：G0 设计与未发布契约草案。没有本批客户端实现、安装更新或正式契约版本；不能由消费者提前采用。普通用户在 UI 阅读、配置、编排及导出模板，JSON 只保留为可选高级详情与调试工具。模板可复用性仍以原始 ZIP 在独立实例通过 UI 导入、重绑、运行与核对结果为准。

## 现状与目标

已安装候选版将通用步骤结果与上下文按字段展示，并默认折叠原始结构。它尚未提供独立的模板入口整体结果读取。步骤成功、Run 终态、入口保存的值及真实业务结果须分别核对，不能用最后一个步骤或原始 JSON 要求普通用户自行推断结论。

源码核对基于客户端 `c09a0569c48690c08b723df43c886b56b76da8f3` 主线相关路径及现有候选改动：`src/templates/service.ts` 把 SDK 结果存入 template-result，`src/host/author-sdk.ts` 保存 author-sdk-result，而 run.detail 尚无该结果投影。正式完成路径的 `get(...) ?? output` 会把已保存 null 当作缺失；本批仅记录，尚未修正。历史读取不能直接套用依赖当前实例/草稿的执行上下文，也不能降低实际执行准入。

UI 目标是在运行详情显示只读入口结论、固定来源和状态；步骤结果继续独立保留。重新读取只刷新视图，不创建 Run、调用模型、重试业务或授予权限。失败运行即使保存结果也只能表示“已保存”，不可显示为业务成功。普通入口及制作副本分别标识，不混用来源。

## 草案与验证范围

语言无关格式、固定来源顺序、Schema 注解、隐私、异步重读与预算见[草案](../../contracts/drafts/entry-result-view/README.md)。单独放入 drafts，不预占下一个发布版本、不修改既有版本快照，不改变待审来源核对方案。

本机通过已有 AJV 2020 环境和独立纯参考模块核对 73 份正反格式资料及 15 项范围资料，共 88 项：45 个有效、22 个格式拒绝、21 个关联条件拒绝，均符合预期。覆盖 false/0/null/空值、失败终态、跨 Run/版本/来源、标签指针、尾随换行、摘要与范围。临时核对报告位于 `/private/tmp/flowark-entry-result-format-verification.json`；该本机路径不作为公开消费者依赖。

这些是协议格式和关联条件核对，不是应用单元测试或实际宿主来源证明。没有新增或运行应用单元测试，没有读取私有业务正文、调用模型、变更权限、写 Skill 或编辑模板 JSON/ZIP。暂不计并发一致性、历史归属、完整 Schema 解释、实际脱敏、生产读取及所有 UI 矩阵通过。

## 消费者与交付门槛

1. 治理审查、确定正式契约归属与发布版本，经最新 CI 实际自动合并并发布后，客户端才采用。
