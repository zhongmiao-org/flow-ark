# 2026-10-15 UI 库与按钮点击尺寸核对

## UI 库采用范围

实时核对客户端已安装依赖为 Ant Design 6.6.5；根 `ApplicationTheme` / `ConfigProvider` 统一采用 Light / Dark 算法及语义令牌。125 个 Renderer TSX 文件的源码声明扫描发现 730 处 `<Button>`，没有直接声明原生 `<button>`、`<input>`、`<select>`、`<textarea>`。外部 UI 导入为 Ant Design、React Flow、Monaco 和图标；流程图及代码编辑器继续使用专用组件，不代表另一套基础控件库。

Renderer 仍有 72 个 CSS 文件，承担页面布局、响应式、流程图/编辑器、组合内容及语义适配。采用 Ant Design 不以删除全部 CSS 为验收条件；共享样式仍需避免覆盖组件内部运行结构。本扫描仅说明基础控件采用情况，不能推导全部组件行为、186 张画板或完整主题验收通过。

实时读取原流程编排 `1:394` 的 Figma 上下文和截图：工具栏普通操作及“显示网页”均为 40px 高，点击反馈没有收缩要求。本轮不改设计节点、原 186 ID 或公共契约。

## 缺陷与修复

`antd-layout.css` 原 `.ant-btn:has(> div)` 把存在直接子 div 的按钮识别为多行内容，设置 `height: auto`。实际 Ant Design 点击波纹会临时插入直接子 div，导致普通按钮从约 40px 降至 21.8px；该规则是全局的，不仅影响“显示/收起网页”。修复前在实际依赖与共享样式页面中分别点击网页切换和普通按钮，均观察到波纹存在时收缩。

删除任意 div 判定，保留直接 `strong` / `article` 组合内容的自然高度。保留 Ant Design 波纹、组件大小、现有选中颜色及多行卡片，不以统一强制高度掩盖问题。同步修正文件注释，明确其中仍含语义适配。

逐项查看按钮相关 `:active`、`aria-pressed`、`aria-expanded`、`.selected` 与 `:has` 规则，包括编排视图、浏览器模式、模板入口、资源选择、任务选项、字段映射和执行记录展开。选中/按下规则主要改变颜色、边框或阴影；文字展开与多行卡片的自然高度是显式布局。本次未发现另一条由临时波纹匹配而改变尺寸的规则；这不是所有页面任意状态组合已通过的结论。
