# AI 任务执行与可读结果

2026-09-21。依据 Figma `23:3957`、`23:4127`、`23:4283`、`23:4425` 和 [AI 任务验收 U09/U10](design-ai-task.md)，将真实运行事件与产物投影为执行、结果及失败页面。实现证据另记 [实施记录](design-implementation.md)，本文不代表已实现或完成验收。

## 结果事实与导航

复用 `run.detail` 的固定快照、同 Run 事件、宿主执行归属、存储异常、脱敏输出及经过完整性核对的产物。执行进度按步骤实例计算，循环实例分别记录，条件未选分支保持未执行；Run 成功不能推断所有静态步骤均执行。页面显示已完成、已经开始但未确认完成、尚未执行，不能把未知总结为成功。运行终态仍在收尾时保留收尾状态；缺少实时观察、宿主失去归属或存储异常时说明最后已保存状态。

影响依据已开始的步骤和登记产物说明。文件副本存在不证明业务原文件是新建、没有覆盖、没有其他副作用或所有业务结果已核对。可信脚本、HTTP、网页写入等不能由模型补造外发次数或“未改变网页”。摘要显示实际登记及可用文件数；完整输出、步骤实例、原始事件和脱敏日志放入详细信息。

从任务进入执行页面后，返回、打开预览、查看详情、进入修改均不创建 Run。保留原任务身份与返回位置；迟到详情、文件读取或配置回复不得抢回已经离开的页面或覆盖新选择。再次运行仍进入明确检查；失败修复及关联新 Run 遵守现有重跑规范，从头执行，未知副作用先人工核对。普通修改只回到草稿，不自动发给模型或执行。

2026-10-10 结果详情返回补充：返回摘要先恢复原位置，再聚焦打开详情时的文件预览入口；该入口不可用时回到“详细信息”。窗口尺寸变化导致原入口在视口外时，焦点恢复须使入口可见，不能只恢复逻辑焦点。详情中切换所选文件不改变原返回来源，查看与返回均不创建或重放运行。

## 运行对象说明 v1

2026-09-23。`run.detail` 增加可选只读 `targetContext`，由宿主从该 Run 已保存的 Snapshot 投影，不能从当前流程草稿、连接目录或当前网页补齐。无 Snapshot 或流程身份不匹配时省略。该增量不改变公共契约 0.13.0、请求字段、执行授权或 SQLite；消费者在本治理合并后采用，旧记录缺项按未知展示。

返回形状为 `{formatVersion:1,runId,versionId,browser?,files}`。`browser` 为 `{bindingId,product?,page?}`，product 仅取快照中的已核对浏览器种类或明确 embedded 绑定；page 为 `{title,url,source:"selected"|"reviewed"}`，分别取快照所选网页或运行前核对的内置页面。它不是实时页面、当前账号或权限状态。`files` 为当前快照中 file/excel 步骤引用的 `{binding,directory?}[]`，directory 只取同一快照文件绑定；不返回未使用目录、凭据、grants、脚本包路径、认证配置或整个授权对象。所有说明文本经现行秘密值及模式脱敏。

Renderer 只接受 runId/versionId 与当前运行一致的说明。当前对象卡片结合事件选定的当前/下一/最后步骤和固定 FlowDefinition 展示网页选择器、框架路径、配置地址、文件逻辑资源与目录、HTTP 或脚本范围。引用只说明来源，不在 Renderer 求值、读取文件或请求网络；所选网页与实际跳转、动态文件名和脚本影响不能推定相同。排队、快照缺失、未知归属及终态分别保留未知或历史语义。查看对象不触发重试、重连、采纳或新运行。

静态检查与模拟界面只证明接线和展示；真实宿主快照/脱敏、草稿变化隔离及外部对象验收分别记录，单元测试按当前 UI 优先顺序后置。

## 只读产物预览 v1

新增白名单 IPC `artifact.preview`，严格输入 `{id}`，id 为 1–100 字符产物 ID，不接收路径、命令、URL 或执行选项。复用来源帧校验和宿主记录；只允许读取本机已登记的 `snapshot-v1` 副本。旧无快照记录、已清理、缺失、路径/内容发生变化时不返回文件内容。

成功返回 `{artifactId,name,size,status:"text",text,truncated}`。仅在完整文件不超过 1 MiB 且为有效 UTF-8 文本、无二进制控制字符时提供内容；先在同一打开的文件描述符读取并核对整个文件的 SHA-256，再核对文件身份/元数据及规范路径未变化。显示最多 65536 个 Unicode 字符，标识是否截断。超出限制或不支持的内容返回 `{artifactId,name,size,status:"unavailable",reason}`，不通过截取未经核对的文件前缀冒充结果。

预览经既有统一脱敏后返回 Renderer，仅按纯文本呈现，不运行 HTML、脚本、链接或公式，不触发外部应用，不把内容自动发送到模型。读取后重新核对登记记录仍有效；并发清理或记录替换不得返回已撤销副本。读取失败保留运行和其他产物的查看入口，不修改原文件、记录或授权。

本地接口增量不改变公开 FlowDefinition/Event wire、SQLite 表结构、模板协议或调度行为。客户端采用本治理合并提交后实现，不在运行时读取治理目录。

## 验证

必须覆盖严格输入、真实副本文本和脱敏、UTF-8/二进制/大文件、截断、哈希不符、符号链接/路径替换、已清理及读取期间变化。界面验证真实 Worker 的暂停/继续/人工/取消/成功/失败和文件回读，条件/循环不能虚增完成比例；检查丢失实时观察和存储故障的未知状态、三尺寸、详情/结果/原任务往返和迟到回复，不因页面测试通过宣称真实模型、任意业务或完整 U09/U10 通过。
