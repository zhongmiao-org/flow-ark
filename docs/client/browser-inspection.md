# 通用网页只读核对

2026-10-16，接续[个人蒸馏/BOSS计划](guided-skills-boss-plan-20261015.md)。上一批局部更新检查点已完成原生制作与独立复导，真实Key路径继续保留。本批转向BOSS制作时先核对已有浏览器能力，补齐实际可视化缺口，不在客户端加入招聘专属节点。

## 证实的缺口与范围

客户端当前main为`3968b62ff88e27a46df34e2360b6127d19340a56`，采用契约0.24.0。BrowserDriver的Playwright、Selenium和内置适配器，以及模板SDK，已有url/count/attribute；可视化browserActions仅列12项，BrowserNodeConfiguration的selector仍是固定文本。作者不能独立编排读取当前地址、统计动态列表及读取链接/标识属性，需要绕到脚本。Selenium现有属性获取/目标选取还需统一原始DOM属性与唯一匹配语义，不能因底层方法存在就计为新节点通过。

新增browser v4仅承载三个只读操作，并允许selector/属性名通过现有Value引用提供。url作用于顶层页面；count支持0项且不等待；attribute必须唯一匹配，原始属性缺失为null、空属性为空文本，相对链接不改成绝对地址。参数、输出、预算、框架和取消边界由[0.25.0](../../contracts/v0.25.0/README.md)定义。写入节点的目标语义、SDK1.0、包2.0、SQLite及IPC保持；切换到既有其他动作时清除不适用的动态目标并提示重新配置，不把动态引用静默交给写入动作。

每次读取是独立观察，不是原子网页快照。业务模板必须将网页与账号、会话、JD对应，并在后续外发前复验；一个网址、元素数或链接不能证明身份。此节点不调用模型；下游若调用仍使用用户自己的Provider/model/Key，不增加写入授权、自动运行或任意JavaScript入口。

## 站点只读观察及限制

用户指定的[BOSS城市页](https://www.zhipin.com/chengshi/c101170100/?seoRefer=index)本次通过网页读取工具仍不可访问；Codex内置浏览器曾实际呈现公开首页、银川文本、职位及登录/注册入口，随后标签状态成为about:blank，恢复一次后亦未能稳定继续。未据此判断网站原因、登录成功或账号身份。浏览器DOM辅助接口没有取得有效页面上下文，原始调试检查未获浏览器权限门准入，没有绕过或改用私有接口。临时标签已关闭。

本轮没有稳定取得登录面板、已登录求职者账号、真实会话/JD关联、索要简历及不感兴趣入口，不编造选择器，不从城市页设置用户偏好。后续以FlowArk实际所选浏览器的页面校准与回执为准；Codex浏览器观察不是FlowArk内置/Chrome运行验收。没有扫码、验证码操作、简历上传、投递、聊天或模型调用。

## 交付顺序与验收

本批为G1：先设计及语言无关格式、正反例、纯数据核对与能力门槛，真实契约tag发布后消费者固定采用。新流程及模板入口都须声明browser-observe-v1，旧端须执行前拒绝；不修改历史契约或旧Run，不开发兼容路径。

G2随后接入动作库/配置、变量选择/预览、执行前解析校验、受保护结果、来源摘要、导出与独立复导。宿主/Worker需在调用前及异步返回后检查取消和活动Run，并对输出类型/UTF-8预算核对；Selenium必须处理唯一性及DOM属性原值。原生至少核对0/1/多目标、null/空属性/相对链接、参数/前序/循环引用、缺失/非法目标、框架、超限、取消/迟到、主题/紧凑布局、重开和包能力阻断；各驱动独立记录。

当前尚未修改客户端或模板代码，未运行新节点。按UI/UE阶段不新增或运行单元测试；本批仅做JSON Schema/格式资料、TS语法和治理检查，不能替代Runtime、实际浏览器、BOSS或完整G3–G5验收。实际发布及后续采用追加记录，不预填tag、SHA或通过结论。
