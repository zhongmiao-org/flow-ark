## 通用声明与交互

[0.31.0契约](../../contracts/v0.31.0/README.md)为作者资源和包清单资源增加可选defaultDirectoryFrom，值仅为另一逻辑目录ID。只允许目录引用无默认来源的目录；拒绝未知、自引用、重复标识、循环和链式关系。多个目标可复用一个来源，与声明顺序无关。包摘要覆盖此字段，作者导出/再次采用须保持；实际路径仍只存本机实例，不进入ZIP。

默认关系只帮助资源表单填草稿，不是运行时别名、持续同步或权限继承。选定来源后，只填入当前未绑定、且本次未由本人另选/清除的目标；本次自动填入项可随本次来源选择继续变化，清除来源时清除本次派生值。已有保存值和手动值均保持，即便恰好与原来源相同，也不能据路径相等推断仍在跟随。导入、创建实例、读取详情、打开表单或启动Run不能自动补绑定、保存或执行。

本人另选或清除目标后，本次草稿不再自动填入它；“使用来源目录”是明确重新填入当前来源的操作。关闭系统选择器无选择不改变原值或默认跟随状态；来源未设置时该操作不可用并说明原因。表单提示复用来源名称及是否未保存，目录写入仍按资源/入口权限和Skill确认分别核对。

保存失败保留草稿、默认来源提示和本次手动覆盖状态；明确取消恢复原绑定。成功保存的两个路径成为独立固定绑定，后续源路径修改不自动改写已保存目标。明确清除只停止本次草稿自动填入；不发布跨会话的永久“禁用默认值”设置。保存资源和后续运行仍走既有修订校验，活动Run快照不变。源文件、Key、动作授权和旧Skill不因默认关系而复制或修改。

作者页只列出可选的无默认关系目录，不允许在此填写实际路径。资源仍被默认关系引用时，移除或改为非目录需先解除引用；标识重命名必须保持关系一致或明确拒绝保存，不能静默丢关系。编译/导入均校验同一规则；不支持该字段的旧Schema必须拒绝新包，不能忽略关系并假装支持。旧快照不可变，不增加旧客户端迁移或SQLite表。
