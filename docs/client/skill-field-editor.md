## 编辑与数据边界

- 在正文/来源卡片之后，用独立全宽卡片编辑结构化内容。字段树与当前字段分列，紧凑宽度上下排列。树使用对象字段名、数组序号和类型展示，长名称换行或截断并可核对完整路径。
- 支持对象、数组、文本、有限数字、布尔和空值。根 data 必须是对象；对象可新增/更名/移除字段，数组可添加/移动/移除条目。选择容器可继续查看其子项，不要求用户写 JSON。
- 当前字段的名称/类型/值先保留为未应用输入，再显式应用；无效数字、重名、未应用输入阻止切换字段/高级模式及保存、试聊、确认。离开仍沿用保存/放弃/继续编辑，不能因未写入主 JSON 就忽略未应用内容。
- 类型变化会替换当前值，移除容器会移除子项。先显示完整路径及影响范围，由用户明确应用/移除；取消保留输入。操作只修改当前草稿，保存使用现有修订校验，不能覆盖已确认版本或活动 Run。
- 高级 JSON 保留完整 data/evidence；未完成/无效文本原样保留，修正后才返回字段模式。字段编辑只变更指定 data 路径，来源记录、其他字段、类型及字面 `$ref` 均原样保留；不将普通 JSON 当作流程变量或执行代码。保留现有层级/数量/大小预算和来源真实性校验。
- 操作不调用模型、不写工作区或发布版本。真实 Key、完整蒸馏、公开包复导及 BOSS 按长期计划另验。

## 保存资源提示

参数与资源页成功取得保存回执后清除旧目录选择提示，展示当前已保存状态；保存失败保留目录与未保存提示。取消目录选择、重新选择及离开保护仍按现有规则处理，不把 UI 提示作为实际资源授权或保存证据。
