# 同名序号文本输出

2026-09-22。对应 Figma [理解与补问 23:2766](https://www.figma.com/design/sVciNUZHG9yx81gCpYzjH9?node-id=23-2766) 的“新建带序号的文件，保留原文件”和首次教学输出规则。此项为通用文件能力，不在执行核心加入教学或站点分支。

## 明确的节点语义

契约 [0.12.0](../../contracts/v0.12.0/README.md) 新增 file v4，`operation:create`、`onConflict:number` 均为固定字段，声明 `file-create-numbered-v1`。binding、name、content 以及 UTF-8 10 MiB、相对路径、动态引用和目录授权沿用[文本新建](file-create.md)。name/content 可使用现行引用；冲突策略不能由模型在运行时动态改变。file v3 仍表示同名停止，不把已有草稿、Run 或计划改成新策略。

先尝试原始名称；若已占用，在最后一个扩展名前依次添加 ` (1)` 至 ` (999)`，共最多 1000 个候选。例如 `页面标题.txt` → `页面标题 (1).txt`；无扩展名 `结果` → `结果 (1)`，单独点文件 `.env` → `.env (1)`，`archive.tar.gz` → `archive.tar (1).gz`。名称已有括号数字时视为普通文字，不猜测或剥离。父目录保持不变，不隐式创建目录。

## 原子提交与中止

只写一次本次临时文件，再对候选路径进行原子不覆盖提交；只有明确的 EEXIST 才尝试下一个名称。不得先判断不存在再用可能覆盖的 rename。已有文件、目录、有效/悬空/指向外部的叶子符号链接都视为被占用，不跟随或替换；父目录解析后仍必须位于授权目录。并发执行各自最多提交一个文件，实际名称以成功提交的候选为准。

候选耗尽、权限、路径长度、存储或其他错误立即失败；取消/步骤超时在写入前和每次提交前检查。已成功提交的文件不能因取消、产物登记失败或后续错误被删除，且不能继续寻找下个名称。自动尝试新名称只发生在已确认没有提交的同名冲突，不重放运行或结果未知的写入。只清理本次临时文件。

成功后只登记实际落盘路径，并按既有规则保存不可变产物副本；输出、运行结果、查看/打开文件均使用该真实文件名。检查页说明“同名自动加序号，不覆盖”，不能预先声称将得到特定序号。已有副作用、取消后可能已提交与产物失败如实保留，不把没有产物登记等同于没有创建外部文件。

## 界面与验证

文件属性沿用现有新建操作，提供“已有同名文件时”的明确选择：停止并提示 / 新建带序号的文件，保留原文件。更改策略进入同一草稿的撤销/重做与保存链；切换不执行文件。方案资源说明、运行影响和 AI 能力说明使用同一语义，保留所选网页的只读加新建范围。

覆盖扩展名/点文件/中文名称、静态与动态值、已存在普通文件/目录/各类链接、1000 候选耗尽、并发竞争、取消、临时清理、其他 IO 错误不换名、登记失败只留一个已提交文件、真实 Worker 字节与副本、旧快照固定策略、UI 保存/重开与实际结果。教学学习进度、跳过/恢复/重新学习另行实现，不能以本能力通过代表 U01 完成。
