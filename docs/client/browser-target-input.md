## 实际缺口

作者通过客户端创建独立只读城市选项校准副本，保留原制作修订11及业务入口，不带回此副本。真实站点拾取的选项是li；八步仅读取当前网址和该选项的href、ka、data-code、data-id、data-val、data-value、value，实际运行完成，七项属性均为null。只证明本次选项的这七项属性缺失，不声称枚举了全部DOM属性，不从跟踪文本或其他字段猜城市代码。本批没有导航、切城、模型请求、招聘外发或简历发送。

现有browser v4的selector引用只供url/count/attribute，v5–v7关联字段节点也可引用定位；v1–v3的click/read/wait目标仍必须固定字符串。模板SDK的动态浏览器调用不能替代本次作者普通可视化节点交付，不能用固定城市分支或整个业务大脚本掩盖缺口。选项定位、城市匹配、求职规则与BOSS选择器仍归独立模板。
