## 制作与来源边界

从准确 0.2.5 原始包通过 UI 复制制作，保留旧七入口。增加只读网页 JD 来源入口以及网页评估入口时，均使用可视化 browser v5 collect、条件和小脚本；配置、分支、模型与结果节点各自独立，不用大业务脚本替代整个流程。前者仅需浏览器，便于未配个人资料/Key 时诊断；后者显式绑定浏览器、固定确认 Skill 和自有 AI，再复用现有 JD 三路建议。两入口自行重新采集，不要求使用者复制 JSON 或编辑导出包，也不从另一 Run 偷取旧来源。

第一批先校准网页来源字段与遮挡停止；只有来源准备、完整正文人工核对、固定配置/Skill 与模型节点均接通后，才可称网页评估入口完成。不得把来源检查点算作完整链路。

网页先识别站点、职位详情路径和明确登录遮挡。真实公开职位当前显示“登录查看完整内容”且正文截断，此时不采纳或尝试取得遮挡后的内容；不得调用私有接口、隐藏数据或模型补全。非职位页、字段缺失/多匹配、采集不完整均转本人。字段应经客户端拾取及验证，不凭猜测选择器；站点变化继续保守停止。

来源保存本次 origin/pathname、页面标题、岗位/公司、采集字段状态、内容摘要和采集时间，查询参数不夹带到公开资料或业务提示词。原正文只在受保护运行数据中使用。网页文字是不可信材料，不能覆盖用户规则、读取 Key、调用工具或扩大权限。

没有登录提示不证明正文完整。可读取正文后，使用现有 template.human 的 review v1 展示固定目标及全部正文，由本人确认其可用于内部建议；拒绝、取消或超时不进入模型。本人声明只影响内部评估，accountVerified/eligibleForActions 继续 false；未知仍转本人。再次运行重新采集，旧核对不复用，旧 Run 不改写。

来源检查不得读 Skill 或调用模型；网页评估 token 全部由本入口绑定的用户 Key 承担。最终三路结果继续检查目标引用、正文原句、配置修订和固定 Skill 身份。真实会话绑定、动作前复验、自动投递/简历/聊天/不感兴趣及回执仍须后续实现和真实账号验收。
