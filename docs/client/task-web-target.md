# AI 任务的网页对象选择

2026-09-22。对应 Figma `23:2440` [选择操作对象](https://www.figma.com/design/sVciNUZHG9yx81gCpYzjH9?node-id=23-2440)、U02/U03 及首次教学前置步骤。实现当前稿件的读取网页、定位元素和新建文件范围；应用窗口、MCP 与账号/工作区读取须另行接入，不能用示例账户或推测登录态填充。

## 真实来源与本机接口

- `task.web.preview {id,revision}`：只读取已存在的内置网页元数据，返回 URL、标题、资源代际、文档 revision、明确的只读网页范围和宿主签发的确认摘要。无页面、加载中、正在操作或不是 HTTP(S) 时返回原因；不隐式打开网页、读取 DOM、登录态、账号或其他窗口。
- `task.web.select {id,revision,token}`：再次读取同一页，核对任务 revision、来源摘要和宿主会话；保存不可伪造的本地网页选择，递增 revision，取消在途生成、丢弃旧提案/撤销及目标修复依据。Renderer 不提交页面证明、URL/标题或“已验证”字段。源选择不创建 Run 或文件。
- `task.web.clear {id,revision}`：显式移除所选来源，递增 revision 并使旧提案/授权失效。清除来源不自动清除已经存在的流程；旧流程在重新生成并采纳前不能继续使用已撤销选择。

沿用加密 ai-task 文档，新增本地 `webTarget`（selectionId、taskId、browserId=embedded、page 元数据、selectedAt、access=read）。本机 `FlowRecord.webTarget` 由采纳事务写入并纳入版本摘要，不能通过 flow.save 或模型输出伪造；手动保存保留这份约束。流程/计划/Run 快照保存其原始选择，不随着重新选择被改写。不修改公开规划格式、SQLite 表结构或旧契约 tag。

## 发送、提案与采纳

描述中的网页地址仍只是文本。只有经过上面确认的网页，才作为宿主构造的 `kind:web` 资料加入规划请求；保留一个系统来源 ID，普通文本资料不能冒用。发送前显示确切 URL、标题、只读范围、账号“未核对”和工作区“本机内置浏览器”。用户仍需确认供应商和全部输入；资源 ID、文档 revision、来源令牌和本机输出路径不发送。最多二十项上下文的总量限制包含这份网页资料。

生成前、凭据等待后、模型返回和采纳前复核页面身份与任务选择；刷新（即使 URL 相同）、导航、关闭、重建、重开、重新选择或撤销使旧来源失效。异步等待后再次检查任务 revision、生成归属及完整流程摘要，迟到结果不恢复失效提案。

本次页面选择授权为只读：可使用普通 value/assert/condition/loop/human、browser read/wait、打开同一已选 URL 的 navigate，以及 file v3 create。模型和手动编辑不得借该选择加入网页写入、其他地址、HTTP、脚本、覆盖文件或其他未列出的能力；明确提示重新调整任务/能力，不能把“已连接”当作动作授权。浏览器必须显式绑定 embedded，不可静默切换本机其他浏览器。选择页不承诺已核对网页账号/DOM 内容，也不自动发送未选页面资料。

撤销采纳恢复原流程或删除首次生成的草稿，保留用户独立确认的当前网页资料。若恢复流程绑定的是已撤销旧来源，仍须重新生成并采纳，不能通过撤销恢复旧网页授权。单项文本上限 50000 字符、全部上下文合计 200000 字符与二十项限制均包含宿主构造的网页元数据。

## 执行与失效

运行前、确认准入与出队执行核对 FlowRecord 中的选择仍与当前任务一致、页面相同且流程仍在只读范围内。普通 flow.run、计划、历史重跑不能绕过来源约束。不同的选择进入不同版本；旧运行和计划不自动继承新网页。

每个实际步骤边界重新核对来源选择；每个网页命令在 Main 的同一资源/租约下核对预期页面，等待拾取取消后再复核，读取后再次核对。同一 URL 的显式 navigate 是该运行声明的操作，可更新仅属于此 Run 的页面 revision；重定向到其他 URL 失败。外部导航/刷新不得被视为运行自己的续页。后续文件步骤只在此前网页结果身份有效时执行，不因失效重放。

已发生的外部操作和产物不删除；失败如实保留。关闭/重开后选择元数据仍可见，但必须重新确认新的资源，不能仅凭 URL 相等复活。来源页可取消返回原草稿；扩大查看复用同一内置网页，回到目标页重新检查后才能确认。

## 验证与边界

覆盖伪造输入、过期令牌、同 URL 刷新、换页/关闭/重开、选择/移除期间生成取消和凭据等待、迟到返回、采纳存储回滚、跨任务来源、手动浏览器绑定/节点范围变动、普通运行与排队/计划/重跑入口，以及真实 Main/Host/Worker 读取与文件字节。页面按 420/708 两栏、24 间距和 700 高度对齐原稿，紧凑布局独立核对；GUI 只使用串行独立测试进程。

此规范和网页来源增量不等于完整 U03、教学或非技术用户验收。首次教学还需持久进度、跳过/恢复/重新学习；理解页 `23:2766` 的“同名自动加序号”须实现原子不覆盖的命名策略，现有 create 同名停止不能冒充该策略已完成。
