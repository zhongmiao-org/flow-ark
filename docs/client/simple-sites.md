## 可导入示例

客户端 `examples/simple-web-form.template.json` 是版本 1.0.0 的模板包，使用现有契约，不增加运行时能力。目标为 [Selenium 官方测试表单](https://www.selenium.dev/selenium/web/web-form.html)，只填写固定虚构名称与练习说明。

在 FlowArk 导入该文件，选择本机 Chrome，将文件绑定 `output` 设为独立练习目录，然后手动运行。导入不执行、不携带浏览器路径或文件绑定。流程将生成或覆盖目录中的 `simple-web-result.xlsx`，截图在运行产物中查看。

流程：打开页面 → 核对标题 → 填写名称和说明 → 勾选测试复选框 → 提交 → 等待并读取回执 → 核对结果标题 → 条件分支 → 写 Excel → 保存截图。页面不提供后端字段回显，本次没有宣称验证服务端持久化或字段接收内容；只证明该测试页的浏览器操作与导航回执。无文件上传、浏览器下载、账号登录或 AI 调用。
