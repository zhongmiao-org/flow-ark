# 已验证模板定义的有界复用

2026-10-28，BOSS 单 ZIP 交付期间对正式宿主进行一次120秒、仅函数栈的 CPU 采样：93,211 个样本中，包校验路径占36.7%，Schema编译相关路径占31.7%，相同归档在后续预检和运行中重复解析并编译。完整结果目录仍有独立成本，不据此声称所有高CPU或点击故障均已解决。

拟在客户端 PackageLibrary 内复用同一归档已验证的静态定义：每次加载仍重新读取有界的完整原始ZIP字节，只有与缓存快照逐字节一致才命中；归档变化或读取/校验失败立即失效并完整重验。解析必须针对已读回的同一字节快照，不能把路径先后读到的两个版本关联起来。只缓存静态包定义，不缓存实例、配置、状态、Run、浏览器、Key、资源绑定或授权。

缓存限8个归档且总计32MiB，计入压缩原字节、展开文件和清单；单包超预算照常校验且不缓存，不提高包格式限额。命中仍执行入口结果Schema只读范围门槛；返回独立清单/Map/Buffer，调用者编辑不能污染缓存。卸载、释放与失败清理缓存。原始ZIP导出校验同一保存字节并读回，保留原身份和摘要。

不新增包格式、协议字段、客户端业务接口或运行权限，不更改既有不可变公共契约快照。使用类型、构建、格式、实际包加载耗时对照与原生UI核对；当前阶段不新增或运行单元测试。准确实现、合并、安装、性能及业务证据分别追加，本段为实施前范围。
