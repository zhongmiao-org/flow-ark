## 编辑约定

2026-09-20 高级节点 JSON 的未完成输入纳入统一提交和切换保护，避免执行旧配置；恢复方式和验证见 [节点超时与高级输入一致性](node-execution-input.md)。

- 可解析值的字段区分固定值与变量。选择变量前可以搜索并查看来源、可读名称和实际引用路径，确认后才替换字段；取消不改变草稿。已有引用直接展示，不伪装为空文本、未勾选或默认选项。明确切换回固定值才替换引用。
- 候选包括流程参数、当前可访问的前序步骤输出、循环体内最近一层的 item/index。条件两边互不可见、容器自身输出在容器内部不可见、分支子节点不得直接泄漏到外层、循环的后续步骤不得引用循环变量。规则与保存/执行校验一致。
- 参数与已知结构的普通数据可以展开字段；步骤输出只推荐实现明确提供的字段，未知脚本/网络响应可选整个结果，再通过高级子路径指定。条件的子输出取决于实际分支、循环的索引取决于实际迭代，不将某次历史 Run 的结果当成固定 Schema。候选不读取凭据、网页当前数据或历史运行值。
- 引用路径拒绝空路径段和原型相关属性；包含点的对象键无法由现有协议无歧义表达，不生成对应候选。自定义子路径明确提示运行时核对，缺失仍由现有引擎报错，不猜值、不静默转字符串或回退固定值。
- 先接入浏览器的值字段、数据、条件/断言、循环集合和脚本输入。保留原生下拉选项、布尔状态等固定值控件；操作切换按既有预设重置。高级 JSON 继续兼容已有流程，表单与原配置互相同步，并纳入草稿撤销/重做。
- 运行参数提供名称与值编辑，保留类型（文本、数字、布尔、空、数组/对象）；引用参数的名称删除受现有引用保护约束。只编辑草稿，保存、Run 快照和计划语义不变。

2026-09-20 模板参数例外：`flow-parameters-v1` 的参数由独立实例配置表单统一编辑，右侧只读显示，避免两份值在保存时互相覆盖；普通流程仍使用上述自由参数编辑。来源和验证见[模板实例参数](template-parameters.md)。

## 2026-09-20 引用校验修正

0.1.18 审计复现：引用遍历无条件排除 `body`，使 HTTP 请求体引用被误认为循环子步骤而漏检；请求体引用的前序步骤可以被删除后保存。参数根使用原型链成员判断，`params.toString` 也被错误接纳。修复沿用现有契约的前序作用域及自身属性规则，不增加引用语义或协议字段。

- 仅条件节点的 then/else 和循环节点的 body 属于结构子步骤；HTTP body 及其任意层嵌套值必须参与引用校验。保存/导入、Run/计划预检、编辑器结构调整和参数删除使用相同的节点值遍历。
- 引用路径不接受空段、原型相关属性、缺失的步骤/参数名称或继承来的参数名；index 只能引用当前循环序号。已有未知输出的子字段仍在运行时核对，不假定外部接口结构。
- 编辑器检查条件/循环输出的子步骤被移动时，同样检查 HTTP body。合法请求体中的嵌套对象、数组、item/index、参数与前序输出继续执行；复制子树仍重映射内部引用。
- 不自动修改旧草稿、版本或运行结果。旧的无效定义在下次保存、运行或计划触发时明确失败；已成功的历史记录保持原状态。

验收：针对原缺陷先复现误接纳，再检查非法请求体引用、参数原型与路径格式被阻止，合法分支/循环请求体经真实本地 HTTP 核对值。用真实宿主验证失效定义不能入队或执行之前的文件副作用；从界面验证来源步骤删除/移动、参数删除被阻止，正常请求体保存重开与执行仍通过。只使用隔离数据、内置浏览器和本地服务。


## 2026-10-02 变量工作页呈现

变量入口使用覆盖内容区的双栏选择页，保持调用字段和流程草稿挂载。来源列表按可访问作用域生成，右侧核对来源与完整路径，确认/固定值/取消操作位于详情内；高级子路径按需展开。搜索不清空已选来源，取消、返回与Escape不改字段。紧凑窗口纵排并自然滚动；从步骤字段打开时记住节点配置面板，选择期间缩窗后仍返回原字段。保留模态背景约束与已有网页可见性协作，原生遮挡和全部来源组合的验收状态见[实施记录](design-implementation.md)。
