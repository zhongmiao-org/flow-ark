## 当前草稿导出（标准 ZIP）

自定义流程和模板流程都在编辑器点击「导出 ZIP」。模板库的导出使用相同 ZIP 规范，见[统一导入导出](../templates/package-format.md#统一导入导出)。流程导出生成新的本地模板身份，保留当前编辑内容及参数结构，清空参数值；文件与浏览器等逻辑资源进入清单，真实路径和授权不导出。重新导入后创建实例、填写入口参数、绑定资源和确认写入权限即可运行。

### 0.1.25 历史草稿导出

导出入口先校验编辑器中尚未完成的值输入，再传递点击时的流程与模板配置定义。宿主校验流程、配置定义和完整模板包，清空运行参数值并产生固定 JSON 内容；主进程在得到该内容后显示既有审阅确认和保存对话框。后续草稿编辑不改变该次导出的内容，取消任一对话框不保存草稿、不写模板文件、不创建版本或 Run。

本地 IPC `flow.export` 改为严格载荷 `{flow, configuration?, reviewed:true}`，configuration 仅含 adapter 与 schema，不接受 values；不再接受 `{id, reviewed}`。Renderer 和 Main 随同一应用包更新，不提供混用旧载荷的回退。flow 按现有 FlowDefinition 和引用规则校验，配置定义按现有配置适配器与模板规则校验。请求仍受 2 MiB 上限和来源帧限制；生成内容还须符合导入端相同的 2 MiB 字符长度限制，超限在确认前拒绝。宿主不从旧数据库草稿替换提交的流程，也不收集本地 bindings、账号、授权或历史。

本地导出的默认版本为 `0.0.0-local.sha256-<完整 SHA-256 摘要>`。摘要复用现有规范化模板内容算法，在清空参数值后计算，包含流程及可选配置定义；相同可导出内容生成相同版本，内容变化生成新版本。该版本标识内容身份，不表示按摘要排序的发布先后。内置模板继续显式指定其版本。旧导出包仍按原规则可导入，不改写它们，也不自动覆盖既有实例、计划或运行快照。

验证须包含：删除草稿中虚构的私密字面量后直接导出；未完成值输入被拒绝；确认期间保存另一个草稿不污染既定内容；取消审阅/保存不落盘；参数与配置值、本地绑定不进入包；同内容复导和变化后的版本；旧包导入仍创建独立未运行草稿。

## 完整任务退出提示

显式退出按 bootstrap 的完整 runOverview 统计一个活动 Run 与全部排队 Run，不能用最近 200 条的 runs 展示窗口判断是否确认。存在任务时仍由用户选择继续运行或停止任务并退出，提示显示完整受影响数量。

从首次退出请求到确认或关闭完成，只处理一次退出流程；重复菜单、快捷键或系统退出请求不重复弹窗、不并发关闭宿主。取消退出后恢复接受下一次退出请求。实际停止继续使用既有 shutdown：停止驻留计划、取消队列并协作回收活动执行与内置浏览器。

验证须实际启动等待人工任务，再排队超过 200 次；确认 206 条提示，取消全部后续队列后仍提示旧活动任务；选择继续运行保持原任务，明确确认后才停止。测试对话框响应可注入隔离 Electron，任务与菜单退出必须通过实际运行宿主和应用入口。
