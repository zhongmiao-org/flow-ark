记录字段见 [RunOutputPackedV1](../../contracts/run-output-packed.schema.json)：`version=1`、`encoding=deflate-raw-json-v1`、`runId`、`expandedBytes`、`sha256`（展开后原始 UTF-8 JSON 字节）、`data`（压缩字节的规范 Base64）。完整记录的 JSON 字节仍纳入原运行账本 `run-output` 副本类别及现有 8 MiB 实际保留总预算，不能只计算摘要或漏算 Base64 正文。压缩在系统保护的 Store 加密之前进行，不落地明文临时文件。

单份展开 JSON 最多 64 MiB、深度 64、1048576 次值访问；此为整个运行的展开限制，不改变单份步骤结果的限制。写前验证有限纯 JSON、稠密数组、数据属性及无环；按实际 JSON 字节线性计量，不把同一子树在祖先中重复累计为序列化工作量。压缩后的完整记录不得超过 8 MiB。读取验证精确字段、版本、运行身份、规范 Base64、展开长度和 SHA-256，限制解压最大输出，验证完整 JSON 后才返回原值。格式、摘要、预算或存储校验失败继续拒绝采用，保留独立步骤与外发回执，禁止截断或只返回部分对象。
