# MCP 工具试运行 v1

2026-09-23，实施协议。对应 Figma 23:3799、23:8492、23:8631 与 U03/U07。原任务选择和方案规则见[任务工具对象](task-mcp-targets.md)，静态参数规则见[参数核对](mcp-argument-review.md)。当前是待消费者接入的规范，不能据此报告执行通过。

## 确认与固定范围

只有原任务的已保存方案能进入工具试运行。统一检查页展示连接、工具原名、参数来源和可能的外部影响；用户明确确认后创建独立 Run，不在查看、采纳、返回或重新检查时连接服务。普通运行、旧重跑接口及定时计划均拒绝缺少此次工具确认的调用；后续再开放无人值守授权，不能自动沿用本次确认。

检查、确认、出队及每次调用重新核对原任务选择、连接修订、已保存能力摘要与工具集合。授权摘要固定在 Run 快照，不能替换为最新连接。固定快照包含逻辑节点、参数和所选定义；不向 Worker 返回认证或连接配置。连接删除、断开、重新发现或保存使后续调用失效，不能改向新地址。生成中的任务、未处理提案和需要重新规划的任务仍先处理方案。

## 调用及期限

Worker 仅通过宿主白名单提交本次 Run 的节点身份、节点实例和已解析参数；宿主核对固定节点、实例路径、目标和 Schema。引用已由核心求值，校验时不再把数据中的 $ref 当作待求值指令。输入 Schema 子集与 65536 字节、20 层、4096 值节点、256 规则节点/12 层的限制沿用静态参数规范。输出 Schema 若有声明也必须在同一子集内，不能跳过无法校验的定义。

同一次会话完成 initialize、tools/list 与一次 tools/call；发现的完整能力摘要必须与快照相同。关闭自动重连、认证自动重试、任务模式、输入补问和 SDK 隐式调用。不能响应服务提出的 sampling、roots 或其他未授权方法。继承连接发现的明确地址/协议、单次 stdio 启动、精确 URL、重定向拒绝及 2 MiB 传输上限。节点期限包括连接、发现、调用，默认 60 秒，最大一小时；到期或取消关闭此次会话，不重试调用。

每个 Run/节点实例最多一次尝试。发送前同步持久化状态 unknown 及 attemptedAt；写入失败不能发送。发送前最后复核失败可记 not-sent；进入发送后超时、断连、取消、无效回复或关闭失败保留 unknown。持久化失败保留之前的 unknown，不以失败状态证明外部未执行。重启不补发，旧 unknown 在运行详情可核对。

连接移除/断开先撤销资格并取消会话，等待本连接的调用收尾后才清理凭据。发现或保存同一连接时存在活动调用则拒绝，避免认证被替换；休眠/退出取消所有会话并等待关闭。关闭失败阻止后续 MCP 调用，不能在同一宿主继续创建新会话。取消只停止等待，不证明外部操作撤回。

## 回复与页面

公共输出使用[契约 0.15.0](../../contracts/v0.15.0/README.md)。收到的输出最多 1 MiB UTF-8 JSON、20 层、4096 个值节点、64 项内容；根对象只投影 version/content/structuredContent/isError。认证内容被识别时拒绝保存该回复，原始协议错误和 stderr 不回显。声明 outputSchema 时校验 structuredContent，缺失、无效或不支持均终止而不宣称成功。

回执包含 runId、nodeId、nodeInstance、selectionId、连接显示名、工具原名、attemptedAt、可选 completedAt、状态及可读说明。状态 received 表示成功收到服务回复，tool-error 表示服务明确 isError，unknown 表示结果不能确认，not-sent 表示没有发出本次调用。仅 received 返回步骤输出，其余终止执行。成功回复不能替代业务读回。

结果页按步骤展示连接、工具、时间、状态和服务内容。文本及结构化 JSON 使用转义纯文本，富内容只在原始 JSON 中查看，不请求其中 URL、不渲染 HTML、不播放媒体。未知结果明确提示人工核对，查看/返回不发起重试。回执和输出经已有秘密脱敏边界后进入 Renderer。
