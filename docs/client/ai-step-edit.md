# AI 只修改所选步骤

2026-09-21。依据 Figma `23:3290`、`23:3467`、`23:6333`，在同一任务清单、流程图和长流程大纲中提供单步修改。属于完整 186 画板 / U01–U12 目标；本文件定义行为，不代表实现或真实模型验收通过。

## 本机任务接口增量

沿用规划格式 1.0 和契约 0.10.0，不新增流程节点、公开模型字段或数据库迁移。以下是 Renderer/Host 严格白名单 IPC 的本机扩展：

- `task.detail` 增加 `flowHash`，为当前完整流程与本机绑定的规范化摘要；只用于本机并发检查，不发送路径或凭据给模型。
- `task.save` 可带 `scope: {nodeId, baseFlowHash, instruction}`。nodeId 沿用 1–100 字母数字/下划线/连字符；baseFlowHash 为 64 位小写十六进制；instruction 最多 10000 字符。没有 scope 表示完整任务修改；不能因单步生成失败静默改成全任务模式。
- 宿主保存 scope 前要求关联流程存在、完整校验通过、步骤存在且流程/绑定摘要与 baseFlowHash 一致。scope 与既有描述、显式上下文、补问答案共同受内容 revision 保护，保存在加密 ai-task 文档。原任务描述保留，单步要求独立保存；开始另一步修改清空上一轮补问答案。
- `task.generate` 沿用 provider、model、reviewed:true。scope 存在时，宿主用所选步骤身份、有限修改说明及 instruction 构造 description，使用当前显式上下文、补问答案和完整基线流程，仍返回完整 AIPlanningResult。发送前界面列明范围、供应商及实际上下文；预览和选择不创建 Run。

空 instruction 可保存草稿，不能生成。无效/过期 scope 拒绝并保留原任务和流程；用户重新读取当前流程后显式重新选择步骤。普通 task.save 不带 scope 才退出限制，普通生成不能继承旧的网页目标修复依据。

## 宿主范围校验

生成前、等待凭据后、收到结果与采纳前均核对相同内容 revision、请求身份、完整流程/绑定摘要。结果到达不能只依靠模型声称“仅修改一步”。

方案必须保持整份流程的顶层字段、步骤总数、顺序、身份、类型、版本及所有其他节点完全一致。选择条件/循环只允许修改该节点自身配置，then/else/body 中所有子步骤仍保持不变；不允许移动、增加或删除任何步骤。所选节点的 operation、binding、templateName、dependencies、HTTP url/method/headers、网页 selector/framePath 和导航目的地、文件/Excel 输出名称保持不变；批量文件节点保留每项文件名与顺序。无实际修改返回可读错误，不产生可采纳提案。

这些检查保护静态配置、现有能力和本机绑定；不会把可信脚本称为安全沙箱，也不保证动态数据改变后所有运行结果相同。动态引用、脚本代码与条件变化仍须在完整执行前检查中确认。类型或资源调整应由用户明确返回完整任务修改，不能通过单步提案扩大范围。

提案保存仅本地 scope 副本。采纳再次验证完整范围并使用已有 Store 事务、摘要冲突和撤销机制；保留绑定，不产生新授权。采纳清除 scope 回到同一完整草稿；不采纳、取消或失败保留单步要求，允许修改后重试。已有 Run、快照、版本和计划不更改，整个规划/采纳/撤销过程不创建 Run。重开不续发生成；未采纳提案的范围仍受校验。

## 页面和导航

清单和图使用同一步骤身份，只有已保存且已采纳的流程允许进入单步修改。尚未采纳的方案先明确采纳/拒绝；长流程未保存编辑先保存，运行快照只读，不能直接修改旧运行。

沿用任务工作区的对话、差异和保存守卫。明确显示所选步骤序号/名称/身份、基线摘要、单步要求；差异按宿主结果显示原值/新值及实际受影响步骤数。返回来源保留步骤、清单/图和大纲位置。改动输入、目标、模型或补问使发送确认失效。完整任务入口必须明确退出单步范围；不能让用户在不知情时发送整个任务修改。

## 必须验证

真实宿主与加密 Store 覆盖：嵌套条件/循环单步成功；相邻/子节点、顶层字段、资源、身份或顺序变化拒绝；无修改拒绝；基线过期、凭据等待和模型返回期间变化、取消/迟到结果；补问及不支持；采纳/拒绝/撤销、存储失败回滚与重开。所有路径确认零新 Run，旧快照/计划字节保持不变。

界面以原稿验证三尺寸、真实选择身份、保存与确认失效、清单/图/大纲来源返回、越界错误与重试；真实 provider 另外验收，不以本机 HTTP 夹具冒充 DeepSeek 实接。
