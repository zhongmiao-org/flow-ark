## 语言无关的有限选择规则

拟新增独立 `bounded-selection-text-v1`，不称v2的无绘制豁免。沿原同步同源DOM、唯一根/字段、框架与来源身份、2000元素/6000节点/64祖先/20字段、15秒及原字节上限；拒绝、取消、导航或预算超限均不返回剩余文字片段。只读，不滚动、展开、删除节点、改变样式或调用私有接口。

1. 目标自身和所有后代完整沿现有可见性、裁切、line-clamp、动画/不支持排版、嵌入内容与生成内容拒绝规则。目标/后代的空格伪元素也不新增豁免。文字仍由通过检查的目标 `innerText` 取得；不得回退 `textContent`、AX、截图OCR或其他目标。
2. 祖先元素自身仍必须通过现有可见性、排版、裁切/目标矩形关联等检查，不能把整条祖先链排除。框架祖先同样检查；未知或不可关联时拒绝。
3. 祖先伪元素先沿v2的无绘制普通空格条件；通过者仍计 `ignoredAncestorSpaces`。不通过时，只有**目标以外**祖先或同源框架祖先的 `::before` / `::after` 满足以下全部条件，才标记为选区外装饰：计算 `content` 为同号单/双引号包裹的一个或多个U+0020，不含转义/其他字符；`position`准确为absolute或fixed；`float=none`；`white-space`准确为normal或nowrap；`animation-name=none`、全部 `transition-duration=0s`，元素没有正在运行或pending的动画。缺失、未知或其他序列化均拒绝，不能把失败条件默认成允许。
4. 该装饰是否带背景图像、非默认层级或不透明度，不再决定**文字子树**是否可读取，但必须计入 `excludedAncestorDecorations`，且 `externalAppearanceVerified` 永远为false。不能把它计入“无绘制空格”、删除其绘制、宣称无遮挡或丢失文字为0。祖先中的文字、NBSP、转义、`content:url(...)`、counter/attr等其他生成内容继续拒绝；在正常流内而未通过v2的空格也继续拒绝。
5. 两计数均0–128，单字段合计不超过128，分别表示本次扫描的伪元素，不是正文字符数。整次计数遵循同次有限扫描，不沿隐藏或已拒绝子树为收集装饰继续搜索。非候选文字字段或匹配不为1时均0；不以已经核准/排除的数量抵销其他拒绝原因。

例如：独立绝对定位背景的祖先普通空格可以形成带明确装饰记录的文字候选；覆盖整块正文的祖先背景仍不应被称作“无绘制”或“已核验外观”。目标本身含生成文字、正文有隐藏后代、截断或预算超限，则候选为null并保留原因。站点可能删节/虚拟加载、兄弟覆盖层及图像中额外信息，仍不在该文字政策的证明范围内。

这项能力只产生来源候选，不产生账号、岗位资格、投递/发送许可或完整性声明。BOSS初次接续沿现有完整阅读/本人核对入口，必须携带新的来源方式及外观未核验状态，不允许旧v2校验脚本把新结果误判为同一来源。后续自动筛选仍须独立定义与验证其实际来源、用户条件、事实/不确定分支和外发边界，不因增加候选读取就宣称150次自动链已实现。
