# 模板实例参数的唯一编辑来源

2026-09-21 当前边界：业务模板、demo/example 和完整模拟网站已迁入独立模板仓库。0.2.0 仅接收标准 ZIP，通过模板库创建多入口实例；旧 JSON、旧内置业务和旧客户端兼容路径已移除。当前使用与实测以[模板验收](../templates/acceptance.md)和[模板开发](../templates/development.md)为准，下文旧版本记录保留历史含义。


2026-09-20。现有 `flow-parameters-v1` 在保存时将实例配置值投影到流程参数。通用参数编辑器若只修改 `flow.parameters`，会被未修改的实例配置覆盖，出现界面输入与保存、执行结果不一致。沿用既有实例配置权威来源，修复编辑入口，不新增协议或数据迁移。

## 编辑与保存

- `flow-parameters-v1` 的非敏感参数由 `bindings.configuration.values` 管理，按模板 Schema 在独立“实例配置”表单编辑。右侧运行参数显示只读当前值与通用入口，不再提供第二套参数输入、增删或高级 JSON 编辑。业务字段和标题仍由模板包提供，不在通用检查器写入招聘专属名称。
- 打开或取消实例配置不保存、不执行。保存仍经宿主完整 Schema 与流程校验；失败保留表单中的输入并明确展示错误，不提示成功，不改变已保存流程。保存成功后使用宿主返回的完整记录更新草稿，参数引用、文件绑定发现和后续运行使用相同值。
- 实例配置弹窗打开期间通过既有网页可见性接口临时隐藏原生 WebContentsView，避免原生视图覆盖 DOM 表单。右侧面板布局保持，关闭弹窗后恢复同一网页，保留会话、输入、1920 CSS 像素宽度与当前运行；不通过关闭会话或重新导航处理遮挡。
- 普通无配置流程及 `recruiting-policy-v1` 的独立通用参数仍按既有参数编辑器操作；招聘配置不因此变成通用流程参数。不自动改写旧包、草稿、版本、Run 或计划。
- 草稿撤销/重做同时恢复实例配置与对应参数，撤销已经保存的值后仍需再次保存。编辑一个实例不会改变模板目录、另一实例、既有运行快照或固定计划；计划采纳新版仍须既有显式更新操作。
- 模板导出继续仅含模板定义与 Schema，清除当前实例参数值与本地绑定；导入以 Schema 默认值建立独立实例。此修复不扩展模板配置 Schema 支持范围。

## 验证

先用当前实现复现通用参数 A→B 在保存时回到 A，再通过实际界面编辑实例配置，核对保存、重开、真实 Worker 输出和内置网页填写值一致。两个模板实例、保存前启动的 Run 与固定计划保留 A，新明确运行采用 B；取消和 Schema 无效值不改变已保存记录，撤销/重做、普通流程参数编辑与模板导出清值均独立核对。

仅使用隔离数据、内置浏览器和本地复杂表单，网页保持 1920 CSS 像素。源码、DMG 候选及日常安装分别记录，不测试招聘网站或真实 AI；实际结果归[验收记录](acceptance.md)。
