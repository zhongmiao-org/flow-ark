# 试运行前检查与明确确认

2026-09-21。实现 [AI 任务主线](design-ai-task.md) 的“确认方案 → 试运行前检查”，界面依据 Figma `23:3799`。适用于已保存的通用流程及模板入口；试运行执行真实操作，不代表无副作用预览。实际实现、检查和安装证据另记于 [Figma 实施记录](design-implementation.md)。

## 检查内容

宿主从当前已保存 FlowDefinition、绑定和实际可用资源生成检查。展示流程名称、固定内容摘要、步骤数量、参数名称、绑定目录/文件的本机位置、浏览器身份和当前内置网页、凭据引用、模板动作及授权模式。密钥值、Cookie、Profile 和历史输出不进入预览；本机路径只用于当前工作台核对，不导出或传给模型。

逐步影响从实际节点推导，覆盖条件的两路与循环体；分支不确定和循环次数不用于虚构写入数量。文件写入/复制/归档及 Excel 写入明确可能覆盖同名文件；网页填写、点击、按键、上传、下载和 HTTP 请求分别标明网络/文件影响。动态引用在执行时确定，不能伪造目标。可信脚本与模板脚本声明为不能静态穷尽的影响，仍须核对代码及原有模板逐动作授权；“检查通过”不声称代码安全、页面内容完整可验证或业务已成功。

沿用宿主预检：流程/参数/引用、模板当前入口、浏览器与操作兼容性、目录、凭据引用及脚本依赖。补充所需目录/模板文件的类型与系统读写访问检查，保存真实路径和文件系统对象身份；目录检查不试写业务文件，不声称剩余空间或任意动态文件已经验证。输入文件的大小/修改时间参与身份核对。未通过时返回真实诊断和不可确认状态，用户修改资源或流程后重新检查。

内置网页通过新增 Host/Main 内部只读方法 `browser.embedded.review` 取得当前资源 ID、文档变更标记、启动/加载状态、URL 和标题，不创建网页、导航、拾取或租约。任意框架导航开始/同文档导航更新文档标记，同 URL 刷新也会使旧检查失效。只声明已核对当前页面身份，不把账号、DOM 内容或选区推断为已核对；这些目标能力仍按 U03 单独实现。外部浏览器仅检查已选绑定，页面由运行时的专用会话和步骤决定。

## 本地接口 v1

沿用 IPC 来源帧校验、2 MiB 输入限制和严格未知字段拒绝，不改变公开流程、RunRequest、事件 wire 或 SQLite 表结构。

| 方法 | 输入与结果 |
| --- | --- |
| `flow.run.preview` | `{id, debug?, task?}`；id 为已保存流程 ID（1–100 字符），debug 默认 false。可选 task 为 `{id, revision}`，revision 为正安全整数。返回可确认状态、内容 token、流程概览、实际资源、逐步影响、检查项及限制说明 |
| `flow.run.confirm` | `{id, debug?, task?, token, requestId, reviewed:true}`；token 为 64 位小写十六进制，requestId 为 UUID。只确认已检查内容，不接收覆盖流程、绑定、参数、权限或执行起点的字段；返回唯一的新 Run |

task 存在时核对任务关联 flowId 与 revision，拒绝仍在生成或有未采纳提案的任务；不通过确认自动采纳 AI 输出。预览可生成内部脚本编译缓存，但不生成版本记录、Run、事件、计划、授权或外部操作。不可确认预览不提供可用 token。

token 固定本次宿主会话/挂起代次、流程和绑定、选中 task、浏览器绑定/文档身份、所需目录/文件身份及固定脚本摘要。异步准备前后重新读取，任何变化都要求重新检查。重开或休眠恢复后不能继续使用未确认的旧 token。

确认沿用手动/计划准入 FIFO。预检前后及事务前重新校验；版本、快照、Run、初始事件和 `flow-run-request` 去重记录在同一事务中保存，失败不留半个 Run。相同 requestId 与载荷串行、并发、丢失回复或重开后确认都返回同一 Run；不同载荷复用 requestId 拒绝。已登记请求可在退出/挂起时查询其原 Run，不据此再执行。未确认 token 不持久化。

快照新增仅本地的 `runReviewAuthorization`，保存本次已核对资源的身份；Run 可选 `review:{reviewedAt}` 标识已检查后启动。进入执行槽前后重验当前授权与固定资源身份，排队期间权限撤销、目录被替换、浏览器重新绑定或原页面切换均停止此 Run。流程正文在确认后修改不影响已固定快照；真正执行中仍沿用各能力的资源范围、逐动作授权和副作用去重。确认与开始执行之间的操作系统资源变化仍由实际文件/浏览器动作继续校验，不承诺无竞态的外部事务。

## 页面与验证

界面为真实对象、读取内容、可能更改、保存位置及执行版本卡片，右侧展示通过/失败/未确定内容与明确勾选。取消、回去修改、切换调试方式或离开页面清除旧检查和勾选，迟到检查不能重新打开页面。确认进行中禁用重复按钮；回复不确定时保留同一 requestId 提供“查询本次确认结果”，不能生成新请求号盲重试。确认成功后进入该 Run；详情暂时失败时保留真实 Run ID 与再次查看入口。离开不撤销已创建 Run，迟到回复不抢回新页面。

必须验证：检查/取消零 Run、资源不完整不可确认、虚构或过期 token 拒绝、两种流程/调试模式、任务变化、异步预检及排队中的资源变化、浏览器同 URL 刷新、目录符号链接改向、事务回滚、重复请求/丢失回复/重开后查询唯一 Run、真实 Worker 与内置浏览器/文件结果，以及三尺寸和页面来源返回。真实模型、任意账号/网页、MCP/桌面与完整 U09/U10 不因这些检查通过而完成。
