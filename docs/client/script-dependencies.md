# 本地脚本依赖与编译快照

依赖能力属于 P1 可信 JS/TS 执行，不建设包管理器或插件市场。治理契约为 [0.4.0](../../contracts/v0.4.0/README.md)。依赖库源码、本地依赖路径和编译目录不进入模板包；用户脚本源码及其依赖声明随流程导出，导出前必须审阅。

## 本地绑定和接口

- FlowRecord.bindings 增加可选 `scriptPackages`，形如 `{"example-lib":{"path":"用户选择的本地包目录","version":"1.2.3"}}`。只接受 package.json 所在目录，已安装的 npm/pnpm 本地包可通过其目录选择；路径经 realpath 解析，不自动搜索另一个版本。
- Renderer 通过系统目录选择器取得路径，再调用白名单 `script.package.inspect`，请求 `{"path":"本地目录"}`；宿主只读取 package.json，返回 `{"name":"example-lib","version":"1.2.3","path":"规范化目录"}`。不导入包入口或执行安装钩子。flow.save 保存绑定；每次新建 Run 重新核对名称和版本。
- 编译阶段只允许脚本直接导入已声明的包和 Node 内置模块；本地包的静态传递依赖按其已有安装解析并固定，不能落回客户端自身 node_modules。支持可静态打包的 JS/TS/ESM/CommonJS/JSON；未解析的动态导入、原生 .node 等在执行前报错。不能将“包被识别”说成“该包的任意功能已兼容”。
- 只读取编译输入，不运行 npm/pnpm/yarn 或包脚本；不联系包注册中心。编译工作目录是私有临时目录，结束清理；最终 bundle 按 SHA-256 寻址，绝不覆盖已有不同内容。每次脚本执行前再次验摘要。
- 本地版本和运行快照记录 `scripts`（节点到编译文件路径）及 `scriptBundles`（可导出协议的摘要/依赖元数据）。run.detail 只返回元数据供审阅。路径不进入公共 ScriptBundle 或模板。

没有 scriptPackages 的既有草稿按空绑定读取。旧版本无 scriptBundles 且无第三方声明时可从固定文本补编译；有第三方声明却无固定产物的旧计划必须重新保存，不能以当前目录猜测原版本。

## 验证范围

验证本地包和传递依赖版本、CommonJS 的 Node 内置引用、JSON、ESM 子路径、缺失/错名/错版本、未声明导入、动态依赖、原生模块、导入/导出隔离。真实 Worker 验证排队后修改依赖、活动任务期间同流程再次编译、固定计划重开后的依赖不漂移、编译产物缺失或摘要不符时零脚本执行。桌面使用虚构包绑定和执行，不读取用户真实包源码。
