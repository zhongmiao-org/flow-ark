# HTTP、文件与 Excel 可读配置

2026-09-20。接续[通用值与变量选择](value-editor.md)，让通用流程通过字段表单完成常用配置。只使用现有契约 0.7.0 的 HTTP、file v1/v2、excel v1/v2，不增加执行器、网络接口、IPC、数据库迁移或包依赖。

- HTTP：选择 GET/POST/PUT/DELETE，配置地址、请求头和请求体，值字段可引用当前作用域变量。请求头通过名称和值编辑；GET 不发送请求体但保留草稿中的配置。表单不发送请求，运行仍走 Worker 原有 HTTP 能力，不自动重试失败请求。
- 文件：读取、写入、复制、明确文件列表归档均提供字段配置。目录绑定仍为本机资源，可在节点中选择或新建逻辑名称并调用既有目录选择；文件名为绑定目录内相对路径。写入内容保留原类型及原序列化规则；复制源与输出、归档输入与输出明确区分，不能通过表单绕过目录和路径限制。
- Excel：读取首个工作表、写入行列数据、基于模板填充单元格分别显示适用字段。行列数据提供单元格选择、值类型与变量编辑、增删行列及分页，不将屏幕上未显示的数据丢弃；已有非矩阵结构使用原值编辑方式保留。模板填充提供模板名、另存文件名、工作表名和单元格地址/值映射，空工作表名沿用首表语义。公式对象继续通过值字段的高级数组/对象方式编辑，不执行客户端表达式。
- 映射编辑不静默覆盖重复名称；HTTP 头名按大小写不敏感检查，单元格地址按 Excel 大小写与行列边界检查。现有不适合表单的配置显示并保留高级值入口，不自动改写。字段和变量选择遵守既有草稿撤销、引用作用域、保存重开和不可变 Run。
- 2026-09-20 普通 Excel 读写按真实行列索引保留空白位置，显式写入的尾部空行也需保留；空值和不等长行的规则见 [Excel 行列位置保留](excel-row-preservation.md)。
- 文件/Excel 切换操作沿用既有默认配置并提示可撤销，保留逻辑目录绑定与超时；移除不属于目标操作的字段。高级节点 JSON 保留，常用表单默认收起高级区。元数据 ID/版本和运行协议不由界面产生另一套语义。

验收：从界面搭建本地 HTTP → 文本文件/归档 → Excel 写入/读取/模板填充 → 内置表单上传的流程，核对服务端请求方法、头、请求体，文件字节、ZIP 条目、单元格类型、公式及模板保留内容。检查分页与增删不损坏未显示数据、变量/固定值切换、重复字段、非法地址、撤销、保存重开、不同操作字段、最小窗口和网页同屏布局。故意 HTTP 失败和越界路径应停止后续步骤，不能只以进程成功验收。

所有数据与网络服务为本机隔离测试；浏览器统一用内置模式，不访问招聘站点或真实 AI。代码、DMG 候选、最终安装与日常桌面分别记录。当前 Mac 解锁请求继续有效，未解锁前不替换日常应用；候选验证可独立推进。
