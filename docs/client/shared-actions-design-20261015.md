# 2026-10-15 跨页按钮与交互状态规范

接续[检查器操作规范](inspector-actions-design-20261015.md)，同步Figma可编辑补充稿[跨页按钮与状态](https://www.figma.com/design/sVciNUZHG9yx81gCpYzjH9?node-id=471-5124)。继续原Button实例、文字样式和Semantic Light/Dark变量，原186节点与原型连线保持。

## 跨页统一约定

配置卡片、参数保存、步骤编辑、脚本、更多操作、运行结果及模板配置继续复用Ant Design。短标签保留完整可访问名称；动态关联步骤名和长路径放入悬停/聚焦Tooltip，必要原因仍在正文可见。禁用容器可聚焦查看原因，内部真实按钮保持禁用；显式disabled与ConfigProvider继承的禁用都适用。

操作行/列间距12px，与正文16px；宽度不足时换行。组内常用操作预留160px，运行控制保留原120px最小宽度，卡片可全宽；加载图标、加载文案和错误重试不得挤动相邻操作。图标40px及上一批检查器规则保留。单个按钮不按临时波纹、loading图标或Tooltip DOM判断业务布局。

短文案示例：脚本配置→编辑脚本/历史输出/参数与资源；更多操作→创建副本/流程大纲；流程控制→步骤与期限/配置关联步骤/配置数据；运行结果→核对重跑，提示明确先核对、不会直接执行。

## 共享CSS边界

- 侧栏nav及其按钮规则仅限.sidebar，不污染面包屑、变量选择祖先和其他导航。
- aria-pressed或selected的配色规则排除真实disabled按钮；禁用沿用主题禁用文字、边框与底色，不被激活配色覆盖。选中语义仍保留在ARIA中。
- loading保留基础配色和尺寸，业务hover/active覆盖不应用于loading；不能以共享样式改变保存、取消或其他操作的可用条件。
- Tooltip容器接入后，原操作组的最小宽度、撑满、间距和按钮ref恢复都需要重新核对。只读卡片的自然换行继续保留。

## 验收

分别核对Light/Dark、普通/激活/选中/加载/禁用、窄窗、长名称及鼠标/键盘提示。设计补充稿的160×40px状态行是规范，不代表原型交互或真实客户端全部通过；按页面记录源检查、临时生产组件查看和原生安装证据。保留原保存/返回、输入保护、Run隔离、权限及异步逻辑，不改模板或公共契约；当前不新增/运行单元测试。
