## 展示约定

1. 自定义名称优先；步骤未命名时使用已有中文操作名和序号。实际循环项次、条件分支仍按固定快照解释，不能猜测未知步骤。
2. 运行展示名称、触发方式、实际时间和状态。列表同名项可用实际时间和列表位置区分；不生成虚假的业务编号。
3. 固定快照显示“按启动时保存的方案执行”；摘要仅供诊断。模板保留实际语义版本，Skill 使用名称及实际确认时间，不把内部版本 UUID 编造成版本号。
4. 模板实例、流程选择、结果来源、会话及资源入口使用已有名称、文件名或来源描述。无法取得名称时明确说明待核对；必要的机器配置键放在高级配置，不冒充名称。
5. 排障确需完整 ID、摘要和实例路径时，通过明确命名、默认折叠的“技术标识（高级诊断）”查看、复制。普通标题、选项、提示和无障碍名称同样执行可读规则。
6. 不修改持久化标识、API 参数、去重键、引用、路由、授权或导出语义；不做数据迁移，不重写旧运行，不增加 AI 请求或外部动作。
7. 用户资料、脚本输出与完整高级 JSON 不做猜测性替换，避免改动业务原文。诊断与原始记录仍可精确核对。
