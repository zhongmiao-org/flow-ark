# 显式选择性本机数据整理

2026-10-27：用户要求整理几百条无用流程、模板副本及历史数据。现有整库开发重置会删除正式实例、Skill 和去重，不能用于当前个人工作区；本次只增加独立显式维护命令，不进入正常启动、安装、迁移或业务运行，不增加产品界面或 MCP 能力。

## 处理范围

先停止应用和拥有的进程，再取得完整受保护备份。只读盘点通过系统安全存储读取原数据密钥，不创建或替换密钥、不读取 API Key、不打印密钥，不允许明文降级。业务 JSON、标准 ZIP 和保留记录正文不改写。

采用明确的保留根清单和数据库内实际引用闭包，保护正式实例、当前作者、个人 Skill/访谈、真实外发/unknown 及其来源。保留对象需要的流程、包、上下文、运行、快照、回执与产物索引一并保护；归属于保留流程/运行的历史不单独判垃圾。新字段或无法可靠检查的引用不得按“未发现引用”删除。预览给出准确对象及数量，不以名称模糊匹配直接执行。

可移除对象在私有清单中逐项固定 kind、id 和原加密 payload 摘要；事件按 Run 归属固定。应用仍在运行、数据库或清单漂移、保留依赖不闭合、备份缺失/不可读或缺少准确清单确认摘要时，维护工具拒绝执行。删除仅涉及明确选中的记录及其归属事件，不修改保留业务内容、额度、去重或动作状态。

## 恢复与验证

使用停止状态的原数据库作为恢复归档；保留加密记录原字节和事件。恢复只插回原本清理的缺失对象，不覆盖后续新增或变化的数据；出现 ID 或依赖冲突即拒绝，不部分恢复。凭据/数据密钥、浏览器 Profile、登录态、原始资料、外部输出、沟通缓存和既有备份不属于清理对象。

正式应用前先在停止副本上实际核对预览、应用、保留对象逐字节不变、漂移拒绝及恢复；不新增或运行单元测试。实际个人清理后核对数据库完整性、保留记录/凭据/登录态摘要及引用闭包，原生重开确认正式入口、Skill 和运行历史可读，且不自动重放或启动招聘。

当前仅为先行维护范围；尚未交付选择性工具或清理实际个人数据。私有清单、备份路径、原始业务内容不提交 Git。实际数量、工具交付、执行与恢复验证分别登记到本页，并据实际结果勾选 ROADMAP。
