## 处理范围

先停止应用和拥有的进程，再取得完整受保护备份。只读盘点通过系统安全存储读取原数据密钥，不创建或替换密钥、不读取 API Key、不打印密钥，不允许明文降级。业务 JSON、标准 ZIP 和保留记录正文不改写。

可移除对象在私有清单中逐项固定 kind、id 和原加密 payload 摘要；事件按 Run 归属固定。应用仍在运行、数据库或清单漂移、保留依赖不闭合、备份缺失/不可读或缺少准确清单确认摘要时，维护工具拒绝执行。删除仅涉及明确选中的记录及其归属事件，不修改保留业务内容、额度、去重或动作状态。

## 恢复与验证
