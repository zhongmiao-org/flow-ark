# 内置网页元素拾取

2026-09-18，0.1.9 已实现网页元素拾取与表单式动作配置。用户提供影刀 6.0 产品视频后，优先补齐从空白流程搭建复杂表单的编辑体验。交付与验证证据见 [客户端验收](acceptance.md)；自动录制、AI 生成与模板商店不属于本次实现。

## 交互

浏览器节点提供“从网页选取”与“验证定位”。选取展开主窗口右侧内置网页，鼠标悬停高亮，点击选定目标并结束拾取，Escape 或取消退出。选取只取得目标，不执行网页按钮、提交、输入或自动开始 Run。节点保留原操作与填写值；首次选取可提供可读名称。选择器与 iframe 路径支持高级手工编辑。原生下拉选项可以显示可读标签，输入内容由用户填写，不复制网页现有输入值。

目标必须能由现有 BrowserDriver 唯一定位：顶层页面、嵌套 iframe（包括跨源）、可唯一定位的开放 Shadow DOM。优先稳定属性，缺少属性时使用结构路径并提示其易变性；不能唯一表达的目标明确拒绝，不能选择第一个相似元素。拾取时和验证时均检查唯一性。密码、输入框当前值、Cookie、登录态与整页 DOM 不进入结果或日志。

## 分层与本地 IPC

网页保持无 preload、无 Node、无工作台 IPC。适配器经现有单 WebContents CDP 连接启用原生检查模式，生成并校验定位；Main 只负责视图和拾取生命周期，宿主检查运行互斥。Renderer 不接受网页脚本、原生 CDP 方法或任意执行入口。

| 白名单方法 | 请求 | 响应 |
| --- | --- | --- |
| `browser.embedded.pick.start` | requestId，非空字符串，最多 100 字符 | 拾取状态 |
| `browser.embedded.pick.status` | 同上 | 同请求状态，或已失效 |
| `browser.embedded.pick.cancel` | 同上 | true；不能取消另一请求 |
| `browser.embedded.pick.validate` | selector（1～4000 字符）、framePath（最多 8 个同界限选择器） | 唯一目标信息，或明确错误 |

拾取状态包含 requestId、phase（picking/selected/cancelled/error）、可选 target 与 error。target 包含 selector、framePath、label（最多 100 字符）、tag、inputType、multiple、structural（是否结构定位）、options（最多 200 个 value/label/disabled，字符串有长度上限）。状态只驻留内存，旧请求失效后不能覆盖新请求或其他节点。所有字段仅当作数据，界面不渲染原始 HTML。

启动与验证只允许没有活动运行或已暂停/等待人工、且没有待消费继续指令时进行。运行开始、单步/继续后的浏览器操作必须先退出拾取；关闭面板、切换节点、导航、页面丢失、最小化/隐藏窗口、超时和退出清理高亮与会话。不能因取消拾取关闭正常网页或重新执行业务步骤。异步旧结果必须丢弃。

2026-09-20 静止光标修复：Chromium 原生检查模式在没有悬停目标时会放行鼠标按下，因此不能单独依赖其拦截。适配器现在先阻止原生按下及对应抬起，清除旧悬停目标后只发送一次用于命中解析的移动，通过高亮节点事件生成定位，不向网页重放点击。Main 注入屏幕位置到网页视口的坐标转换，处理跨进程 iframe 的局部坐标；适配器仍只控制本网页。仅注册临时文档根节点以取得节点 ID，不保存 DOM。解析失败、取消和过时请求清理监听与检查模式；在视图之外丢失的抬起不能影响之后正常的点击。

公共流程沿用契约 0.7.0 的 browser v2/v3：仅将 selector/framePath/name 写入现有草稿；target 元数据不进入流程协议或数据库，不改变不可变 Run。无 SQLite 迁移，无模板格式变化；旧客户端仍可执行保存后的标准节点。治理约定先提交并通过 PR/CI，客户端记录实际采用的治理 SHA 后交付。

### 客户端内部契约

本接口仅属于Renderer→白名单IPC→宿主执行互斥→Main视图生命周期→内置网页适配器，不成为平台API或可移植节点。已发布0.39.0的browser v5/v6、包2.0、SDK和数据库格式不变，不生成新的公共版本；客户端声明采用本治理提交。原pick.*、任务修复/聚焦和旧节点保持，不让旧状态误作字段候选。

独立方法前缀`browser.embedded.fields.pick`：

| 后缀 | 严格请求对象 | 响应 |
| --- | --- | --- |
| start | requestId、scope | 本请求state |
| status | requestId | 本请求state；非当前为cancelled |
| cancel | requestId | true；只能取消此字段请求 |
| confirm | requestId | 再次核对后的candidate；失败不返回可采用值 |
| validate | scope、selector、framePath | 只读candidate；不产生待应用请求或执行动作 |

requestId非空且最多100字符。scope为`{version:1,kind:"root"}`，或`{version:1,kind:"field",root:{selector,framePath}}`；各对象严格拒绝未知键。所有新selector为非空文字、最多2000字符；framePath最多8层、每层同界限；不接受变量、脚本、任意CDP或网页对象。validate的root模式selector/framePath是全局根；field模式selector是相对根定位且framePath必须与scope.root.framePath完全相同，不能借验证改框架。外部IPC预算仍2MiB，无凭据/文件/网络能力。

state包含requestId、phase（picking/selected/cancelled/error）和按状态出现的candidate或error。candidate为`{version:1,kind,root:{selector,framePath},field,label,tag,structural}`：root模式field为null，root是实际点选唯一目标；field模式root保持原scope准确字节，field为`{selector}`，selector唯一对应原根的严格后代。label/tag各最多100字符，只为可读定位元数据；不返回输入当前值、完整textContent/innerText、选项、整页DOM、Cookie或登录信息。Renderer只按文字显示。

适配器复用本网页的受控指针命中与鼠标按下/抬起拦截。此作用域模式选择原始Element，不自动提升到label.control或button/a祖先；框架归属由实际命中获得。根选择与字段查询均使用目标Document/Element原生querySelectorAll，与collect相同，不沿用旧全局ShadowRoot穿透来冒充可采集目标；Shadow DOM不在本增量支持范围，应明确拒绝，旧普通拾取仍保持其原有支持。框架路径继续由明确唯一框架组成；不能匹配/表述的框架拒绝，不能换驱动。

field start先固定唯一根的文档/框架和实际DOM节点身份；点选必须属于同一Document和根的严格后代，root本身、外部元素、另一框架以及重复/无效定位均拒绝。生成相对定位优先稳定属性，失败才使用有界结构路径；最多64级祖先、最多128次候选唯一性查询，每条选择器最多2000字符，框架最多8层。不得为找目标遍历无界Shadow DOM或把全文回传；超出生成预算、单次目标解析15秒或拾取120秒时明确停止，不自动降级为首项。

候选需要在适配器/Main内存中固定原生resource、文档代次（含同网址刷新/子框架导航）、根与所选节点实际身份；不能仅凭URL、相同文字或重新解析同名元素接受替换。confirm再次检查相同resource/文档/框架、原根仍唯一且同一DOM节点、原目标仍为同一DOM节点/严格后代、相对定位仍唯一指向该目标、原始scope及候选准确一致。验证路径也须前后核对文档/框架代次；失败时整次拒绝，不保存“已验证”。身份句柄不返回Renderer、不持久化、不进入流程、结果或ZIP。

启动/验证/确认沿用现有宿主运行互斥和待继续指令保护；Main拒绝并发网页操作。换选择、取消、Esc、关闭或扩大/收起网页、隐藏/最小化/退出、导航或文档/框架变化、运行继续及120秒到期均取消当前字段候选，清理高亮和身份。旧普通拾取开始也必须使字段候选失效，反之亦然；取消旧字段请求不能取消较新的普通/字段请求。确认等待期间允许放弃，迟到结果不得覆盖另一动作、根、字段或新输入。正常退出不恢复待采用候选、不自动重放。
