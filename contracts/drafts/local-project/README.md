# Local project v1（未发布候选）

2026-11-05 用户批准本地代码、Mermaid区块绑定、配置、CLI/MCP与内置AI开发通道。工程清单机器格式见project-v1.schema.json，语义与准确阶段见../../../docs/client/local-project-development.md。此目录未发布，当前客户端实现为工作分支，不宣称已采用正式contracts标签。

Mermaid限定flowchart TD/TB/LR。节点声明ID["名称"]，同层next连线构成唯一顺序链。condition显式ID__then和ID__else子图，loop显式ID__body子图；非空结构分支通过带then/else/body标签的边连接至该子图首节点。结构节点完成子块后继续本层next，不允许任意跨块边或图环。节点文件仅存节点本身，不存then/else/body，脚本单独引用公开源码。编译结果必须通过既有FlowDefinition、作者定义及标准完整包校验。

常量公开固定；配置defaults/instance/profile/env/overrides顺序合并，输入独立。真实env仅在显式选择profile后读取根目录声明变量。公开清单禁止.flowark及真实env；包默认权限保持deny。脚本读取编译时固定的只读ctx.constants，节点常量引用用单字段$constant对象；不执行JSON或env表达式。JS/TS仍为可信代码，不是安全沙箱。

开发IPC采用project.*白名单，路径选择与ZIP输出由Main选择器提供；外部运行使用本机配对连接，不能转发任意内部方法。运行请求须经原RunReview和本人确认，不因AI/MCP调用自动获得许可。完整请求/响应、事务恢复及AI模式仍在实施核验，非本候选全部已完成声明。

开发重建保留规则：已连接工程的调试实例可显式重建到新不可变包，而不为每次脚本修改创建空白实例。只在无活动 Run/连续会话、配置与状态 Schema、资源/动作声明及入口边界完全一致时允许；核对源码/编译摘要差异后，以完整实例修订 CAS 更新当前流程定义及包引用。保留实例/流程/数据上下文标识、配置、输入、绑定、授权、状态与修订、效果及unknown；历史Run、包、快照和来源副本原样保留。目录扩展、边界变化或客户端本地流程改动时停止并提示，不静默丢弃。数据上下文仅在Schema相同且准确旧包身份匹配时迁移包引用；不可用于普通模板自动升级或清除历史。迁移回执固定前后包及实例修订，运行仍需原核对。

重建后的既有结果绑定：不改写旧Run、结果索引、原始owner或证明，不把旧结果复制进新包范围。重建回执登记未改变的资源ID与完整Ref摘要；只有当前实例仍准确绑定该Ref，且回执证明同实例/相同声明及Schema的显式重建，才允许读取原owner范围的已固定结果。再次解绑立即停止此路径；目录搜索仍只展示当前包范围，不扩大历史发现。读取继续核验原proof、数据摘要、完整副本及当前绑定修订。

开发运行覆盖与入口输入：profile/env/显式覆盖不保存为本人实例配置。宿主按工程Schema解析后创建仅供本次核对的许可，固定工程修订、基础流程摘要、实例ID、基础配置修订/摘要、有效配置和入口输入摘要。许可标识仅存在宿主Run快照，不能由普通流程/公共包注入。原RunReview在私有开发上下文中核对该快照，提交时原子关联Run；SDK读有效配置，写入仍复验基础实例、资源、权限及许可。普通RunReview和非项目实例没有覆盖入口。核对前profile/env变化拒绝提交；运行中源码/配置文件变化只影响下一次解析。结果、状态及unknown继续属于同一实例，不因覆盖新建空状态或重放。

机器可读开发请求见 `requests-v1.json`，安装候选的 MCP 工具目录及参数见 `tools-v1.json`（26个工具，含有界批量上下文、节点规划、局部规划修订、逐节点代码及精确补丁、草稿查询、确定性组装及源码节点Schema）。二者为未发布候选，包含开发运行分层参数与只读历史查询；不扩大本机配对、资源或运行权限。实现仍在类型化边界验证，最终交付须重新核对目录一致性。
