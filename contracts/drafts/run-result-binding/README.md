## 两种结果用途

`host-redacted-v1`只供普通结果页显示，既有策略可能整体遮蔽conversation、facts或content字段。不能从这个显示投影反推原值，也不能把显示摘要作为业务数据复用。已有完整原始结果仍在本机加密Store；直接读取它缺少最终已知秘密值保护，不能绕过资源选择。

本能力另定义`credential-redacted-v1`可复用数据副本：仅由原Run宿主在结束前、仍持有原授权秘密值时生成，并使用最终已知集合复核。过滤已知秘密值、常见Key/Bearer文本、凭据语义字段/秘密字段名；不因字段名包含conversation/facts/content或私人联系资料就整体遮蔽业务内容。保留业务身份与事实的代价是副本可能包含本人资料；须在专门的普通阅读区明确预览范围，再为准确目标选择。不是新增公开、模型或外发许可，不声称能发现全部未知秘密。后续正式契约须固定字段识别、匿名键、碰撞与UTF-8/JSON算法及正反资料，不能依赖实现自定。

完整原值先按固定完整Schema校验，过滤后的完整数据再次按同一Schema校验；破坏必需结构、const/pattern或身份的过滤结果不可复用，不猜补字段。`dataChanged`明确表示过滤改变canonical数据；摘要与字节数只证明实际交付副本，不暴露保护前摘要。准确Run/来源ID、包/定义摘要、Schema路径不能被过滤成另一个身份；无法保护则停止。

私有记录使用现有加密KV，无新DDL或启动迁移。保存策略版本、Run/快照/原值/Schema的私有核对摘要、准确正式/作者来源、完整可复用数据、纯文本注解和登记完整性，绝不保存秘密值集合。另用小型只读目录索引记录宿主核验的范围、入口、Run终态及固定原因；不把整份资料/Key/原Schema写入目录或日志。登记失败/unknown不伪称可用；原Run、完整原始结果、显示副本及专用视图继续保留。

旧Run只有显示副本或没有复用索引时，不回填、不重跑、不读取Key重建；读取历史与授权新流程复用分开。只有原本就持有完整最终秘密集合的原Run收尾路径可以登记，不提供任意旧Run的“修复副本”接口。

## 声明与隔离

公开资源`run-result`仅允许`access:read`，声明至少一个本模板`sourceEntries`（唯一、最多64个、必须实际存在）。入口明确引用该资源及`run-result-read-v1`能力；作者通过字段/资源UI维护，不能把本机ref作为默认值。通用`run-result` v1节点仅有read操作和逻辑binding，不接收Run ID、路径、结果、Schema、latest或权限开关；后续用变量选择器引用数据与来源。包/作者/节点契约及能力门槛须一并发布，不能只放宽能力列表。

v1限于正式模板实例与固定作者SDK副本。正式目标只选同一instance、同一固定packageKey/digest、声明入口内的来源；制作目标只选同一author draft的声明入口，可明确选该草稿较早修订的固定checkout/SDK上下文。不能混用正式/作者、其他实例/制作草稿，名称相同无效。没有固定模板/作者身份的普通流程不支持本版来源绑定，必须明确阻止，不伪装已接通。完整Agent目标保留，后续若需跨拥有者共享/普通输出再独立定义授权契约。

来源仅限SUCCEEDED且完整来源/Schema/可复用副本核验通过的Run；FAILED/CANCELLED/INTERRUPTED/活动Run即使有保存值也不可作为本版可执行来源，仍可用0.41.0只读查看。运行成功不证明建议真实、页面当前或外部动作成功。

## 普通选择、预览、保存

目标包含准确instance或author flow、当前保存修订；宿主重新解析实际拥有者、完整定义、资源及允许入口，不信任Renderer自报owner。列表仅分页读取该范围的宿主小索引，每次最多20条；先过滤拥有者/入口，再返回元数据。无值、无Key、无私人Schema、无其他实例标题。候选只表示可以请求预览，不能在完整核验前称来源已验证。旧记录无索引不作为候选；目录新增不改变当前选择。

游标固定目标指纹、资源、搜索及目录上界和位置；换目标/资源/查询、伪造上界/位置或位置超界拒绝，不自动跳页。没有新的合格项时可继续有界翻页，不扫描无限历史。目录顺序由宿主登记位置确定，不靠客户端时间或名称排序证明因果。

预览严格输入target/binding/runId；重新核对Run、固定快照及执行版本、准确归档/作者上下文、完整Schema/原值、私有副本/索引与交付数据摘要。异步包/Schema读取后再次核对来源和目标，变化拒绝，不能拼接两次记录。完整Schema仍禁止外部引用；固定结果Schema在解析前64KiB限制，底层整包沿现有20MiB压缩/100MiB解压/512文件限额，不把响应限额称全部I/O上限。

宿主返回只读完整预览、有界纯文本注解和不可预测reviewId/readStamp，私有核对记录绑定目标指纹/资源/ref/完整副本/Schema；有效期最多10分钟，以宿主单调时钟核对，重开失效且不自动确认。最多512个未过期预览/选择许可，耗尽明确提示。普通阅读区可逐层展开对象/数组和更多字段，摘要200项/8层不能成为“完整内容只能看JSON”的理由；高级机器详情只作可选调试。选择始终采用完整已核验数据，不按当前展开字段截取。

本人点击“确认选择此结果”后，select只接收准确预览身份、readStamp、target/binding和reviewed:true；宿主重新核对目标和源，再登记短期选择许可并返回ref到本机表单草稿。此时尚未保存绑定。最终参数/实例保存继续用原CAS；宿主对新增/变更ref要求准确未过期选择许可，不能手写JSON或借另一资源/目标的许可。保存失败保留旧绑定和输入；回执未知先读取当前保存状态核对，不能自动用新请求覆盖。

inspect只读取此目标已保存ref，或经准确预览身份获准的候选；不能靠猜Run ID读取数据。列表、预览、选择、保存绑定、inspect都不创建Run或调用模型。模型和Worker SDK不获得全局目录/选择接口；可信脚本运行模型保持既有边界，本能力不被称为OS安全沙箱。

## 固定运行与撤回

绑定只存ref，不把整个私人数据塞入公开定义。新Run准备时固定ref、来源与数据副本的核对身份，纳入执行版本/快照。读取节点经宿主白名单，核对活动Run/节点/资源声明、不可变快照及当前保存绑定仍允许此ref，再核对原来源和私有登记，交付准确完整副本。禁止任意路径/Store回退、动态换最新、从显示投影或最后步骤补值。

后续来源新增或当前制作草稿变更不替换旧ref。参数草稿中的清除/替换未保存前不生效；保存后阻止后续依赖运行和对旧绑定的新读取。已经交付节点的数据、模型/网络请求或站外副作用不能撤回；停止活动任务需明确取消。编辑绑定不改变旧Run内容，历史只读仍使用原身份。不能把“清除绑定”说成立即撤销所有已读内容或已下发动作；既有写入范围核对继续生效。

拒绝自引用；来源须在消费者准备前真实完成并登记，不能以墙钟时间或调用者声明充当此证明。不递归自动执行数据里的`$ref`、HTML、脚本或提示词；它们只是数据。结果来源不扩大事实可信度、动作权限或模型指令权限。BOSS所需账号/会话/原消息/职位/Skill/条件/接管复验、稳定意图和去重仍归模板及既有宿主边界，不写进通用节点。

保存流程、实例、不可变版本/快照、计划和作者调试绑定的引用均受保护；正常维护不得删除仍被引用的来源Run/包/私有副本。清除当前绑定不解除旧Run引用。来源被显式维护移走、存储失败或无法核验时，后续读取明确停止，不重建、换源或重放。无需本版虚构尚不存在的删除功能，但后续正常维护入口必须遵守本条。

## 导出与复用

公开ZIP/作者带回只保留逻辑资源、sourceEntries、能力和读取节点。排除ref、review、选择许可、原文、数据副本、目录索引、Key、配置、Run历史、本机授权；不把已选数据烘焙为字面量。新实例初始未绑定，不能从旧实例或同名资源继承；重新导入后由使用者生成/选择自己的结果再保存。公开性仍需作者按既有可信代码/资源核对，不声称工具能发现任意脚本中所有隐藏秘密。
