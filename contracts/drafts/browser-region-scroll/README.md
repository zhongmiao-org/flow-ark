# 单次区域纵向滚动

2026-10-20。先行设计、真实列表缺口和分层验收见[客户端说明](../../../docs/client/browser-region-scroll.md)。本目录维护0.49.0候选来源，不修改已封存0.48.0。新增browser v12/scroll与browser-scroll-v1；旧节点、SDK1.0、包2.0、IPC/数据库保持。

固定CSS或单层变量引用目标沿既有1–2000 Unicode标量、固定8层framePath规则；方向up/down及1–2000整数CSS像素固定在节点。Worker解析目标一次，宿主核对固定节点和当前nodeInstance；只有selector引用槽可改变。作者及正式入口须自己的browser/use资源和browser、browser-scroll-v1声明；不需要点击/提交动作，也不由滚动授予它们。

驱动唯一绑定可见目标后，在当前文档内最多64层组合祖先中选取最近的纵向auto/scroll/overlay区域；没有此区域才使用该文档scrollingElement。到边界不滚动父区域。区域自身、祖先、文档和框架关系固定；反向flex、非水平书写、滚动吸附、动画、无法判定布局或超限拒绝。首批内置/Chrome，其他浏览器明确阻止新节点。

采用固定有限操作和instant位移，不能由模板注入网页JS。执行前后核对同一目标、区域、文档/框架代次、网址及取消/期限；单次不重试。已发生位移不承诺撤销，导航或迟到不进入后续步骤。回执v1记录方向/距离、区域来源和祖先层数、前后位置/高度/可见高度、实际位移/边界，不能证明加载完成、候选队列完整或业务完成。结果与调用来源及数值关系严格校验，原始网址/目标依既有受保护存储及脱敏显示。

wire/schema、格式样例及固定关系参考不是实际浏览器或应用单元测试。正式封存、PR/tag、客户端独立采用/打包安装、普通UI配置与原生复导、真实列表续批分别记录。个人现场证据不进入这些文件。
