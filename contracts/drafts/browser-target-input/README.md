## 节点与声明

拟新增browser v8与独立browser-target-input-v1，限click/read/wait；旧v1–v7不改。流程、作者/正式入口均声明browser和新能力；入口仍须独立browser/use资源。正式包中click保留既有模板写入动作/授权边界，不因selector引用而跳过；作者调试仍明确限定自己的副本与绑定。

selector为1–2000个Unicode标量的非空白CSS文本或严格单键`$ref`。引用根限params/steps/item/index，沿用已有点路径规则，禁止空段及__proto__/prototype/constructor；不执行数据中的第二层引用，不拼接模板表达式。framePath为固定CSS字符串数组，最多8层，各层非空白且最多2000标量。value必须null，不借此扩展fill/upload/press或其他动作。可选timeoutMs为100–3600000毫秒，仍受父容器和取消约束。

作者在普通目标配置中明确采用引用目标，通过已有变量选择器绑定并保存；默认旧节点不静默升级。将新节点改成不支持引用的动作须明确清除不适用的引用并提示重新配置，允许草稿撤销。导出只含逻辑引用，不带入运行时解析值、当前页面、城市或本机资源内容。

## 解析、宿主与驱动

本次Worker仅用不可变流程及本次参数/前序/循环作用域解析selector。宿主按准确固定节点核对id/type/version/operation/name/timeoutMs/value/framePath，固定selector须完全相同，只有预先声明的引用selector槽可变为有限文本；不得增加字段或换动作。运行必须仍活动，nodeInstance登记且末段对应节点；模板能力与浏览器资源、当前写入守卫照常复验。该规则不声称宿主可以重建任意脚本内部上下文，脚本/Renderer/模型不获得直接调用此宿主路径的权限。

解析后不再接受引用对象、数组、数字、null、空白或无效Unicode，不截断、不将空目标解释成body。每次调用使用原framePath逐层唯一绑定框架；驱动在当前命令中唯一定位并绑定一个可见元素，多匹配立即拒绝，未出现可在期限内等待。命令中目标、页面或框架失效时拒绝，不改用替换节点继续，不切驱动重放；业务层仍需投递前核对城市、账号和岗位身份。单次命令绑定不等于跨节点原子快照，不声称能锁住网站。

click只执行一次调用，返回`{clicked:true,verified:false}`，不证明网站受理或业务成功。调用后出错、取消或超时不自动重试，实际业务意图由既有操作账本/模板处理unknown。read返回有效Unicode文本，最多65536 UTF-8字节，超限整次拒绝；wait返回true，仅证明本次唯一元素可见。返回前再次核对活动Run/取消；迟到结果不进入后续动作。通用日志和普通显示沿既有脱敏，不公开解析后私人目标。

## 格式资料与阶段

wire.schema.json定义节点与已解析调用格式；examples.json和reference.mjs/check-examples.mjs仅核对格式、引用路径、Unicode及固定字段关联。使用外部既有AJV依赖目录，不导入应用源码或Store，不修改应用数据。它们不是宿主、驱动、取消、动作账本、UI或真实招聘验证，也不是应用单元测试。

本批45项正反格式/关联资料通过，可用`node contracts/drafts/browser-target-input/check-examples.mjs /absolute/dependency-directory`重现；依赖目录仅提供AJV 2020，不建立应用源码或运行时依赖。包含参数/前序/循环引用、固定字面量、非法目标/路径/字段/期限、篡改固定调用、结果类型及UTF-8字节边界。CSS语法和真实匹配不由纯格式资料证明；驱动和宿主准入仍未实现。
