# 契约 0.9.0

2026-09-21，增加完整流程规划输入与结果，既有 FlowDefinition、节点版本、模板包 2.0 和 SDK 1.0 不变。开发快照使用 `contracts-v0.9.0`；只有远程 tag 实际存在才算发布，规范文件不代表消费者或真实模型已验收。

新增 `AIPlanningContext`、`AIPlanningQuestion`、`AIPlanningRequest`、`AIPlanningResult`，规划格式为 1.0。示例使用虚构值，不发请求、不执行任务。旧 0.8.0 消费者不支持这组新定义，原流程/模板消费者不必为了规划能力改变格式。应用采用固定副本和生成类型，不从治理目录运行时导入。

结果分为完整方案、补问、不支持三类。方案必须有完整流程；补问与不支持不得夹带可执行流程。文本上下文代表明确选中的文本或提取说明，`image` 标签不意味着协议携带了图像字节或模型具备视觉能力。未实现的连接、图像解释或应用能力须明确提示，不冒充可执行节点。

语义校验、采纳、并发、取消、差异和本地接口见 [AI 规划宿主](../../docs/client/ai-planning.md)。MCP 连接、桌面窗口绑定及二进制附件协议仍需各自增量定义，此版本不冒充已经覆盖。
