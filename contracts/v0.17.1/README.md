# 契约 0.17.1

2026-10-12 修正 0.17.0 示例步骤遗漏 version 字段，并澄清 ZIP 导出只保留中性结构、不携带用户值；旧快照保持不可变。运行与能力语义不变。

## 数据与求值

`FlowDefinition.parameterSources` 是可选对象，键为已存在的参数名，值为仅含 `$ref` 的对象。表达式只允许 `params.<其他参数名>[.<字段或数组索引>...]`，最多 2048 字符、32 段、1000 项，参数依赖深度最多 64。根参数与各段不能是空段、空白或 `__proto__`、`prototype`、`constructor`。不允许自身或间接循环，不读取步骤输出、循环项、文件、绑定、凭据，不执行 JavaScript、函数、插值或算术。

保留 `parameters` 中的固定值。运行开始前以当前不可变快照中的参数与来源按依赖顺序求值，结果深拷贝，来源存在时覆盖相应固定值；缺失参数、缺失路径、非法表达式、循环等均在产生步骤副作用前拒绝，不能回退到固定值。未设置来源的参数仍使用原固定值；清空来源恢复该固定值。数组只允许存在的规范十进制索引，不读取 length、继承属性或其他属性。参数固定 JSON 内的 `$ref` 字样保持普通数据，只有独立来源字段参与求值。

宿主预检、授权核对、步骤校验、Worker 与模板 SDK 均使用同一有效参数；存储、版本与运行快照保留固定值和来源原文。导出定义 ZIP 沿用清除用户值规则：有来源时只保留 Schema 已声明的对象键/数组位置和中性值（文本为空、数字为0、布尔为false、null不变），保留来源表达式；不导出实际值或实际求值结果。输入 Schema 按有效参数类型生成，导入后按当前实例输入重新求值。改变草稿不影响运行中或固定计划的快照。来源存在时必须声明能力；旧严格 Schema 拒绝新字段、未知能力拒绝执行，当前阶段不新增旧客户端迁移或兼容层。

## 编辑与归属

普通流程可编辑来源；模板实例的参数仍以模板配置为权威，客户端不越过只读投影编辑。变量选择器仅展示本作用域其他流程参数，支持已知子字段及高级子路径。选择或手工修正后写入来源字段，取消不变，未完成输入保留并阻止保存；返回/跨页沿用未保存保护。来源改变也需核对依赖来源的有效值。

重命名同步改来源键及结构化 `$ref` 的根参数，不能改普通文本或脚本。删除时先移除该参数自己的来源；其他来源或步骤仍引用它则阻止删除并指出引用。清空最后一条来源时删除空对象和本能力，其他能力保留。

治理 PR 合并并发布不可变 tag `contracts-v0.17.1` 后，客户端独立固定复制 Schema、摘要与生成类型。站点业务仍归模板，不新增业务节点或 IPC。示例见 [example.parameter-sources.json](example.parameter-sources.json)，交互设计见 [参数来源表达式](../../docs/client/parameter-sources.md)。当前不新增或运行单元测试，类型/构建/人工核对单独记录。
