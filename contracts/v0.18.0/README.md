# 契约 0.18.0：结构化 AI 节点

2026-10-15。为独立个人蒸馏、职位判断与聊天提供通用 `ai` v1 节点，能力名 `ai-node-v1`。流程格式仍为1.0、包2.0、SDK1.0；历史快照不变。发布以远程 `contracts-v0.18.0` 为准，契约存在不代表客户端或真实模型调用已通过。

## 字段与输出

`binding` 为逻辑AI资源名（小写字母开头，字母/数字/连字符，最多100字符）；`instructions` 为1–100000字符的固定非空白指令；`input` 使用既有 Value，可选择固定JSON、参数或前序输出引用。`schema` 是固定JSON Schema，其根必须声明 `type:object`，支持本地 `#` / `#/…` 引用，不读取远程Schema，不按流程变量求值，也不参与步骤重命名或参数重命名。其他属性、特别是provider/model/key不进入可移植节点。

输出为既有AIResult：`provider`、实际`model`、`requestId`、经过完整Schema校验的`output`和`usage`；后续步骤使用 `steps.<id>.output.<field>`。未取得用量时usage为null，不猜零。成功完成后才发布输出；截断、拒绝、非JSON、格式不符、401/限流/网络错误均停止，不静默重试或更换服务/模型。

Schema正文最多64KiB，结构深度最多32层、节点最多5000；请求instructions/input/schema序列化合计最多1MiB。Schema需在任何模型网络请求之前编译校验；不执行自定义关键字/代码或远程加载。现有JSON字符串上限、引用作用域及运行步骤上限继续生效。

## 本地绑定与授权

沿用本机 `Bindings.resources[binding]` 中的provider/model；Key只由宿主通过系统凭据库按当前配置修订读取，不返回Renderer、节点或执行Worker。AI资源不要求加入“允许脚本读取凭据”清单；绑定AI能力不授予脚本读取Key权限。两者禁止相互冒充。

预检核对每个AI节点的资源、显式模型、用户Key及配置修订，准备期间变化即撤销。排队和活动运行持有已固定的绑定；运行使用期间禁止修改/删除其Provider配置。普通流程运行核对明确展示将发送到用户绑定模型、产生token消耗；模板还须在当前入口声明 `ai` / `ai-node-v1` 能力及对应 `ai/use` 资源，不能借用其他入口资源。全部模型调用由用户自己的Key承担，不存在开发者Key或共享额度兜底。

## 执行、取消与隔离

执行核心只解析input并调用注入的执行端口，不依赖供应商或Electron。宿主从不可变节点快照取得指令/Schema/绑定，只接受当前Run和节点实例的已解析输入。宿主在取Key前、取Key后、请求前后核对运行所有权与取消；节点超时/取消通过有身份的撤销请求传递，先于调用到达的取消也生效，迟到结果不写入步骤输出。单节点默认期限60秒，模型适配器当前单次请求上限45秒、输出预算4096tokens；不自动循环或调用其他工具。

本节点只生成数据。模型输入是普通资料，不能授予文件/浏览器/消息动作权限；后续有副作用步骤仍须原有授权与业务核对。模型处理日志只记录脱敏请求标识、状态与用量，不自动记录完整指令和输入正文。

## 编辑、导出与消费者采用

Figma先补通用节点配置、资源缺失、请求取消及格式失败状态；配置支持指令、输入来源、输出字段和高级本地Schema。保存/切换不调用模型；未完成字段/JSON草稿阻止离开保存，错误保留原输入。

标准ZIP导出保留指令、Schema与输入表达式，声明 `ai/use` 逻辑资源及能力，清除本机provider/model/key。导入后重新绑定，未配置禁止运行。输入中真实个人资料仍须作者显式整理为参数/资源，公开导出核对不能以“不含Key”代替无个人数据检查。

先合并并发布治理快照，再由客户端独立固定复制Schema/摘要和生成类型；不能运行时读取父仓库。严格旧Schema会拒绝新节点，未支持 `ai-node-v1` 的客户端在执行前阻止；本阶段不实现旧客户端兼容层，不修改SQLite或清库。
