# P1契约0.31.0：模板目录默认来源

TemplateAuthorResource与TemplateArchiveManifest.resources项新增可选字符串defaultDirectoryFrom，格式为既有逻辑资源ID；只能用于directory并指向同一声明集合中另一个directory。来源目录自身不能带defaultDirectoryFrom；不允许未知、自引用、重复ID、链或环。可多目标引用同一来源，声明顺序不参与语义。JSON Schema规定字段格式和目标类型，directory-defaults.ts给出跨声明语义，作者保存与包校验均调用；example.directory-defaults.json及17项cases为语言无关资料，不是产品运行证据。

此字段是目录绑定编辑器的初始草稿默认规则。只有本人在资源表单选择来源目录或明确选择“使用来源目录”时才能应用；不在导入、创建实例、读取/打开表单、保存其他字段或Run准入时执行隐式解析。实际绑定必须经过既有template.save并由本人核对可见目标路径，运行时不沿该字段查找备用绑定；缺目标仍按缺项阻止。

应用来源选择时，填入本次草稿中尚未设置且未被本人明确另选/清除的目标；同一次草稿内，来源后续修改/清除仅同步此前自动填入的值。已有保存值或本人手动值不可被覆盖，包括与来源恰好相同的路径；不能只凭路径相等推断自动派生关系。手动选择/清除停止该目标在本次草稿中的自动填入；本人明确使用当前来源可重新填入。系统选择器取消无操作。

失败保留当前草稿、派生提示与手动覆盖状态；取消表单回原保存值。成功保存后，来源与目标均为独立固定绑定，后续来源修改不持续更新目标。未保存的派生/覆盖状态属于编辑会话，不写入资源协议或SQLite永久开关；明确清除不构成跨会话永久禁用默认规则。保存CAS、活动Run不可变快照和缺项预检不变。

声明不包含绝对路径、内容、凭据或账号，不复制文件，不改变read/write/readwrite或入口资源范围，不继承动作授权。只复制本人选定来源路径供当前目标预览；Key、业务事实、Skill确认与执行授权独立。作者移除/改类型/重命名仍须保持引用有效，导出摘要覆盖字段，编译与复导保留。所有不支持该字段的消费者必须拒绝新定义/包，不能静默忽略；包2.0、SDK1.0、节点、IPC、实例绑定和SQLite格式不变，无旧客户端迁移或隐式清库。
