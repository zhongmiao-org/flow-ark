# 契约 0.13.0

2026-09-23。新增 `mcp` v1 工具步骤：`target` 为逻辑目标标识，`tool` 为工具原名，`arguments` 使用现行 Value 常量/引用，期限复用 timeoutMs；流程须声明 `mcp-tool-v1`。连接地址、认证、程序路径、发现状态与本机授权不进入可移植节点。

开发快照标识 `contracts-v0.13.0`，以远程不可变 tag 为发布依据。流程格式 1.0、模板包 2.0、SDK 1.0 不变，不改写历史 Run/计划。没有该节点或执行能力的消费者必须在执行前拒绝，不能回退 HTTP、脚本或另一连接。

完整字段与执行边界见[工具节点](../../docs/client/mcp-tool-node.md)，脱敏方案见[示例](example.mcp-tool.json)。Schema 能接受某个方案不代表本机连接已绑定、工具参数符合服务定义或工具调用已实现。消费者分别报告草稿编辑/规划和真实执行支持；当前新增契约只为接入草稿与方案提供格式，不宣称 tools/call 可用。
