# 契约 0.11.0

2026-09-22，新增 `file` v3 `create`：UTF-8 文本只新建、不覆盖。流程格式仍为 1.0，模板包 2.0，SDK 1.0。现行规范中 v1 读取／写入／复制与 v2 ZIP 归档仍有各自语义；已有流程、运行快照和契约目录不改写，不增加旧客户端迁移。

开发快照标识 `contracts-v0.11.0`，以远程不可变 tag 存在为发布依据。流程和模板入口声明 `file-create-v1` 能力；不认识节点或能力的消费者必须在执行前拒绝，不允许降级为覆盖写入。规范和发布不代表客户端已实现或教学闭环已验收。

完整语义见 [新建文本文件](../../docs/client/file-create.md)，正例见 [example.file-create.json](example.file-create.json)。Schema 复用值引用形状；解析后的文本类型、UTF-8 字节上限、相对路径、目标冲突及原子提交由消费者实现与验证。客户端固定纳入副本和生成类型，不在运行时读取治理仓库。
